# ADR 0181：同一份排版只让一个窗口编辑——后开的窗口只读、可一键接管；「存成副本」是真分叉

- 状态：已接受（2026-11-12，产品负责人裁决；1.0 豁免见 `docs/1.0-release-readiness.md` §1.8，原话「都按推荐来，1.0豁免」）
- 相关：[0120 恢复门](0120-document-restore-verdict-and-recoverable-last.md)（「动作记住、出口之后接着做」与画布中间的卡）、
  [0101 排版时间线](0101-layout-timeline.md)（副本不继承时间线）、`docs/rules/frontend/ui-visual-discipline.md`「失败出口三种结局与红色提示门禁」

## 背景

同一份排版（同一个 `documentId`）在两个窗口里开着时，此前只有一条**不带按钮**的红色提示：「这份排版已在另一个窗口打开，同时编辑会互相覆盖。」
两边照样能改；真撞上（自动保存 409 `stale_write`）只有「重新加载」，本窗口的改动进恢复槽位；覆盖确认框里写着「想两份都留，请改用另存为」，
而「另存为新排版」并不换 `documentId`——两个窗口仍然是同一份。这是失败出口门禁台账里的一条 `TODO(dead-end)`（#1857 留下）。

参照 Word 与 Illustrator 的共同做法：**一份文档同一时刻只有一个编辑者；后来者只读或被送去已开的窗口；想留两份 = 明确地存一份副本；绝不静默覆盖。**

## 决定

### 一、终态表

| 时刻 | 一句话 | 主按钮 | 次按钮 |
| --- | --- | --- | --- |
| 后开的窗口打开同一份排版（收到 `doc-held`） | 这份排版已在另一个窗口打开。 | 在这里编辑 | 存成副本 |
| 被接管的窗口 | 这份排版正在另一个窗口编辑。 | 拿回来编辑 | 存成副本 |
| 已经撞上（保存时 `stale_write`，窗口互相没发现） | 另一个窗口保存了更新的版本。 | 存成副本 | （「重新加载」在顶栏状态芯片的说明块里） |

前两行是画布中间的卡（与恢复卡同一做法），不是红色提示；第三行是状态栏提示——它只有一个按钮位，不为第二个按钮撑宽胶囊，「重新加载」与「另存为…」（同一个真分叉）留在顶栏状态芯片的说明块里。外部修改（`conflictExternal`）那条的出口不变（「重新加载」）。

同批把这组提示改成人话：顶栏芯片「外部冲突」→「别处有改动」；说明块第一句与状态栏提示同句；读不到磁盘那份的摘要时不摆那一行；「从磁盘重新加载」→「重新加载」。

### 二、只读与「动作记住」

后开的 / 被接管的窗口在用户选择之前**不能改**：用户动手的操作先记住，选完接着做，不丢（0120 的同一原则）。只读期间自动保存不写盘。

### 三、「在这里编辑」= 接管

经 `BroadcastChannel`（`lib/docPresence.ts`）：请求方发接管请求 → 持有方先把没存的改动存好再回应，然后自己变成「被接管」→ 请求方载入最新版、放开编辑、执行记住的操作。

- 持有方在限时内没回应（已关 / 卡死 / 不认识这条消息的旧版标签页）→ 请求方直接接管，载入盘上最新版。
- 持有方存不进去 → 仍让出，它的改动留在它自己的窗口里，可「存成副本」，不丢。
- 「拿回来编辑」是同一协议反过来走。
- 只有**正在编辑**的窗口回应接管请求：只读的窗口（后开的、已让出的）不回话，免得第三个窗口抢在编辑者存好之前替它应答。两个窗口同时都是只读（浏览器恢复标签页）时，等满限时（3 秒）后接管。
- 只读期间被记住的是经入口闸门的动作（按钮、菜单、快捷键、拖放）；直接打字 / 拖动被拒并提示先选，不重放——与 0120 恢复门的覆盖范围一致。

presence 仍是**尽力而为，不是租约**：真正拦住覆盖写的仍是自动保存的乐观并发；`BroadcastChannel` 不存在时整层静默跳过，落到终态表第三行。

### 四、「存成副本」= 真分叉

把此刻窗口里的排版分成一份新排版：新 `documentId`、新自动保存位置、名字「原名 副本」；绑定了项目文件的写成原文件旁边的新文件（重名加序号，不覆盖任何已有文件）；
时间线与撤销历史不继承；原来那份（本机自动保存与项目文件）一个字节不动。分完后本窗口端着副本，原 `documentId` 不再由本窗口占。

「另存为新排版…」（⇧⌘S）改走同一个分叉——这才让覆盖确认框里「想两份都留，请改用另存为」成立。

## 隐私与安全

纯前端；不新增后端端点、不绕过会话认证（ADR 0008）、不加遥测事件。`BroadcastChannel` 只在同源标签页之间传 `documentId` 与标签页随机 id，不传排版内容。

## 不做的事

- 不做后端占用登记（租约）：桌面版 + 浏览器、或两个不同浏览器同时开，窗口互相发现不了，保存时撞上走终态表第三行。
- 不做合并两个窗口的改动。
- 不把后开的窗口直接关掉 / 跳走：浏览器里跳不到另一个标签页，对面关了用户会卡住。

## 验证

单测覆盖：分叉（新 id、原件不动、项目文件不覆盖重名、历史不继承）；接管协议（正常、超时、持有方存不进去、反向拿回、旧版标签页）；
只读期间操作被记住并在选择后执行、自动保存不写盘；终态表第三行的两个按钮。失败出口台账删去 `autosave.docConflict`，`DEAD_END_CAP` 13 → 12。
