# ADR 0128：智能对齐——图内编辑跨图对齐同类元素、等比缩放吸附、吸住后保持

## 问题

外部方案《Tavotto Smart Alignment》提出：科研排图里用户要对齐的往往不是图片外框（白底），
而是图里的子图、轴标题、图例。对照 2026-10-14 的 main：

| 场景 | 现状 |
| --- | --- |
| 图内拖子图 / 轴标题 / 图例，对齐**同一张图**里的元素 | 已有（`inFigureSnapCandidates` + `snapMoveNearest`，09-25） |
| 图内拖元素，对齐**旁边另一张图**里的同类元素 | 没有——候选只来自本图 |
| 图内拖元素，对齐页面参考线 | 没有 |
| 图内拖子图的缩放手柄 | 不吸 |
| 锁宽高比的角柄缩放（面板默认锁定） | 完全不吸（`startResizeDrag` 只在 `!proportional` 时吸） |
| 吸上之后 | 每帧重新挑候选；两条候选一样近时来回跳 |
| 吸附反馈 | 只有贯穿整页的吸附线，看不出吸的是自己哪条边、对方是谁 |

评审页（含可拖演示与逐项裁决）：<https://claude.ai/artifact/Aw3uD9BPjV4XoeiB7tVYSL>。

## 用户裁决（2026-10-14）

- **暂缓**：拖整张图时用图内子图做锚点（方案 §4/§8 的平移内容感知）。拖整张图仍只拿外框吸附。
- **做**：图内编辑时跨图对齐同类元素；等比缩放吸附。
- 轴标题、文字都算吸附对象；其余细项全部按评审页推荐（下文逐条写入）。

### 1.0 收敛纪律的例外登记

本 ADR 扩大了交互能力，按 `AGENTS.md`「1.0 收敛纪律」登记为例外，理由：只改前端交互层，
吸附只改位移 / 尺寸，**override 的写法与写回事务一个字不变**（仍是一条 `pos_frac` / `position`、
面板仍是 x/y/w/h），不改文档格式、不改引擎与 manifest。

## 裁决

### 一、吸附内核：候选带元信息，同档比距离，吸住后保持（PR1）

候选线从「一串数」升级为带元信息的线：`{ v, kind, edge, source, panelId?, gid?, rect? }`——
`kind` 是语义类型（外框 / 子图 / 色条 / 图例 / x 轴标题 / y 轴标题 / 图标题 / 文字 / 页面 / 参考线 / 网格），
`edge` 是 0/1/2（左中右或上中下），`rect` 是它所属元素在页面 mm 里的框（反馈用）。

- **X / Y 各自独立**挑一条。
- **挑法**：容差内（`snapTolMm`，6 屏幕像素）→ 先比档位、同档比距离。档位只在缩放吸附里用到
  （外框对外框、内容对内容、任何东西对页面 / 参考线 / 网格 = 第一档；外框与内容混搭 = 第二档）；
  图内拖动所有候选同档，只比距离（同图与跨图不分先后）。
- **吸住后保持**：一次手势里每个轴记住当前吸着的（自身锚点, 目标线）这一对；只要这一对的距离仍在
  **2 倍容差**内就继续吸它，拖离超过 2 倍容差才放开、重新挑。手势结束即清空。
- 旧调用方语义不变：画布对象平移（`snapMove`，按左→中→右顺序取第一条）这次**不动**。

### 二、图内编辑跨图对齐同类元素（PR2）

在排版画布上双击进图内编辑后，拖图内元素时，除本图已有的候选外，再加：

1. **别的图里的同类元素**，只配**同一条边**（拖图例时，B 的图例底边只配自己的图例底边）：

   | 正在拖的 | 跨图去配 | 用哪几条线 |
   | --- | --- | --- |
   | 子图（`role: axes`，非色条） | 子图 | 左↔左、右↔右、上↔上、下↔下 |
   | 色条 | 色条（左右上下）、子图（只上↔上、下↔下） | |
   | 图例 | 图例 | 四条边各配同一条边 |
   | x 轴标题（gid 以 `.xlabel` 结尾） | x 轴标题 | 中线↔中线（两个方向） |
   | y 轴标题（`.ylabel`） | y 轴标题 | 中线↔中线 |
   | 图标题（`role: title`） | 图标题 | 中线↔中线 |
   | 普通文字（`role: text`） | 普通文字 | 左↔左、中线↔中线 |

   x / y 轴标题分开配；刻度、刻度标签、数据线、箭头不参与。
2. **页面参考线**（「吸附到参考线」开着时）。

参与跨图的别的图：**当前视口里看得见**、未隐藏、未旋转、未翻转、拿得到**权威** manifest 的面板；
元素在它自己的裁剪窗外的不出线。**快速编辑模式不跨图**（那里别的图都让开了，吸到看不见的东西上
没法解释）。正在编辑的面板本身旋转 / 翻转时，整个图内吸附照旧关掉。

**图内子图的缩放手柄也吸**：正在动的那条边吸本图其他子图的同一条边与整图四边、别的图子图的同一条边；
不动的边不吸。

### 三、等比缩放吸附（PR3）

锁比例（或 ⇧ 强制等比）的角柄 / 边柄缩放：固定点 F 不动，每个**会跟着动**的锚点 a 与候选线 c 解出
`s = (c − F) / (a − F)`，按「先档位、后距离（屏幕像素）」选一对，宽高按同一个 s 变。

- **锚点**：外框的会动的边与中线；面板（未旋转、未翻转、有权威 manifest）再加它的子图与色条的三条线
  （裁剪窗外的不算）。轴标题、文字、图例**不**当缩放锚点。
- **候选线**：现有的 `candidatesFor`（页面、别的对象外框、参考线、网格、别的图元素中心线），
  **加上别的图的子图与色条的边**（只在缩放时加，拖整张图的候选不变）。
- 面板缩放是显示缩放，图内分数坐标不变，所以锚点随 s 线性变，解是精确的。
- 旋转过的对象照旧不吸；非等比缩放沿用现有的「只吸正在动的边」。
- 同样有「吸住后保持」。

### 四、反馈（PR4）

吸上时除贯穿整页的吸附线外：自身那条边加粗、它所属的框（子图 / 图例 / 外框）画虚线；目标在**别的图**
里时，把对方那个元素也用虚线框出来。状态放在 `interactionStore`（与 `setSnap` 同一处、同一生命周期）。

### 五、不变的

- 方向键微调不吸附（ADR 0093 §六）。
- 按住 ⌘ / Ctrl 临时不吸；吸附总开关、「吸附到对象」关掉就不吸。新能力**归入「吸附到对象」**，不加开关。
- ⇧ 锁向的既有规则（锁水平 / 垂直只在仍在走的轴上吸，45° 沿锁定方向投影）。
- 被拖元素、它的后代与随行元素不出线（`underAny`）。
- 候选一律取权威 manifest（ADR 0017）。
