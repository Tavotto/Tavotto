# ADR 0177：情景提示动画卡（看到笨办法才教，会动的小卡）

日期：2026-11-10 · 状态：**Accepted**（用户 2026-11-10 看过三条原型后拍板：「动画卡可以。这个大小可以接受。我豁免。」）
相关：ADR 0040（一次性情境提示，本 ADR 在它上面扩一类载体）；ADR 0161（拖边 = 改图幅 / ⌥ 裁剪）；
`docs/rules/frontend/onboarding-and-activity.md`；`docs/1.0-release-readiness.md` §1.8。

## 动机

很多手势是藏起来的：双击画布外的空白处适应画布、按住 ⌥ 拖边是裁剪、从标尺拖出参考线。用户不知道它们存在，
也就无从触发。ADR 0040 的一次性提示只在「第一次选中 / 第一次进入」时说一句话——那时用户并不需要它，
而且一句话讲不清一个手势（用户原话：「一句话不好」）。

## 决定

### 1. 触发：看到笨办法才说，自己用过就不再提

每条提示三段判据（全在 `lib/onboarding/hints.ts`，纯函数 + store 订阅）：

- **触发** = 用户正在用笨办法做这件事；
- **学会** = 用户自己用过一次这个功能（哪怕从没提示过）→ 永不再出；
- **上限** = 每条最多出 2 次、两次之间至少隔 20 小时；点 × = 别再提。到时自己收起 / 场景变了被收起不算「别再提」。

第一批三条：

| 提示 | 触发（笨办法） | 学会 |
| --- | --- | --- |
| `fit_canvas` 双击空白处回正 | 取景框露在窗口里的部分既不到它自己的三成、也不到窗口的三成，停手 2 秒 | 让画布「适应」过一次（任何入口，`view.fitted`） |
| `edge_crop` 按住 ⌥ 改为裁剪 | 多图排版里拖图边、改了图幅（`panel.edge_dragged` `resized`） | 拖边裁剪过一次（`cropped`） |
| `ruler_guides` 从标尺拖出对齐线 | 多图排版里 30 秒内挪了 3 次对象，标尺开着、还没有参考线 | 拉出过一条参考线（历史标签 `addGuide`） |

「画布跑偏」要两个条件同时成立：放大看细节时露出来的只是页面一角，但窗口里满满都是页面——那不是跑偏。

### 2. 节奏

- 与一句话提示共用 `useHintStore.current` **一个槽位**，不叠；
- 每次启动最多 2 张卡；教程进行中、有模态对话框开着时不出；
- 分层解锁：每条有层级（1 基本手势 / 2 修饰键 / 3 效率），按「用过这个应用的天数」（本地日期计，0 / 2 / 5 天）放行。
  第一批三条都在第 1 层；
- 设置 › 常规 › 「操作提示」开关整个关掉（一句话的与动画卡的都不出）；「重新显示操作提示」把两本账都清掉。

### 3. 载体：动画卡

窗口右下角的一张浮卡（`components/hints/HintCard`，320 宽）：上面 320×180 的一段小动画，下面一句短话 + 至多一颗按钮 + ×。

- 非模态、不抢焦点、不占布局（`fixed`，与反馈卡 `FeedbackCorner` 同一个角、同一个宽度）。放画布左下角试过：
  1280 宽的窗口里画布列只有 550px，一张 320 宽的卡盖住用户正在摆弄的图，还和底部居中的通知轨抢位置；
- 反馈卡在场时让位（不画、不收起）；与准备引导卡相交按反馈卡同一套避让；属性栏收起、卡落在画布上时抬到通知轨之上；
- 动画演 2 遍停在定格帧，指针移上去再演；系统开了「减少动态效果」只显示定格帧；
- 按钮只给「一步就能替用户做完」的提示（第一批只有 `fit_canvas` 的「适应画布」）；
- 读屏的那一句由通知轨的活动区播（它按 `current` 取文案），卡片自己不加 aria-live。

### 4. 动画是写好的光标戏，不是录屏

小场景是 React 组件（`components/hints/scenes.tsx`），舞台 / 光标 / 拖拽来自 **stageshow**（MIT，
`web/src/vendor/stageshow/`，只取舞台那一层 14 个文件，不带它的窗口 / 手机 / 品牌图标；唯一的本地改动是键帽表改用 `MOD` / `ALT`，
出处与许可在 `THIRD_PARTY_NOTICES.md`）。这样浅深色、
Windows 的 Alt 键帽、译文都自动跟，仓库里不放视频文件；场景连同套件整块按需加载，不出提示的会话不下载。

**每个动作必须和真行为一致**（2026-11-01 用户对 stageshow 的裁决「不拿仿真界面换真东西、不编造功能」在这里的落点）：
场景文件头写明每一步对应的真代码；胶囊里的字用真画布同一条译文；改了手势先改场景。

### 5. 状态与信号

- 账在 `onboardingStore`（本机、跨项目、跨重启）：`hintStats[kind] = { shows, lastAt, done }`、`hintsOff`、
  `activeDays` / `lastActiveDay`。旧的 `hintSeen` 不动（一句话提示仍按它）。旧 blob 没有这几项 = 全新的账；
- 新增两条活动信号（闭集，只有枚举）：`view.fitted`（`fitStage` 一处发）、`panel.edge_dragged { outcome }`
  （`startPanelEdgeCrop` 松手成功时一处发）。「挪对象」「拉参考线」复用已有的 `history.pushed` 标签；
- **没有新增遥测**：这两条信号不进遥测映射，账只在本机。

## 没做的

- 拖动中在尺寸胶囊里加一行「按住 ⌥ 裁剪」：胶囊的淡色后缀已经被「文字 pt 不变，松手后重新出图」占着，不再堆第二句；
- 其余十来条提示（⇧ 锁向、⌘ 关吸附、方向键微移、⌥ 轮换选中……）：分批做，每批约四条，各自带场景与判据。
