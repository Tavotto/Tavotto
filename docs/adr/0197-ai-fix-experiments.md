# ADR 0197：AI 修复的试错——小实验、失败时的提示与修复经验

日期：2026-11-19 · 状态：**已接受**（维护者 11-19 批准三层都做、各 PR 给 1.0 豁免；本 PR 落第 2 层 `run_snippet`）

## 问题

兼容性评测（`scripts/eval/fix_compat`）里，内置 AI 修不好的题多半是「看出了原因，却没法低成本地验证猜测」：
它只能读文件，或者整份脚本跑一次 `try_run`（要用户批准、一两分钟）。用 Codex + Tavotto 插件的人修得好，主要靠
Codex 能随手跑一小段代码看结果再决定下一步。`run_command`（ADR 0149 修订 #1374）能跑命令，但每条命令一张批准卡，
不适合试错。

## 决定

分三层，按 PR 落地：

1. **失败时就给提示 + 尝试记录表**：试运行失败的结果里按结局码附一句对症建议（一张表，键是结局码）；每次试运行后附上
   试过什么、错误有没有变化。同一条记录也进修复审计与诊断包（见第 4 条）。
2. **小实验 `run_snippet`（本 PR）**：在一个环境里跑一小段模型写的 Python，几秒出结果。
3. **把失败变成指导**：离线——评测里失败的轨迹提炼成第 1 层的新提示，并加一道题防退步；在线——每台机器本地记住修成功的做法
   （最后做，界面先给维护者看）。
4. **修复经验进诊断包**（维护者 11-19 裁决「总是收（脱敏后）」）：结局码之外，AI 写的启动脚本、读过的片段、报错原文、
   AI 的总结也收，一律先过 `diagnostictext` 脱敏；敏感运行参数仍一律不收。report.json 换形照例升 bundle schema。

### `run_snippet` 的边界

- 档位 `run`（与 `try_import` 同档），**不弹卡**（维护者 11-19 裁决「全部免问」；已向维护者说明下面 Windows 的盲区）。
- 执行器只有一条：`trial.run_python`（写入根绊线 + 禁起进程 + 有就套操作系统沙盒）。实验另加 `strict_deny`：
  - **断网、凭据位置不可读**：进程内第二个 audit hook 拦 `socket.connect / bind / sendto / sendmsg / getaddrinfo / gethostby*`，
    以及落在硬拦表里的 `open / os.listdir / os.scandir`；清单就是 AI 读取范围的硬拦表（`ReadScope.deny_roots()`，与 `readscope.DENY_HOME_RELATIVE` + Tavotto 自己的密钥文件同源）。
  - 操作系统沙盒同一份清单：macOS profile 加 `(deny network*)` 与逐条 `(deny file-read* (subpath …))`；bwrap 加 `--unshare-net`，凭据目录盖空 tmpfs、凭据文件盖 `/dev/null`。
    实验口径的沙盒单独探测（`--unshare-net` 在禁了网络命名空间的机器上会失败，失败就退回进程内守卫并标 `os_sandbox: none`）。
  - 当前目录是项目根、项目根在 `sys.path` 上（经环境变量交给守卫前导、用户代码运行前摘掉；不改模型代码，报错行号不偏）：能读项目数据、能 import 项目模块，写不进项目。
  - 时限默认 20 s、上限 30 s；代码 ≤ 20 000 字符、先 `compile` 检查；输出各路只回最后 6 000 字符，过 `scrub`。
- **不算「改动」**：`run` 不是 `CHANGE_TIERS`，所以不会解开「先动手才能起草产品缺陷」那道闸（ADR 0149 修订 #2053）；照常计入步数预算、照常进审计（代码只记长度）。
- 结果只是实验，**不能证明修好**：工具描述如实写，修好仍以 `try_run` 为准。

### 如实写下的盲区

- **Windows 没有操作系统沙盒**：只有进程内守卫。C 扩展 / `ctypes` 直接发系统调用能绕过断网与拒读（写入绊线本来就有同样的盲区，`writetripwire` 头注）。维护者知情后仍选免问。
- 进程内的读拦截按「真实路径前缀」判（macOS / Windows 上先 casefold：不分大小写的文件系统里 `~/.SSH` 就是 `~/.ssh`，自审发现），模型代码先 `os.chdir` 再相对路径打开照样拦；硬链接到凭据文件的别名拦不到（OS 沙盒在的平台由沙盒拦）。

## 后果

- AI 能在动手前低成本地验证猜测：import 行不行、参数解析器要什么、数据第一行长什么样、某个函数在不在。
- 守卫前导多一个可选的严格段；不带 `strict_deny` 的调用（试跑 / 探 import / 体检）行为逐字不变。
