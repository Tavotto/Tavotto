# ADR 0052：自绘图标集取代 lucide-react——24 网格、描边 2、实心孪生做选中态

日期：2026-09-15 · 状态：**Accepted**
相关：`docs/ux/ICONOGRAPHY.md`（说明书）、`docs/ux/DESIGN_CONSTITUTION.md` 第四节、
[0010 检查器呈现层](0010-inspector-presentation-layer.md)。

## 问题

2026-09-06 的图标统一（用户反馈第 7 条）把尺寸收成四档、描边收成 1.75、别名与手绘
svg 清零，但图形本身还是 lucide 的。2026-09-15 用户再次反馈：「所有图标都不够精致，
有一种很 demo 的感觉，很多图标不统一」，点名警告图标与改图助手图标，参照对象是
OpenAI（ChatGPT / Codex）的图标。

把 OpenAI 自己的设计系统 `@openai/apps-sdk-ui`（MIT，755 个图标源码公开）逐个量过
之后，「demo 感」的来源能说清楚，而且每一条都不是「换个尺寸」能解决的：

| 量到的差异 | lucide 在 Tavotto 里 | OpenAI 图标集 |
| --- | --- | --- |
| 线宽（16px 上） | 1.75 / 24 → 1.17px；14px 上 1.02px，比 13px 正文的笔画还细 | 2 / 24 → 1.33px |
| 标点（叹号 / 句点） | 长 0.01 的线段，直径 = 线宽 | 实心圆，直径 2.3～2.5（线宽的 1.25 倍） |
| 闭合外形的角 | 多数 r=2 | 三角外角 r≈4、方框 r≈3.5、六角 r≈3；内角 r=1 |
| 每个图标的元素数 | 不限（齿轮 8 齿、剪贴板 6 段） | ≤ 3（设置 = 六角 + 环，机器人 = 框 + 天线 + 两点） |
| 选中 / 激活态 | 只靠底色 | 43 对 outline / filled，外形不变、内部细节挖空 |

lucide 是一套通用库，不会为我们改这些；在它之上打补丁（换描边、加实心态）只能改
第一条和第五条，标点、圆角、元素数改不了。

## 裁决

1. **图标集自己画，全产品只有这一套**：`web/src/components/ui/icons/`。几何在
   `defs.ts`（141 个，路径由圆角矩形 / 圆 / 圆角多边形三个小函数在加载时算出来），
   组件工厂在 `createIcon.tsx`，公开面 `index.ts` 逐个导出，**名字与 lucide 时代
   一一相同**——同一语义只用一个名字的表（ICONOGRAPHY.md 第四节）不动，102 个
   使用点只换了 import 路径。
2. **画法**：24 网格；所有线条 2 单位描边、圆头圆角，按比例缩放（12 / 14 / 16 / 20 上
   1.0 / 1.17 / 1.33 / 1.67px）；闭合外形外角 ≥ 2.5、内角 ≥ 1；标点是直径 2.5 的纯填充
   圆；每个图标 ≤ 3 个可辨元素，元素间净空 ≥ 2 单位；同一家族同一个骨架（五个圆形
   状态共用 r=9 的圆，四个文件共用一个折角文档，八个对齐都是「一条线 + 两根实心条」）。
3. **选中态 = 实心孪生**：`<Layers filled />`。外形不变，内部细节用 `<mask>` 挖空；
   只给真正用作开关 / 激活态的 28 个（左轨五个上下文 + 设置 + 项目接入状态、状态家族、
   助手、图钉、眼睛、锁、矩形 / 圆工具、书签、灯泡、闪电、菱形、标签）。没有孪生的图标
   忽略 `filled`。元素树的类型图标**不做**实心态（OpenAI 也不做）。
4. **尺寸阶梯与 Provider 机制不变**：`ICON_SIZE` 四档、`IconProvider` 在三个根上给默认；
   `ICON_STROKE.regular` 1.75 → 2，`emphasis` 2.5 保留给复选框的勾。图标集自己的默认
   就是阶梯，不套 Provider 也一样——Provider 只是「默认档在哪改」的唯一答案。
5. **门禁升级**（`iconography.test.tsx`）：图标只从 `components/ui/icons` 引入且名字必须
   在 `ICON_DEFS` 里；**任何第三方图标库的 import 一律红**（lucide-react 已从
   `package.json` 拆掉）；内联 svg 豁免表加图标集本体那一个 `<svg>`；新增「每个定义都
   渲染得出来」与「filled 渲染孪生、蒙版 id 不串」两条。
6. **无障碍与 lucide 一致**：没有 `aria-label` / `aria-labelledby` / 子元素时自动
   `aria-hidden`。类名 `icon icon-<kebab>`，用例按它认形状。

三个换了隐喻的图标（其余 138 个都是同一隐喻的重画）：设置（8 齿齿轮 → 六角 + 环）、
图层（三层菱 → 一层实心 + 两道）、项目接入状态（六段剪贴板 → 剪贴板 + 勾）。改图助手
保持「一大一小两颗火花」。

## 后果

- 依赖少一个（lucide-react 1.31），产物里只剩真正用到的 141 个图标；Codex 内嵌画布、
  playground 与工作台共用同一份源码，产物按 ADR 0043 现建。
- 以后加图标要**画**而不是**挑**：在 `defs.ts` 里按上面的画法写几何，用 `iconography`
  门禁与真浏览器截图看一眼。这是有意为之——挑出来的图标就是「不统一」的来源。
- 蒙版让每个实心态图标多一个 `<mask>` 节点；28 个里同一屏最多十来个，可忽略。
- 用例里按类名认形状的四处（`lucide-type` 等）改成 `icon-type`。
