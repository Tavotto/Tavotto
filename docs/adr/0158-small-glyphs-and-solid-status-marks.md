# ADR 0158：12px 另画小号字形，状态记号一律实心

日期：2026-11-01 · 状态：**Accepted**（用户 2026-11-01 在「12px 小图标对齐」演示页上选定「小号专用画法 + 其余 16px」与「状态记号一律实心」）
相关：[0052 自绘图标集](0052-in-house-icon-set.md)、[0156 图标微动效](0156-icon-micro-motion.md)、[0157 描边 1.5 + 像素网格](0157-icon-crispness-stroke-pixel-grid.md)；`docs/ux/ICONOGRAPHY.md` 尺寸阶梯与「小号字形」一节。

## 动机

ADR 0157 之后 16px 已锐，12px（`xs`）仍糊：24 网格的图缩到 12px，描边 1.5 单位 = 0.75px = 2 倍屏 1.5 个物理像素，
线总有一侧边缘跨在半个像素上，**只挪坐标对不齐**。2 倍屏实测（灰边 = 着色像素里落在半像素上的比例）：现状 67%。

演示页比过三条路：缩小 + 线加到 1px 并吸到 12px 网格（43%）、发丝线（57%）、在 12 格上另画（32%）。用户：「这些小图标看上去每个都很糊，
换个思路」→ 选另画；看到实心状态记号后「实心的好，就是风格不太一样」→ 定下统一规则；再指出「三角警告和圆形提醒中间看不清」
（演示页蒙版继承了描边，挖口被糊住；产品代码的挖口本来不描边）与 Aa / x² 不好看。

## 决定

1. **小号字形**：`defs.ts` 的 `SMALL_DEFS` 给最常用的 13 个小记号另画一份（ChevronRight / ChevronDown / X / Check / Plus / RotateCcw /
   Download / ExternalLink / Circle / Lock / TriangleAlert / Info / CircleCheck）。坐标仍写在 24 单位里（与大图共用动作的角色、变换原点、
   位移量），但只用 12px 上的整像素：线 2 单位 = 1px，横竖线中心落在半像素上，斜线只用 45°；路径条数与顺序和大图一一对应。
   `createIcon` 在 `size <= ICON_SIZE.xs` 且有小号时换画小号，描边 ×4/3（常规 1.5 → 2 = 1px）。
2. **没有小号的图标不用 12px**：原来 xs 的 44 处（删除、图片、硬盘、加粗、上下标、移动……）改 `ICON_SIZE.sm`（16），走 0157 已对齐的几何。
   门禁 `iconography.test.tsx`：`<X size={ICON_SIZE.xs}>` 的 X 必须在 `SMALL_DEFS` 里。
3. **状态记号一律实心**：TriangleAlert / Info / CircleAlert / CircleCheck / CircleX / ShieldAlert 的默认形改为实心底 + 蒙版挖空符号
   （原来的 `sel` 孪生），不再有线条版；12px 小号同一画法，挖口是整像素矩形，上下两段之间留 1px。规则：「现在是什么状态」用实心，
   「点了会做什么」用线条。Lock 在 16px 仍是线条（图层锁定开关靠 `filled` 区分开 / 关），只在 12px 的只读记号上是实心。
4. **重画 Aa / x² / x₂**：CaseSensitive 的 a 改单层（圆碗 + 右竖）、与 A 同基线；上下标的 x 放大、2 改成更开的写法。

## 看护

- `iconography.test.tsx`：xs 门禁与自检；12px 渲染小号字形且描边 2、16px 仍是大图；状态记号默认带蒙版挖空。
- `motion.test.tsx`：状态记号的动作角色从 `sel` 挪到默认形后，登记与 CSS 仍同源。
- 真浏览器：2 倍屏工作台截图目检（顶栏下拉箭头、提示条里的实心提示）。

## 后果

- 12px 上 13 个小记号平均灰边 67% → 32%；实心状态记号 16–24%。箭头 / 叉 / 对勾全是斜线，降不到 40% 以下，靠 1px 线与整像素端点变清楚。
- 小号字形的线中心在半像素上，普通 1 倍屏（Windows 100% 缩放）也锐。
- 状态记号变重：提示条、问题列表里的警告 / 完成更显眼，这是本意。
- 以后要在 12px 用新图标：先在 `SMALL_DEFS` 画一份，门禁会拦。
