# ADR 0205：图内复制粘贴——⌘C / ⌘V / ⌘D 在同一张图里得到新的图内元素

日期：2026-11-23 · 状态：**草案（待维护者拍板）**
相关：[0163 图内文字复制为标注](0163-canvas-text-rotation-and-copy-figure-text.md)（本 ADR 修订它的 ⌘C / ⌘V 分派）、
[0037 右键菜单](0037-quickedit-context-menu.md)、[0083 修改的目标身份](0083-override-target-identity.md)、
[0171 导出修改后的 .py](0171-export-edited-script.md)、[0017 几何权威](0017-display-fallback-vs-geometry-authority.md)

## 背景

用户 2026-11-23：「目前的复制和粘贴都是只能作为标注，没有办法作为图内元素，而这样会导致用户粘贴时，会退出图内编辑。
然后想要继续编辑就还要再进图内。体验非常割裂。」同日拍板「开始做第二步」——即本 ADR：真正的图内复制粘贴。

现状（ADR 0163）：图内编辑里 ⌘C 把选中的图内文字换算成画布上的 `TextObject`，⌘V 落成标注并**退出图内编辑**
（`lib/clipboard.ts` `materializePaste` 末尾 `setElementPanel(null)`）。根因在引擎：override 只能**改**脚本画出来的 artist，
没有「新增 artist」这一类；所以复制出来的东西只能落在图外。

调研（2026-11-23）确认：没有任何 ADR 禁止 override 新增 artist；引擎已有自己往图里加 artist 的先例
（3D 轴箭头 `_set_axis_arrows` 的 `add_artist` / `remove()`，`overrides.py`）。

## 决定

### 一、模型：一条「副本」修改记录

* 副本是一条普通 override：`{gid: "<宿主>.copy_<id>", prop: "copy_of", value: {src, text, at}}`。
  * `gid`：宿主是源文字所在的子图（`axes_N`）或整张图（`fig`），`<id>` 是前端粘贴时生成的 8 位随机串。
    **不用 `texts_N` 序号名**——用户以后在脚本里自己加一个 `ax.text` 会占掉那个序号，副本的修改就落到别人身上。
  * `src`：源元素 gid（样式从它来，见下）；`text`：粘贴那一刻的文字内容（快照）；`at`：落点，**宿主子图的 axes 分数**
    （宿主是整张图时为 figure 分数）。
* 副本之后的一切编辑（改字、字号、颜色、拖动、旋转……）都是对副本 gid 的普通 override，走既有 `HANDLERS`，
  与改脚本里的文字没有区别——属性页、样式面板、「选中全部同类」、对齐、预检不需要认识「副本」。
* **样式按引用、位置与文字按快照**：重放时新建 `Text(at, text)`，`update_from(源 artist)` 拿脚本原样的字体 / 颜色 / 对齐 / 转角；
  粘贴时前端把源上**已有的样式类 override** 原样抄一份到副本 gid（同一次提交），所以粘出来与源此刻画出来的一模一样，
  此后两边各改各的。脚本里改了源的样式，副本跟着变（它是「这一类文字」的一员）；这是有意的。
* 副本 `set_in_layout(False)`、`clip_on=False`，带私有标记 `_mm_copy`；`instrument` 的按序登记跳过带标记的 artist，
  由副本自己的 gid 登记进 `state.index` 与 manifest，**角色沿用源的角色**（标题的副本仍是 `title`），所以「选中全部同类」、样式面板、
  预检的字号检查都把它当同类。

### 二、引擎（重放）

* `copy_of` 在 `_apply_rank` 里新开一档：**几何组（图幅 / 结构 / position / scale）之后、其余属性之前**——副本的位置用 `transAxes`，
  子图挪了它跟着走；对副本 gid 的其它修改排在它后面，所以创建总先于改样式。三者对拍（`HANDLERS` 顺序、`_RESTORE` 键、`_needs_state`）
  与 `scriptadjust._RUNTIME` 的 `_rank` 同源对一起改。
* 撤销 / 删掉这条记录 = `_RESTORE` 里 `remove()` 并从 index 摘掉。
* **落点用源文字画出来的锚点**（draw 之后 `get_transform().transform(get_unitless_position())`），再向右下错开 `DUPLICATE_OFFSET_MM`
  （与 ⌘D、标注粘贴同一个常量），换成 axes 分数存进 `at`；错出图外时收回图内。标题的位置是 draw 时才定的，用 pre-draw 坐标会落错。
* 源不在了（脚本改了）：这条记录与副本的其余修改照常报「元素不存在」，进界面的失效修改列表；写回照常被挡（与任何修改失效同一出口）。
  不拿默认样式凑一个出来——那是「看着对、其实错」。

**实测（2026-11-23 一次性实验，matplotlib 3.x，标题 / 竖排 y 轴标题 / 数据坐标 `ax.text` × 无布局引擎 / `tight_layout` / `constrained_layout`）**：
18 种组合里副本尺寸与源一致、其余元素外框零移动、热态与冷重放落点差 0.0000（figure 分数）。
发现一处：用外框反推锚点时，基线对齐的文字向下偏 0.013——所以锚点只取画出来的变换位置，不从 bbox 反推。

### 三、下游

| 下游 | 怎么办 |
|---|---|
| 写回原始文件 | 副本只是一条 patch，一次性 worker 全量重放时照样建出来，PDF / PNG 自然带上；验证门不放松。已核：基线（`baked_overrides`）只用来判断「磁盘文件是否已带着这组修改、能否跳过渲染」，引擎总是从脚本重跑再套全部修改，**不会叠两份** |
| 导出 PDF / PNG / SVG / EPS | 渲染的是重放后的 Figure，自动带上；`scope=original`（原件）不带，与其它修改一致 |
| 导出修改后的 .py（0171） | 新增「创建型」语句，排在所有属性语句之前：`_c1 = ax.text(x, y, s, transform=ax.transAxes)`、`_c1.update_from(<源的选择器>)`、`_c1.set_in_layout(False)`；副本 gid 的后续修改指向 `_c1`。源的选择器写不出时整条副本进「写不进去的逐条说明」。`WRITES` / `NOT_WRITABLE` 对 `copy_of` 表态 |
| 同步到同脚本的其他图 | **不同步**，进 `skipped` 并说明「副本不跨图同步」——同步是按位置映射，源在目标图上未必存在 |
| 外部审阅 / 预检 | 遍历 manifest 元素，副本自动在内 |
| 「恢复此元素修改」（副本上） | 只清副本 gid 上除 `copy_of` 以外的修改（回到刚粘出来的样子），**不删副本** |
| 「隐藏此元素」（副本上） | 换成「删除副本」：删掉 `copy_of` 及副本 gid 的全部修改，一次提交 |
| 「恢复图内修改」（整张图） | 副本一起消失——回到脚本原样，与它的语义一致 |
| 旧版本打开 | `copy_of` 不认识 → `future_props`，静默不建；副本 gid 上的其它修改报「元素不存在」，写回被挡。换回新版本一切还在 |

### 四、剪贴板与入口（修订 ADR 0163 第 4、7 条）

* **一份负载两种落法**：图内编辑里 ⌘C 写的负载在现有 `objects`（换算好的标注，0163 原样）之外，多一段 `elements: {docId, panelId, gids}`。
  * ⌘V 落在**同一份排版、同一张图的图内编辑里** → 按 `elements` 建图内副本，**不退出图内编辑**，新副本在下一次权威 manifest 出现后被选中；
  * 落在别处（画布、别的图、别的标签页 / 排版）→ 照旧用 `objects` 落成标注（0163 行为逐字不变）。
  * 分派在 `consumePayload` 里，不开第三条创建路径；标注那一支的 `setElementPanel(null)` 保留。
* **⌘D**：图内编辑里选着图内元素时 = 原地建副本（今天会复制整张图，属于误伤）；其余照旧走 `duplicateSelected`。
* **右键弹层**（`QuickEdit.ElementQuick`）：「复制 ⌘C」「粘贴 ⌘V」「创建副本 ⌘D」；「粘贴为标注」保留（无快捷键，
  想在图内编辑里也落成标注时用）；「复制为标注」去掉（⌘C 已经同时带着标注那一份）。
* **范围（第一期）**：标题、轴标题、`ax.text` / `fig.text` 的文字、`annotate` 的文字（只复制文字，不带箭头）。
  不做：单个刻度数字（不是常驻 artist）、图例文字（偏差 issue #1667 未解）、3D 子图、色条轴。这些在 ⌘C / ⌘V 时照旧落成标注，不报错。
  形状 / 线另起修订。
* **几何权威**：⌘C 时没有权威 manifest（正在重渲染）= 仍按 0163「还不能复制」处理，不拿旧清单算落点。

### 五、终态（每条都有结局）

| 情形 | 结局 |
|---|---|
| 同图图内编辑里 ⌘V | 新副本，选中它，仍在图内编辑 |
| 别的图 / 画布 / 别的标签页 ⌘V | 落成标注（0163 原样） |
| 粘完渲染失败 | 与任何修改失败同一出口（顶栏胶囊 + 可撤销）；选区不动 |
| 源被脚本删掉 | 「元素不存在」进失效修改，可删除副本 |
| 面板旋转 / 翻转 | 落点在内容坐标里算，与拖动同一把尺；错开方向按页面上的右下 |
| 第一期范围外的元素 | 落成标注，不报错 |
| 旧版本打开 | 副本不出现、其修改报失效；换回新版完好 |
