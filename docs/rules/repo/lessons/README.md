# 错题本：犯过的错与做对的事

> 由根 `AGENTS.md`「任务路由」点名：改哪一层，动手前读这个目录里那一层的文件（`repo.md` 放跨层的，
> 改跨层规则、门禁或工作流时也读它）。
> 写入只走每日复盘：会话里踩到的坑写进维护者本机的复盘收件箱，由夜审合成一个 PR 改这里——
> 并行 PR 不直接改这里（同一文件多 PR 必撞）。格式、体积与脱敏由 `scripts/dev/lessons.py` 解析、
> `tests/test_lessons_format.py` 看护。

## 怎么用

- **Seen 只数不同的日子。** 同一条在 3 个不同日子出现，就升级：规则写进对应层的细则（照细则的
  「规则 + 为什么 + 看护用例」写法，并点名 `L-xxx`），这里那条压成标题一行的指针。
- 升级之后再犯，在细则里补证据，不回到这里重新计数。
- 每层一个文件，上限 16 KiB：一个 agent 读的就是一份，上限按读的单位定。
- 条目点名的代码已不在、或已有门禁拦住、或 60 天没再出现且细则里已有同义规则：夜审直接删，在 PR
  正文列出。原文留在提交历史里。
- 这是公开仓库：不写机器地址、账号、人名、反馈包编号、本机路径。证据只写 PR 号与提交号；
  用户反馈写「一份用户反馈」。

## 条目格式

```text
### L-007 一句能照做的规则（≤ 60 字）
- 类: 别这样            # 或「照这样」（做对了、值得照抄的）
- Seen: 2026-10-31, 2026-11-02
- 为什么: 一段。发生了什么、代价是什么。
- 证据: #1587, #1604

### L-008 已升级的条目只留这一行 → docs/rules/<层>/<主题>.md
```

编号跨文件唯一、只增不复用，下一个可用编号看 `python scripts/dev/lessons.py --stats`；文件内按编号排。
