### L-120 实机测桌面壳的隔离要 DATA_DIR、CONFIG_DIR、HOME 三件套
- 类: 照这样
- Seen: 2026-09-26
- 为什么: 只设 TAVOTTO_DATA_DIR 时应用照样把 recent_projects 写进用户真实配置，多次污染；判据是跑前跑后 stat 用户 config.json 的 mtime 不变。
- 证据: #663

### L-122 测试里写出可执行文件再 exec，写要与同进程所有 fork 互斥
- 类: 别这样
- Seen: 2026-11-03
- 为什么: 写 fd 未关时别的线程 fork 的子进程继承它，exec 得 ETXTBSY 被当成 spawn 失败；合并组偶发红（L-100）。
- 证据: #1603, #1654

### L-152 夹具判「没有新进度」按已收字节数，不按轮询次数或计时片
- 类: 别这样
- Seen: 2026-11-06, 2026-11-07
- 为什么: 更新试探用例原用 150 个定时片发假下载，CI 调度一拉长来源就从 Github 变成 Mirror，挡了别的 PR 两次；修法又在每次 Pending 时重置检查点，额外唤醒能让夹具一直扣住尾字节，直到生产代码正确判停滞，再挡一个 PR。稳定区间以已收字节不变为准；反证时在原驱动里注入额外轮询，须仍绿，撤掉修复须红。
- 证据: #1798, #1801
