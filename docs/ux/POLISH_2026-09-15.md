## 二、两家共有的手段（量化）

| 手段 | OpenAI apps-sdk-ui | Claude 产品壳 | 共同点 |
| --- | --- | --- | --- |
| 面板 vs 底 | gray-50 1.05:1、gray-75 1.11:1 | sidebar #f6f6f4 vs #fff 1.08:1 | ≤ 1.11:1，白块不「浮」 |
| 边框 | alpha 10 / 15 / 16（1.24～1.43:1） | 10% / 5% | 半透明，静态 ≤ 1.45:1 |
| hover → active → selected | 8% → 12% → 16% | 4～5% → 10% | selected ≈ hover × 2 |
| 输入框聚焦 | 边从 16% 升到 50% | ring 1px + 0 1px 2px 5% | 聚焦才达 3:1 |
| 浮层 | ring 8% + `0 10px 15px -3px 10%`，圆角 12 | ring 6% + `0 4px 24px 4%`，圆角 8～10 | 1px 环 + 一层大模糊；圆角比控件大 4～6 |
| UI 正文 / 控件字 | 14 / 14（sm 12） | 14 / 12.5～14.5 | 正文 14，最小 12，台阶 2px |
| 强调字重 | 600（b/strong、标题、分段、徽章） | 500 配 #0b0b0b | 至少高一档且配深色 |
| 分段控件 | gray-100 容器 + 白 thumb + 阴影，600 | 白 thumb | 选中项白色浮起 |
| Tooltip | gray-700 底白字 2 × 8，圆角 8 | — | 不是小白卡 |
| 进场 / 退场 | 350 / 200ms，out-expo | 200 / 60ms，out-quart | 进场 ≥ 200ms |

  去实色边 · T4 hover 5 / active 8 / selected 10 · T5 底 `#f7f6f3` · T6 分段白 thumb + 600 · T7 Tooltip

  页签选中态 600、设置页控件贴右。
- **批次 B（PR #359）**：设置 · 项目页（目录行 = 值在标题列 + 更改…）、样式 / 规范页（库收成一行：一份写
  名字 / 二到四份分段 / 再多 Select，正在用的规范不摆主动作）。
- **批次 C（PR #360）**：检查器 · 画布对象页（X/Y/W/H 坐进框里、图片适配拆成取景一行 + 适配一行）。
- **批次 D（PR #361）**：导出对话框（一种行语法，80px 标签列；预览卡收成头部一行）。
- **第二轮 · 全面打磨（原语 → 页面，六条 stacked 分支）**：`ux/polish-primitives`（原语层，audit-primitives A01–B20）→
  `ux/fp-left`（左栏 40 条）→ `ux/fp-inspector`（检查器 40 条）→ `ux/fp-canvas`（顶栏 / 画布 / 浮动栏 / 通知 / 命令面板 40 条）→
  `ux/fp-dialogs`（对话框与设置 47 条）。五份审计与两份第二轮调研（`polish-research-2.md` 逐组件量化、`polish-research-pages.md`
  页面级）见会话 scratchpad；落下的规矩在宪法第二十节；对比稿 artifact「Tavotto 全面打磨对比」。
- **批次 E～G（一个 PR）**：问题面板（页 → 筛选 → 组 → 行，图名进页签 title，组头一行）、顶栏（项目 /
  文档面包屑、缩放改文本钮 + 适应画布图标钮、写回降 ghost）、脚本区（安全导入说明删、分组计数同一格式）。
  素材区的底部操作条与接入状态条**保留**：前者是 listbox 外唯一可 Tab 到的真按钮（axe nested-interactive），
  后者只在有状态时出现——两条都不是「常驻说明」。

## 五、版式层的四条病根（批次 B～H 的依据）

- **L1 一页里三种行形态并存**：标签在上 / 标签在左 / 行内混排轮换。两家一个表单只有一种。
- **L2 控件列定宽 240 且左起对齐在页面中间**：改成贴右缘（批次 A 已做）。
- **L3 动作权重不唯一**：黑钮与白钮并排、边框组 + 边框钮 + 黑钮相邻。每个语境一颗 primary。
- **L4 层级靠标题堆叠**：问题面板一条问题上面六层头。两家一屏最多三层：页 → 组 → 行，组间 28px 留白。
