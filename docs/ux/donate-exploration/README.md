## 一、研究结论（以仓库为准）

- **视觉语言**：`docs/ux/DESIGN_CONSTITUTION.md` 的 Paper × Instrument；值取自 `web/src/index.css`
  `@theme`：桌面 `#efefed`、纸 `#ffffff`、墨 `#1b1b18`、墨阶 `#4a4a45 / #6c6c66 / #a3a39a`、
  accent `#2c73de`、画布选择框 `#4685e2`、field `#f2f2f0`。全部文字对底色 ≥ 4.5:1（ink-3 在桌面上 4.59）。
- **The Small Blue Rule**：蓝色只做选择、焦点。页面里蓝色**只**出现在「编辑层」——选中框、手柄、对齐参考线、
  焦点环——与应用内画布完全一致。数据永远是墨色。
- **字体**：宪法只允许一套 UI 字体（系统 sans）+ 文档字体（Times New Roman / 宋体，画布上的文字对象用）+
  mono（脚本名、代码）。原型照此分工：sans 是 Tavotto 的声音，serif 是「纸上的图」，mono 是「源」。
- **图的样式**照抄 `examples/figures/paper_style.py`：衬线、刻度朝内、无框图例、细线宽——页面上的每一张图
  都像 Tavotto 真实打开的 matplotlib 图。
- **能力只写仓库能证明的**：支持矩阵来自 `docs/support-matrix.json`；写回的 prepare → verify → commit、
  PDF 文字保真、出版规范预检、遥测同意、架构决策记录数（`docs/adr/` 111 份）都来自 AGENTS.md / README / ADR。
  没有用户证言、机构背书、用户数、筹款目标。
- **边界**：「不发明图的内容」是产品原则（PRODUCT.md）。所以动效里**数据曲线从不移动**，移动的只有图例、
  字号、面板排布；第三幕最后一步专门把这一点说出来。

## 二、三个方向

### A · The Scientific Manifesto（科学宣言）
- **核心创意**：一份开放科学刊物的第一页。整页满版纸白，刊头 hairline、目录式的六幕索引、一个脚注。
- **视觉语言**：纯版式。超大标题（≈154px / 字距 −0.05em）只放前半句，后半句以较小字号在右侧「回应」。
  那条线是一把毫米标尺，从左侧平直走来，在右侧升成一条 S 形曲线后离开画面。
- **排版系统**：12 栏；标题占 3–12 栏，回应占 8–12 栏，脚注占 3–7 栏——不对称但都落在栏线上。
- **动效**：标题逐行 4px 上浮；标尺线 2.2 s 画出。
- **情绪**：信念、冷静。
- **不足**：换个 logo 就能属于任何开源项目；线是装饰，不是证据。

### B · The Living Figure（生长的科学图形）——推荐
- **核心创意**：整页就是一张图。首屏是 Tavotto 画布上的一张剂量–反应图，标题写在数据为空的左上区域
  （就是 matplotlib 会放图例的地方），图例处于**选中**状态——这是首屏唯一的蓝色。
- **视觉语言**：灰桌面 + 白纸面板（应用工作面板的同一隐喻）；衬线图字、刻度朝内、误差棒、EC₅₀ 虚线。
- **排版系统**：A 的 12 栏与幕头（一条墨线 + 起点一个数据点 + 罗马数字索引）；标题用容器查询单位随图缩放，
  所以「标题住在数据空白里」在任何宽度都成立。
- **动效**：先数据点、后拟合曲线、最后编辑层——顺序本身表达「数据在先，模型在后，编辑最后」。
- **情绪**：精密、安静、可信。
- **不足**：维护成本最高（SVG 坐标、五个滚动状态）；手机上被编辑的图偏小。

### C · A Letter to Science（写给科学的一封信）
- **核心创意**：桌面上一张信纸，日期、称呼、正文、署名；页边一条批注写明「这里没有东西在卖」。
- **视觉语言**：正文用 Tavotto 的文档字体（衬线），信纸外是桌面灰；那条线从信纸**背后**穿过——信只是遮住了
  线的一段，线本身没有断。
- **动效**：信纸内容依次显现；线 2.6 s 画出。
- **情绪**：温暖、真诚，但不煽情。
- **不足**：必须由真实的维护者署名（原型里是 `[Name of the maintainer]` 占位），否则像模板；作为可分享的视觉
  物件最弱。

**判断：做 B，从 A 和 C 各借一样东西。** B 是唯一让页面本身替 Tavotto 论证的方向：读者亲眼看着一张真实的图
被编辑，而数据一动不动。A 和 C 都把话说得很好，B 把它演示出来。
从 A 借：12 栏网格、单墨线幕头、让每张图喘气的大字节奏。从 C 借：第五幕的语气（第一人称复数、在表单旁边
把支持的条件说清楚），以及——等有真实的维护者可以署名时——表单上方一段短短的署名留言。

## 四、最终页面的结构

| 幕 | 标题 | 视觉 |
| --- | --- | --- |
| I The promise | Discovery is hard enough. Expressing it shouldn’t be. | 图 1：剂量–反应曲线，图例被选中 |
| II The problem | The last millimetre shouldn’t take another night. | 九张同一面板的缩略图，沿一条「夜晚的时间轴」排开：23:12 → 01:52，图例只挪了 3 mm |
| III The principle | Keep the source. Shape the figure. | 粘性舞台 + 五步滚动：原样 → 移图例 → 调字号 → 对齐面板 → 数据留在原处；旁边是「未改动」的脚本和一条条增长的 override |
| IV The invisible work | Good tools take work you may never see. | 一条平直的「仪器记录线」上有八个小刻度——顺利的一天，发生了八件事，看起来什么都没发生；下面是 01–08 八项真实的工程工作 |
| V The invitation | Help us keep building. | 单次 / 每月、四档金额 + 自定义、独立币种选择、演示提交 |
| VI The continuation | The next discovery is still unwritten. | 一条测量序列停在「最近一次测量」，坐标轴继续延伸到屏幕边缘——我们不替未来画数据 |

## 五、动效设计与实现

全部是 SVG + CSS transition + 两个 IntersectionObserver，无动画库，无 canvas，无滚动劫持。

| 动效 | 叙事意义 | 实现 |
| --- | --- | --- |
| 首屏绘制 | 先坐标轴（0.8 s）→ 测量点逐个出现（每点 70 ms）→ 拟合曲线画过它们（1.5 s）→ EC₅₀ 注释 → 图例 → 选中框。数据先于模型，编辑最后 | `pathLength="1"` + `stroke-dashoffset`；首帧绘制后加 `.is-ready`（双 rAF），标题同时可读，不等动画 |
| 夜晚时间轴 | 时间在走，图例几乎没动 | 每格的 hairline `scaleX` 依次延伸，140 ms 级联 |
| 五步舞台 | 每一步只有一个元素在变，且都是数据**周围**的东西 | 步骤文字过视口中线时切换 `data-step`；图例 `transform` 1.0 s、字号 `font-size` 0.7 s、面板 0.9 s；选中框只在它那一步出现（180 ms）；第五步把非数据层淡到 20%，让数据单独留下 |
| 记录线 | 「看不见的工作」 | 一条 `stroke-dashoffset` 线性画出的基线 + 八个刻度依次出现 |
| 未完的线 | 开放结尾 | 坐标轴 `scaleX` 3.2 s 延伸并溢出到视口边缘（`overflow-x: clip`，无横向滚动）；曲线只画到最后一个测量点，空心圆收尾 |
| 捐赠 | 安静、明确、快速 | 只有 120 ms 的颜色 / 底色过渡；没有弹窗、没有庆祝动画 |

- 进场位移一律 ≤ 4px（宪法第七节）；位置跟随型的移动（图例、面板）属于宪法允许的「指示物滑到新位置」。
- `prefers-reduced-motion: reduce`：所有 transition 关闭，所有元素直接处于最终状态；滚动叙事仍会切换步骤
  （那是信息，不是装饰），但瞬时切换。
- 无 JS 时页面完整可读：初始标记就是最终的排好版的状态，JS 只负责把它「倒回去」再播放。
- 不能滚动的定高画框（画布上的 artboard）里，所有显现直接完成，不会停在透明。
- 页面放进可滚动容器（画布上的手机画框）时，观察器自动以那个容器为 root。

## 六、实际渲染检查（Chromium / Playwright）

- 1440×900 与 390×844，英文与中文，全部截图在 `screenshots/`；两种宽度 `scrollWidth == clientWidth`，无横向溢出。
- 第三幕五个状态逐一截图（`act3-steps-desktop.png`、`act3-steps-mobile.png`）。
- 表单：单次 / 每月切换、自定义金额校验（< 1 禁用按钮并提示）、演示提交的状态说明、键盘方向键切换 radio、焦点环。
- 自审中修掉的问题：页脚内边距被覆盖、金额按钮样式误伤内层 span、规格列表等高拉伸、手机端图例选中框裁字、
  初始图例没真正压住数据、币种随语言切换会把 $42 变成 ¥42（改为独立币种选择）、中文孤字换行、
  以及中文字体回退：Linux 上 `-apple-system, BlinkMacSystemFont` 连写会被当成 system-ui，汉字落到系统
  回退字体，最终中文栈改为 `-apple-system, "Noto Sans SC", sans-serif`。

## 七、如果正式上线，还需要

   每月支持的取消流程必须真实可用，「Monthly support can be stopped at any time」才能保留。

   任何抵税字样（现文案已写「我们不声称它可以抵税」）。
3. **资金去向说明**：第五幕的 `[Link to the funding statement — to be written]` 必须在上线前替换成真实页面。
4. **署名**：如采用 C 的署名留言，需要真实维护者署名与授权。
5. **移植到官网仓库**：按 `Tavotto_website` 的技术栈拆成组件；品牌名从 `web/src/lib/brand.ts` 同源取值；
   第四幕的平台与版本口径改为从 `docs/support-matrix.json` 生成，避免与 README 漂移。
6. **字体**：自托管并预加载中文子集（只含本页用到的字），去掉对 Google Fonts 的运行时依赖。
7. **暗色主题**：按宪法第二十八节，纸与图保持白色，只换桌面与界面色。
8. **无障碍复核**：在 Safari / VoiceOver 与 NVDA 下通读一遍；axe 两腿零 violation。
9. **度量**：只按现有遥测同意规则记录匿名的「到达第五幕 / 点击继续」，不加第三方追踪。
