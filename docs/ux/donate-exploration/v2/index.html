Tavotto is an open-source editor for scientific figures. It lets you finish the figure your script drew without rewriting the script. This page is about why we build it, and how you can help.

Tavotto 是一个开源的科研图形编辑器。它让你直接完成脚本画出的那张图，而不必一次次重写脚本。这一页讲我们为什么做它，以及你可以怎样帮助它继续下去。

IIIThe principle原则III / VIII

Keep the source. Shape the figure.

保留脚本，雕琢图形。

Tavotto opens the figure your script has already drawn. You shape it directly; the script stays as it was.

Tavotto 打开脚本已经画好的图，由你直接塑造；脚本保持原样。

In every step, the curves, points and error bars stay exactly where your script put them. Tavotto makes a figure easier to shape — never its data easier to change.

每一步里，曲线、数据点与误差棒都停在脚本画下的位置。Tavotto 让图更容易被塑造，但绝不让数据更容易被改动。

VThe people behind the work这项工作背后的人V / VIII

A note from the maintainer.

来自维护者的一封短笺。

Tavotto began with a very ordinary frustration. The script has drawn the figure and the result is settled, yet moving one legend or changing one font size still means editing code and running it again, and again. I want to take that repetition out of research work, so that good results can be shown freely and precisely. Doing this well takes a long time, and I intend to keep doing it carefully.

Tavotto 起源于一个很具体的困扰：脚本已经画出了图，结论也已确定，却还要为了挪动一个图例、调整一处字号，一次次修改代码、重新运行。我希望把这些重复劳动从科研工作中减去，让好的研究成果能被更自由、更准确地呈现。把这件事做好需要很长时间，我会继续认真地做下去。
