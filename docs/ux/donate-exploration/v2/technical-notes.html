Technical notes: the details behind the three missions.

技术说明：三项使命背后的细节。

As of version 0.18, October 2026. Each line points to where the repository states it; anything still in beta says so.

截至 2026 年 10 月的 0.18 版。每一条都注明了仓库中的出处；仍处于 Beta 的部分如实标出。

01

Your Python, as it is.

就用你现有的 Python。

Python 3.10 to 3.14 and matplotlib 3.8 to 3.11 — in the runtime Tavotto carries, or in your project’s own environment, which is in beta.

Python 3.10 至 3.14，matplotlib 3.8 至 3.11——可以用 Tavotto 自带的运行环境，也可以用你项目自己的环境（Beta）。

docs/support-matrix.json · pyproject.toml [worker]
02

Tested where you work.

在你工作的地方测试。

Desktop apps for macOS 14 or later on Apple silicon, macOS 15 or later on Intel, and Windows x64 — each with an installer, CI checks and a smoke test of the real build. Linux runs from PyPI in a browser tab, in beta.

桌面版支持 Apple 芯片上的 macOS 14 及以上、Intel 上的 macOS 15 及以上，以及 Windows x64——都有安装包、CI 检查，并对真实构建产物做冒烟测试。Linux 通过 PyPI 在浏览器标签页中运行，目前为 Beta。

docs/support-matrix.json · release notes 0.17 / 0.18
03

Nothing written until it is proven.

未经证明，一字不写。

Before a change is written back into a figure file, the script runs again from scratch and the result is compared with what you saw — geometry and pixels. If anything differs, the file is left exactly as it was.

在把修改写回图形文件之前，脚本会从头再运行一次，结果与你所见逐一比对——几何与像素。只要有任何不同，原文件保持原样。

AGENTS.md · write-back invariant
04

Text that stays text.

文字始终是文字。

PDF export embeds each vector panel as it was drawn, so text remains real, selectable, searchable text. PNG and TIFF are rasterised from that same PDF, and every exported file is reopened and checked.

PDF 导出按原样嵌入每个矢量面板，文字始终可选中、可搜索。PNG 与 TIFF 从同一份 PDF 栅格化而来；每个导出文件都会被重新打开并检查。

README · Export for publication · release notes 0.16
05

Checked before it leaves.

离开之前，先做检查。

Before export, the figure is checked against a versioned publication profile: one set of rules, read by both the engine and the interface.

导出前，图会依据一份带版本的出版规范接受检查：同一套规则，引擎与界面共读。

PRODUCT.md · src/tavotto/profiles/publication.json
06

Failure, said plainly.

失败就说失败。

When a refresh fails, the status says so. Approximate previews are marked as approximate. Properties Tavotto cannot edit are listed, not hidden.

刷新失败时，状态如实说明。近似预览会标明是近似。Tavotto 无法编辑的属性会被列出来，而不是藏起来。

PRODUCT.md · Product principle 4
07

Your figures stay on your machine.

你的图留在你的电脑上。

Everything runs locally. Telemetry is off until you say yes, and your scripts, paths and the text inside your figures are structurally unable to leave.

一切都在本机运行。在你同意之前，遥测保持关闭；你的脚本、路径与图中的文字，在结构上就无法被发送出去。

08

Decisions, written down.

每个决定，都有记录。

More than a hundred architecture decision records, kept in public beside the code — including the ones that say what Tavotto will not do.

一百多份架构决策记录，与代码一起公开存放——也包括那些写明 Tavotto 不做什么的决定。
