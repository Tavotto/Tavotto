To everyone who has stayed up late to move a legend,

Discovery is hard enough.
Expressing it shouldn’t be.

You know the evening we mean. The analysis is done and the result is real. What remains is a legend that covers the last point, a label one size too small, a panel a millimetre out of line — and a script you run again, and again, to fix them.

Tavotto is an open-source editor for that last stretch. It opens the figure your script drew and lets you shape it directly, while the script stays the source and the data stays exactly as it was measured.

We build it in the open, carefully, and we would like to keep doing so. This letter explains why, and asks for your help.

With respect for the work you do,
[Name of the maintainer], for the Tavotto project
