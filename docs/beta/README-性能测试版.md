# Tavotto Beta 0.18.1b1（首跑体验预览版）安装与使用

这是一个**测试版**，用来试「把一个只有脚本的项目第一次跑出图」这条新流程。它和你电脑上的正式版
Tavotto 是两个独立的应用，可以同时装着，互不覆盖；项目和设置是共用的。

本版 = 正式版 **0.18.0** + 「首跑体验收敛」T01～T12 这一批还没合进正式版的改动
（分支 `feat/onboarding-convergence` @ `b47522224`）。

## 能不能用

**Mac**
- 需要 **Apple 芯片的 Mac**（M1 / M2 / M3 / M4 …）。Intel 芯片的 Mac 打不开这个包。
  看法：左上角  → 关于本机 →「芯片」一行。
- **macOS 14（Sonoma）或更新**。

**Windows / Linux**：这一版**没有**提供。

## 安装（Mac）

1. 双击 `Tavotto-Beta-0.18.1b1-arm64.dmg`，把 **Tavotto Beta** 拖进「应用程序」。
2. 第一次打开会被系统拦下（这个测试版只有临时签名，没有经过 Apple 公证）。任选一种放行：
   - **方法 A**：打开「系统设置 → 隐私与安全性」，往下翻，看到「已阻止使用 Tavotto Beta」，
     点 **仍要打开**，输入开机密码。
   - **方法 B**（如果提示「已损坏，无法打开」）：打开「终端」，粘贴下面这一行后回车，然后再双击打开：

     ```
     xattr -dr com.apple.quarantine "/Applications/Tavotto Beta.app"
     ```

   只需要放行这一次。
3. 它**不会自动更新**。测完直接拖进废纸篓。

## 这一版多了什么（请帮忙试）

下面这些都**只在浏览器和自动测试里验证过**，没有在打出来的桌面应用里逐项点过；哪一步不对都告诉我们。
建议用一份**项目副本**来试。

1. **导入即检查，不运行任何东西**（T01/T02）：打开一个项目文件夹时，Tavotto 只读地扫一遍有哪些脚本、
   哪些图，**不执行**你的脚本；画布上方出现一条检查条，告诉你哪些脚本还没跑过、可以从哪里开始。
2. **准备面板**（T09/T09b）：从检查条或脚本库开始第一次运行时，会打开准备面板，一步一步列出
   这个脚本第一次跑起来还缺什么（运行目录、参数、Python 环境、缺的包），每一步都要你确认后才做。
   原来的接入中心也搬进了这个面板。
3. **脚本的命令行参数**（T03/T07）：用 `argparse` 的脚本可以在面板里按表单填参数，也可以直接粘贴
   你平时在终端里敲的那一整行命令。填的参数会跟着这张图走：之后编辑、重开、导出都用同一组参数重放，
   不会退回成「不带参数」。同一个脚本用两组参数跑出来的同名图是两张，不会互相覆盖。
4. **选 Python 环境**（T05）：项目里有 `.venv` 之类的环境时，面板会推荐它，但**要你点确认才采用**；
   也可以手选别的。选了之后真的用那个环境跑。
5. **缺包一次装齐**（T06）：缺好几个包时，给你一份清单、确认一次；包装进 Tavotto 自己管理的环境，
   **不改你自己的 Python 环境**。装失败时保留原来的环境。
6. **脚本里的 `input()`**（T08）：运行中遇到 `input()` 会在面板里问你；回答按「这个脚本 + 这组参数」
   记住，之后重放 / 导出不再重复问。`getpass` 的输入是掩码，不落盘。
7. **出错时的诊断**（T04）：某次运行或导出失败时，可以取到**这一次失败**的脱敏诊断（不含你的数据、
   口令），之后成功重试也不会覆盖它。
8. **Codex / MCP 插件**（T10）：插件和桌面应用用同一份参数与环境选择；只有脚本、还没跑过的项目，
   插件会提示你回到桌面应用里完成第一次运行（插件本身不做首跑）。

## 已知问题

- **进入编辑时面板会挡住元素树**：第一次跑完、进入编辑时，如果准备面板里的「参数详情」还展开着，
  面板会占满整个窗口高度，左边的元素树被压到点不到。**绕法**：先把准备面板关掉。
- **验证范围有限**：以上功能只在 macOS（Apple 芯片）上的浏览器和自动测试里验证过；
  Windows、Linux、WebKit（Safari 内核）、打包后的桌面应用里的准备面板首跑、真实云盘占位文件、
  真实私有 pip 源、联网安装真实包、与旧版本插件 / 引擎混用都**没有验证**。
- 打开项目时仍会在项目里写一份 `tavotto_registry.json`（记录静态图名），这是原有行为。
- 插件 / MCP 不支持「只有脚本的项目第一次运行」，会给出待办引导回桌面应用。
- 参数表单里，`append` / 多值（`*`、`+`）类参数只读，要改请用「粘贴命令」；没有文件 / 列内容预览。
- 「已存在的输出文件会被覆盖」目前在界面上没有专门的提示。
- 应用重启后，正在进行的准备步骤不会自动续跑，需要再点一次「运行」。
