# Tavotto beta 0.19.3b2（图标微动效预览版）安装与使用

这是一个**测试版**，用来看界面图标的微动效（点按钮、指针移上去、提示出现时图标动一下）。它和你电脑上的
正式版 Tavotto 是两个独立的应用，可以同时装着，互不覆盖。**beta 与正式版的设置、最近项目和数据目录不共享**：
beta 用自己的 `Tavotto Beta` 目录（Mac：`~/Library/Application Support/Tavotto Beta`；
Windows：`%APPDATA%\Tavotto Beta` 与 `%LOCALAPPDATA%\Tavotto Beta`），
测试不会改动正式版的设置。装过 0.18.1b 系列 beta 的话，这个目录会沿用下来。

本版 = 当前 main（`84951824d`，即 v0.19.2 待发版的内容）+ 图标微动效（PR #1548，未合入）+ beta 打包类提交。

## 能不能用

- **Mac**：需要 **Apple 芯片**（M1 / M2 / M3 / M4 …），**macOS 14（Sonoma）或更新**。
- **Windows**：64 位 Windows 10 / 11，不需要事先装 Python。
- Linux 这一版没有提供。

## 安装（Mac）

1. 双击 `Tavotto-beta-0.19.3b2-arm64.dmg`，把 **Tavotto beta** 拖进「应用程序」。
2. 第一次打开会被系统拦下（只有临时签名，没有经过 Apple 公证）。任选一种放行：
   - **方法 A**：「系统设置 → 隐私与安全性」，往下翻到「已阻止使用 Tavotto beta」，点 **仍要打开**。
   - **方法 B**（提示「已损坏，无法打开」时）：在「终端」里粘贴下面这行回车，再双击打开：

     ```
     xattr -dr com.apple.quarantine "/Applications/Tavotto beta.app"
     ```
3. 它**不会自动更新**。测完直接拖进废纸篓。

## 安装（Windows）

1. 双击 `Tavotto beta_0.19.3-beta.2_x64-setup.exe`。
2. 这个测试版**没有代码签名**，SmartScreen 会弹「Windows 已保护你的电脑」：点 **更多信息** → **仍要运行**。
3. 按向导装完即可，不需要管理员权限（装在你自己的用户目录下）。开始菜单里叫 **Tavotto beta**。
   卸载：设置 → 应用 → 已安装的应用 → Tavotto beta → 卸载。
4. 和 Mac 一样：与正式版并排安装、不自动更新，设置和数据与正式版分开。

## 相比 0.19.3b1 改了什么

- 左轨的项目、图内、样式、问题、准备，右上角联系作者，画布底部工具胶囊里的 8 个工具（选择、文字、箭头、矩形、椭圆、直线、形状、子图标签），保存状态和提示灯泡，也都有动作了。左轨当前选中的那颗一样会动。
- 按钮里没有自己点击动作的图标，点的时候会轻轻按下去再弹回来。

## 这一版要看什么：图标微动效

动作都只播一次（0.4～0.7 秒）、播完回到原图标；系统开了「减少动态效果」时一律不动；画布和图本身不动。

- **点一下按钮时**：运行（三角轻推）、重新运行（转一圈）、还原（逆时针一圈）、导出（箭头落进托盘）、导入（箭头上升）、
  复制（前卡探出；复制成功后的勾一笔画出）、撤销 / 重做（回摆）、删除（掀盖）、改图助手（星星转半圈、小星闪）、新建（＋转 90°）、
  编辑（笔尖写两下）、保存排版（下半格按下）、外部打开（箭头探出）、裁剪（两角往里收）、编组 / 取消编组（两块靠拢 / 分开）、
  放大面板（箭头往外推）、固定（图钉按下）、链接（两半分开再扣上）、显示 / 隐藏（眨眼，隐藏时斜线画出）、锁定 / 解锁（锁扣落下 / 弹起）。
- **指针移到按钮上时**：左轨的排版（四格依次缩放）、素材（两张图错开）、图层（顶层抬起）、属性（旋钮来回滑）、历史版本（表针倒转）、
  搜索（四处看看）、设置（转 60°）；还有图类型里的折线 / 散点 / 柱状、行尾「⋯」（三点依次跳）、修复（扳手拧一下）、
  关闭 ×（转 90°）、继续 →（箭头穿出再回来）。
- **提示出现时**：说明条与状态提示里的完成（画勾）、警告（轻摇）、失败（摇头）、提示（点落下）；准备卡的状态图标；导出核验通过。

请帮忙看：有没有哪个动作**太多 / 太慢 / 太显眼**，或者在 14 px 的小图标上**看着糊**；左轨划过去时会不会觉得一直在动。
