# Tavotto beta 0.19.3b3（界面审计第一批验收版）安装与使用

这是一个**测试版**，用来验收 10-31 界面审计里已采纳的第一批改动（5 个 PR，都还没合进 main）。
它和你电脑上的正式版 Tavotto 是两个独立的应用，可以同时装着，互不覆盖。**beta 与正式版的设置、最近项目和数据目录不共享**：
beta 用自己的 `Tavotto Beta` 目录（Mac：`~/Library/Application Support/Tavotto Beta`；
Windows：`%APPDATA%\Tavotto Beta` 与 `%LOCALAPPDATA%\Tavotto Beta`），
测试不会改动正式版的设置。

本版 = beta 0.19.3b2（main `84951824d` + 图标微动效 #1548 + 时间线版本竖线条）
+ #1557 #1552 #1556 #1555 #1554 + beta 打包类提交。

## 能不能用

- **Mac**：需要 **Apple 芯片**（M1 / M2 / M3 / M4 …），**macOS 14（Sonoma）或更新**。
- **Windows**：64 位 Windows 10 / 11，不需要事先装 Python。
- Linux 这一版没有提供。

## 安装（Mac）

1. 双击 `Tavotto-beta-0.19.3b3-arm64.dmg`，把 **Tavotto beta** 拖进「应用程序」（会替换掉旧的 beta）。
2. 第一次打开会被系统拦下（只有临时签名，没有经过 Apple 公证）。任选一种放行：
   - **方法 A**：「系统设置 → 隐私与安全性」，往下翻到「已阻止使用 Tavotto beta」，点 **仍要打开**。
   - **方法 B**（提示「已损坏，无法打开」时）：在「终端」里粘贴下面这行回车，再双击打开：

     ```
     xattr -dr com.apple.quarantine "/Applications/Tavotto beta.app"
     ```
3. 它**不会自动更新**。测完直接拖进废纸篓。

## 安装（Windows）

1. 双击 `Tavotto beta_0.19.3-beta.3_x64-setup.exe`。
2. 这个测试版**没有代码签名**，SmartScreen 会弹「Windows 已保护你的电脑」：点 **更多信息** → **仍要运行**。
3. 按向导装完即可，不需要管理员权限。开始菜单里叫 **Tavotto beta**。

## 这一版要验收什么

每条写了怎么试、应该看到什么。示例项目可以用欢迎页的「试用示例」，或任意含 2–3 张图的项目。

### 画布（#1557）

- **B1 新图不叠旧图**：在素材里依次对三张图按 ⇧Enter（或点卡片右上角 +）加进同一张画布。
  应看到：三张图互不重叠。页面放不下时后加的图会**等比缩小**（最小到 40%）去塞进空位，第一张仍居中。
  请特别看：第二、三张被缩到约 60% 你能不能接受——如果更想要「第一张放左上、后面的保持原大」，告诉我，这要改一条现有约定。
- **B6 提示条**：打开导出、⌘K、联系作者时，底部「已加入画布 / 操作提示」类的胶囊不再浮在遮罩上；「已导出 · 在 Finder 中显示」这类结果仍压在对话框上（这是原有约定）。
  平时不再冒「渲染完成」；只有之前出过失败、这次修好了才提示。空画布上不再弹「左侧『问题』可定位…」。
  双击素材打开到新画布时，提示写「已在新画布「图名」里打开」，按钮是「撤销」。
- **B7**：右栏切到「画布」页时，不再出现「可在右侧『画布』页调整 · 打开画布页」那条说明。
- **D4 焦点环**：用鼠标点左轨、选中图按 Enter 进图内编辑、开关「新排版 ▾」菜单，都不应再出现粗蓝框；
  **按 Tab 键导航时蓝框必须照常出现**（这一条请务必在 Mac 和 Windows 各试一次）。

### 读得清（#1552）

- **C1 字号**：右栏属性的标签与数值、左侧图内元素树、图层、问题面板的对象名，从 11–12px 提到 13px。
  看：默认栏宽下有没有标签被截断或折行难看；属性栏里的灰色说明字仍是小号。
- **C2 元素树**：标题 / 轴标题 / 曲线这些叶子行变成正文黑色，「文字」「数据系列」这类分组行变灰、不加粗；内容外面的中文引号去掉。「子图」名字不变。

### 菜单与引导（#1556）

- **D2 「⋯」菜单**：分成「文件 / 视图 / 帮助」三组；「写回原始文件」不可用时原因在悬停提示里；顶栏「新手教程」胶囊还在时菜单里没有「开始教程」。
- **D3 ⌘K**：快捷键是一整颗键帽（⌘A），「添加 (a)(b)(c) 标签」改叫「添加序号 (a)(b)(c)」。
- **E2 设置 › 通用**：「界面乱了？」改成「重置界面布局」；外观说明改写；「打开画布设置」那行删掉。
- **F1 欢迎页**（新装或清空 beta 数据目录后看）：标题没有「:)」；下面是一句灰字，不再像能点的链接。
- **F2 新手教程**：只在顶部显示进度；第 1 步左上角是「返回欢迎页」；没做完时按钮写「拖入脚本后继续」等。

### 对话框（#1555）

- **E1 导出**：标题下只有「图名 · 尺寸」，裁边差异在尺寸旁的 ⓘ；「位置」显示「项目名 / 相对路径」，悬停看完整路径；
  「严格核验产物」「生成样式检查报告」收进「高级」（已开着时会自动展开）；预览图不再上下留大片灰。计数仍是「N 项要改 / N 项留意」。
- **E3 联系作者**：页脚左「我的来信」、右「关闭 / 发送」；「企业微信」在标题下一行；附件是「添加截图/文件」按钮，拖文件进对话框也行。顶栏按钮位置不变。

### 布局（#1554）

- **B4 左栏**：窗口 ≥1280 宽、新装（或没在设置里动过「固定左侧栏」）时，左栏默认固定，连续加图不收起。
  老用户以前存下的「不固定」不会被改掉。
- **G1 窄窗口**：把窗口拖到 1100 左右宽：右栏不再挤画布，选中对象时从右侧浮出，点画布空白或按 Esc 收回；
  窗口 <1180 时左轨只剩图标，悬停看名字。设置里固定了属性栏的话照旧占位。Windows 笔记本 1366×768 @125% 请重点试。
- **C5 改图助手**：画布上只有一张可编辑的图、什么都没选时，打开改图助手就能直接输入，目标自动是这张图；多张图时空态列出图名，点一下选中。

仍然包含 b2 的时间线版本竖线条和 b1 的图标微动效。
