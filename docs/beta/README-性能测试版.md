# Tavotto Beta（性能测试版）安装与使用

这是一个**测试版**，只用来帮我们找出「拖动时一卡一卡」的原因。它和你电脑上的正式版
Tavotto 是两个独立的应用，可以同时装着，互不覆盖；项目和设置是共用的。

## 能不能用

- 需要 **Apple 芯片的 Mac**（M1 / M2 / M3 / M4 …）。Intel 芯片的 Mac 暂时打不开这个包。
  看法：左上角  → 关于本机 →「芯片」一行。
- macOS 11 或更新。

## 安装

1. 双击 `Tavotto Beta_…dmg`，把 **Tavotto Beta** 拖进「应用程序」。
2. 第一次打开会被系统拦下（这个测试版没有经过 Apple 公证）。任选一种放行：
   - **方法 A**：打开「系统设置 → 隐私与安全性」，往下翻，看到「已阻止使用 Tavotto Beta」，
     点 **仍要打开**，输入开机密码。
   - **方法 B**（如果提示「已损坏，无法打开」）：打开「终端」，粘贴下面这一行后回车，然后再双击打开：

     ```
     xattr -dr com.apple.quarantine "/Applications/Tavotto Beta.app"
     ```

   只需要放行这一次。
3. 这个测试版**不会自动更新**。测完可以直接把它拖进废纸篓。

## 这一版多了什么

- **字体下拉不再跟着属性页重画**：上一版里每次拖完松手，属性页会把几百个字体选项整个重建一遍，
  这是「松手那一下顿住」的主要来源之一。这一版应当明显轻快一些。
- **新的 PDF / 图片后端（RenderCore）**：素材预览、导出 PDF / PNG / TIFF 都换成了新后端。
  这部分请顺手试一下导出（见下面第 7 步），有任何报错或导出结果看起来不对都告诉我们。

## 录一份性能报告（约 5 分钟）

0. **先关掉低电量模式**（系统设置 → 电池 → 低电量模式 →「永不」）。开着它整个界面只有 30 帧。
1. 打开**你平时觉得卡的那份项目 / 那张图**，**先等它渲染出来**（装好后第一次打开图会慢十几秒，
   那是在建字体缓存，只发生一次；等它完了再开始录）。
2. 设置 → 诊断 → 性能分析 → **开始**。画布右上角会出现「性能分析」面板。
3. 先别动鼠标，等 2 秒。
4. **照常拖动并松手**：标题、图例、坐标轴标签、子图都行，每样拖几次、**每次都松手**。
5. 点 **自动测试**，再点一下你觉得最卡的那个对象。接下来约 7 秒**不要动鼠标**
   （它会自己拖两轮然后撤回，**不会改动你的图**）。
6. 点 **完成并保存**。访达会弹出来并选中报告文件（`tavotto-perf-….json`），把它发给我们。
7. **试一下导出**（新后端）：顶栏「导出」，分别导一次 **PDF** 和 **PNG**。告诉我们：
   大概等了几秒、导出的文件打开看着对不对（文字、图、清晰度）。出错的话，设置 → 诊断 →
   「导出诊断包」，把那个 zip 也发给我们。

报告里只有数字：帧耗时、次数、节点数、电脑型号 / 内存 / 电源状态。**没有**文件名、图里的文字、
脚本或路径。可以用「文本编辑」打开检查。

如果方便，也请告诉我们那张图大概是什么内容（几条线、每条大概多少个点、有没有散点 / 填充 / 公式），
这能帮我们在本地复现。
