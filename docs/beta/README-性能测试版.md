# Tavotto beta 0.19.0b3（渐进式编辑预览版）安装与使用

这是一个**测试版**，用来试「默认直接编辑一张图、需要时再进入排版与出版」这条渐进式流程。它和你电脑上的
正式版 Tavotto 是两个独立的应用，可以同时装着，互不覆盖。**beta 与正式版的设置、最近项目和数据目录不共享**：
beta 用自己的 `Tavotto Beta` 目录（Mac：`~/Library/Application Support/Tavotto Beta`；
Windows：`%APPDATA%\Tavotto Beta` 与 `%LOCALAPPDATA%\Tavotto Beta`），
测试不会改动正式版的设置。装过 0.18.1b 系列 beta 的话，这个目录会沿用下来。

本版 = 当前 main（`1e29aa1f1`，渐进式编辑包 P01～P06 + beta 0.19.0b1 / b2 反馈修复全部合入）+ beta 打包类提交。
P07（智能重排版）只做了设计，**不在这一版里**。

## 能不能用

- **Mac**：需要 **Apple 芯片**（M1 / M2 / M3 / M4 …），**macOS 14（Sonoma）或更新**。
- **Windows**：64 位 Windows 10 / 11，不需要事先装 Python。
- Linux 这一版没有提供。

## 安装（Mac）

1. 双击 `Tavotto-beta-0.19.0b3-arm64.dmg`，把 **Tavotto beta** 拖进「应用程序」。
2. 第一次打开会被系统拦下（只有临时签名，没有经过 Apple 公证）。任选一种放行：
   - **方法 A**：「系统设置 → 隐私与安全性」，往下翻到「已阻止使用 Tavotto beta」，点 **仍要打开**。
   - **方法 B**（提示「已损坏，无法打开」时）：在「终端」里粘贴下面这行回车，再双击打开：

     ```
     xattr -dr com.apple.quarantine "/Applications/Tavotto beta.app"
     ```
3. 它**不会自动更新**。测完直接拖进废纸篓。

## 安装（Windows）

1. 双击 `Tavotto beta_0.19.0-beta.3_x64-setup.exe`。
2. 这个测试版**没有代码签名**，SmartScreen 会弹「Windows 已保护你的电脑」：点 **更多信息** → **仍要运行**。
3. 按向导装完即可，不需要管理员权限（装在你自己的用户目录下）。开始菜单里叫 **Tavotto beta**。
   卸载：设置 → 应用 → 已安装的应用 → Tavotto beta → 卸载。
4. 和 Mac 一样：与正式版并排安装、不自动更新，设置和数据与正式版分开。

## 相比 0.19.0b2 改了什么（请帮忙复测）

- **单图 / 排版自动切换**：画布上只有一张图时就是单图编辑，第二张图进来才进入多图排版。
- **拖页面四边改画布**：读数改成机械制图式尺寸标注——画布里的箭头尺寸线，数字在尺寸线中间、没有白底，不再跳动、不压标尺。
- **右栏页签**：改成分段按钮组，间距更大、不容易点错。
- **改图助手的模型选择**：先选厂商（Claude / Codex，带图标）再选具体型号；Codex 能看到全部可用模型，Claude 显示具体型号（如 Opus 5.5），并可选思考强度。
- **顶栏保存状态**：硬盘图标旁常驻「已保存 / 未保存」短字，点一下就保存。
- **设置 →「支持 Tavotto」**：桌面版点了能打开网页了；按钮换成红色实心爱心。
- **新手教程**：拖入示例脚本后的渲染动画最长 1.5 秒；示例图的图例缩小、上移，但仍故意压着曲线，留给你在教程里拖开。
- **属性栏**：去掉了「N 个问题」标签；上下文栏胶囊右侧留出呼吸空间。
- **捕获结果**：列表里每项带缩略图。

## 0.19.0b2 已有的修复（沿用）

- **首页**：最近项目卡片在旧版 WebKit 下不再溢出；首页随窗口宽度自适应；指针图标居中。
- **反馈对话框**：勾选不再卡住；复选框挪到文字外侧并加「一键全选」；诊断区顺序调整。
- **新手教程**：欢迎页留白调整；「修改文字」气泡不再压住文字。
- **排版时间线**：改为右栏页签；预览按显示宽度 × 屏幕 DPR 取图，不再发糊。
- **吸附对齐**：更近的那条线足够近时，让位给它（不再被远处的线抢走）。
- **SVG 导出默认保留可编辑文字**：Word 里「转换为形状」后可以直接改字。已知限制：含公式的文字转换后会碎成多段。

## 0.19 渐进式编辑相比 0.18 多了什么（沿用自 b1，请帮忙试）

1. **三步新手教程**：第一次打开有欢迎页 → 拖入示例脚本 → 拖动图例 → 改标题字号 → 前后对比。
2. **快编只有一个出口**：快编上方的上下文栏只剩一个按钮——从排版进来的写「← 返回排版」，
   从素材库直接打开的写「排版与出版 →」；按 **Esc** 也是同一个动作。原来近义的「添加到画布」去掉了。
3. **第一次回到排版时的说明**：右栏页签条下会出现一条不挡操作的说明——「纸面就是导出的 Figure 尺寸」。
4. **单栏 / 双栏页面预设**：宽度改读当前出版规范（不同期刊不一样），不再一律 85 mm。
5. **按原图导出的检查**：按原图导出时，出版预检按原图本身的尺寸算，不会再被画布上的缩放误判。
6. **导出对话框说清楚**：对象头写出将要生成的文件名与格式；检查行点名查的是哪一份产物；
   没查出问题时说「按「规范」未发现问题」并写明覆盖范围，不再笼统说「检查通过」。
7. **属性面板小调整**：图例条目的「链接」挪到前面；背景细项收进一行摘要；箭头的位置与尺寸默认折叠。

**建议的试法**：用教程里的示例，或打开一个已有项目 → 直接改一张图 → 点「排版与出版 →」把它放上页面 →
切换单栏 / 双栏预设 → 来回进出快编几次（留意图有没有被改动）→ 导出 PDF / PNG，看对话框说的和实际文件是否一致。

## 已知问题

- **验证范围**：新流程只在浏览器自动测试里验证过（Chromium 中 / 英文、WebKit）；打包后的桌面应用（Mac / Windows）**没有实际点过**；Windows 包只在 CI 上做过静默安装、后端冒烟与卸载。
- 英文界面的「Layout & export」叫法、「从素材库打开一张已在排版上的图算『返回』」、快编里显示 Esc 键帽，这三处还待确认。
- 工具认不出来的图元，导出检查不会把它列为「查不了」。
- 教程的拖放步骤没有在真机上测过。
- SVG 里的公式文字，在 Word「转换为形状」后会碎片化（已知限制）。
