The Windows app now **ships its own Python rendering runtime** — install Magplot,
open a project, render: no Python setup, no first-run download. This release also
lands a large round of canvas and engine fixes from a full interaction audit:
copying no longer crashes, undo steps back reliably, and thin lines are finally
easy to select.

## Added

**Windows: the installer bundles a private rendering environment.** Previously,
in-figure editing needed a Python with matplotlib on your machine. The Windows
installer (and the portable zip) now carry an isolated CPython + scientific stack
used only by Magplot. Your own Python installs — if any — are untouched, and
pointing Magplot at your own environment still takes priority when your scripts
need extra packages. If the bundled runtime is missing or damaged, Magplot now
says "the installation is incomplete, please reinstall" instead of wrongly asking
you to install Python.

**One-click diagnostics bundle.** Settings → Privacy, diagnostics and About can
now export a single file with versions, install method, rendering interpreter,
AI CLI detection and recent errors — API keys and personal paths are redacted
before anything is written, so it is safe to attach to an issue.

**Script registry tools.** The static scanner now understands f-strings,
`Path(...)` arithmetic, `os.path.join`, constants and cross-function calls when
finding your figure names, and recurses into subdirectories. For scripts whose
output names are only known at runtime, a new dry-run probe runs the script once
and registers what it actually saves. Both are available from the project menu
and Settings → Script registry.

**AI assistants: third-party API endpoints.** Point the claude or codex CLI at a
custom base URL and key from Magplot's settings. Credentials are injected only
into the processes Magplot spawns — your `~/.claude` and `~/.codex` configuration
files are never modified.

**Superscript / subscript shortcuts.** In canvas text, ⌘/Ctrl+↑ and ⌘/Ctrl+↓
toggle superscript and subscript, and exports reproduce the exact glyph size and
baseline.

## Fixed

**Copying an object crashed the editor — every time.** Symptom: duplicate or
copy/paste on the canvas froze the app with a console error.

**Undo sometimes stepped back less than one action.** After edits that touched
the same property repeatedly (dragging, typing), one undo could revert only the
last frame instead of the whole action.

**Arrows and thin lines were nearly impossible to select.** Clicking now works
anywhere within 8 px of the segment, not just on the drawn pixels. Rotated
objects also got correct handles: they follow the rotation, and resizing keeps
the opposite corner anchored.

**A hung render no longer blocks the panel forever.** Workers that stop
responding are killed and reported; the render cache now prunes itself under a
disk budget instead of growing without bound.

**Autosave races between browser tabs.** Saves are queued per document, editing
the same document from two tabs shows a warning, and a stale save can no longer
silently overwrite newer work.

**Long unbroken words overflowed exported panels.** Text that had nowhere to
break (URLs, chemical names) now wraps character-by-character in the PDF export,
matching what the canvas shows.

**Windows polish.** Black console windows no longer flash when Magplot probes
environments or runs AI assistants; subprocess text is pinned to UTF-8, fixing
garbled output on Chinese-locale (cp936) systems; and the store-installed codex
CLI is now found via its Windows execution alias.
