## Name your groups in the layers list

Groups in the layers list can now have names. Double-click a group (or press F2) to rename it in place; Enter keeps the name, Esc cancels, and clearing it goes back to "Group · N objects". The name also shows on the bar while you edit inside the group, groups the assistant creates keep the names it gives them, and exported SVGs carry the names so they appear as named groups in Illustrator.
