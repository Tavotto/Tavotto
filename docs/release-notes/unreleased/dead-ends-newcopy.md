## Three more dead-end messages now have a button

When a figure handed over from your editor has not been run yet, the message now has a “Run” button: it runs the figure’s script and then puts the figure on the canvas. When the figure you are editing loses its script, the message now offers “Relink script”, which opens the project status page on that figure. When a project fails to open or be created, the message now names the project: if the folder cannot be found, “Choose folder again” opens the folder picker (the project stays in your recent list, so an unplugged drive is not forgotten); a failed creation says so on its own and offers “Try again”, as does any other open failure, followed by “Send problem report” if it fails a second time. The “copy” button on that message copies the sentence plus the original error text, so you can send it to us.

Message pills at the bottom of the window now grow with their sentence (up to 560 px) instead of cutting it off at 360 px.
