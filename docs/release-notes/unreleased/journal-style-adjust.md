## Adjust a figure's style to the journal in one step

When a project is checked against a journal and the figures on the canvas use font sizes, fonts or
line widths the journal does not allow, the Style panel now shows a line such as "4 not matching
Nature Chemistry" with an "Adjust to journal" button. Hovering lists each change (for example
"Ticks size 8 → 7 pt"). One click raises sizes below the journal's minimum, lowers sizes above its
maximum, thickens lines below its minimum width and switches to a font the journal accepts when one
is installed. If the canvas follows a style, that style is updated; otherwise a new style named
after the journal is created and followed. One undo reverts it.
