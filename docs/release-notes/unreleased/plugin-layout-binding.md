## Codex and Claude Code now start from what you did in Tavotto

When a figure sits in one of your Tavotto layouts, the Tavotto plugin now opens it on that layout's panel, so the agent sees the in-figure edits you already made there instead of starting from a blank slate. If you change the panel in Tavotto while the agent is working, it picks up your changes on its next step and says so. If the same figure sits in several panels the agent asks which one, and elements you've locked are left alone.
