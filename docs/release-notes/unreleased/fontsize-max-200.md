## Font sizes can now go up to 200 pt

The font size boxes in the property panel used to stop at 24 pt for tick labels, legends and colorbar ticks, 36 pt for other figure text, 96 pt for canvas text boxes and 72 pt in style presets. Because the panel shows sizes as they appear on the page, the limit shrank with the figure: in a figure scaled to about 72%, typing 20 pt for tick labels snapped back to 17.36. All of these now go up to 200 pt.
