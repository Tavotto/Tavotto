## The spec page no longer shows default numbers under a journal

When a project is checked against a journal, Settings › Journal spec showed the journal's column
widths at the top but the default spec's 80 / 150 mm further down, so it looked like two sets of
rules were in force. The spec library now opens on the journal itself and lists the values the
project is actually checked against; anything the journal does not specify reads "Not specified"
followed by the value used instead. "Duplicate to edit" copies the journal's rules into a spec you
can change. Switching from the journal to another spec now asks first instead of silently dropping
the journal.
