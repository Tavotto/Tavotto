## Layout: dragging a figure's edge inward now resizes it too

In a multi-figure layout, dragging an uncropped figure's edge inward used to crop it and stopped at the content edge, so a figure could only get bigger. Dragging inward now re-renders the figure at the smaller size with the same text size, just like dragging outward. If the text no longer fits, a notice offers to scale the text down just enough to fit the frame. Hold ⌥ (Alt) while dragging an edge to crop instead.
