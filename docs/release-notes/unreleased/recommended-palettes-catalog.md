## Licence notices for the upcoming recommended colour schemes

Tavotto now ships the colour values for its upcoming recommended colour schemes (still off by default, so nothing changes on screen yet): Okabe–Ito, Paul Tol's schemes, four ColorBrewer sets, Fabio Crameri's categorical scientific colour maps, and journal-style sets from the ggsci package. `THIRD_PARTY_NOTICES.md` lists each source with its licence and requested citation. The journal-style sets are GPL-3.0 and kept in a separate file; builds that set `TAVOTTO_NO_COPYLEFT_PALETTES=1` leave them out.
