## Open a Jupyter notebook like a script

A `.ipynb` file no longer dead-ends. Drop one on the home screen or on the canvas, or press the new "Turn into a script and run" button on a notebook listed under "Jupyter notebooks" in the script list, and Tavotto turns the notebook's code into a plain `.py` next to it and runs that. Markdown cells are kept as comments, and notebook-only commands such as `%matplotlib inline` or `!pip install ...` are commented out with their original text kept. Nothing is executed during the conversion and nothing leaves your machine. Your notebook is never changed, and a `.py` of the same name that you wrote or edited is never overwritten (the new copy gets "(notebook)" in its name instead). If a notebook cannot be converted (very old format, no code, something Tavotto cannot read), it says why in one sentence with a button to send feedback.
