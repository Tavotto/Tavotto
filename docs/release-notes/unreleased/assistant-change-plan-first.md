## The assistant shows a change plan before it edits, and one-click layout shows a preview first

When you ask the assistant to change a single figure, it now first looks for changes it can make inside the figure (colours, sizes, positions, text, what is shown) and sends back a card with the revised figure. Open it to compare before and after, untick anything you don't want, and apply it in one step — ⌘Z undoes it. If the whole request needs the script, it goes straight to the Agent as before; if only part of it does, the card says so and offers **Edit the script for the rest**. One-click layout works the same way: the result opens as a before/after comparison, and **Apply** does the layout in one undoable step. Your instruction and the figure's list of editable elements go to the AI connection you picked; scripts and data are not sent in the plan step. To go back to the old behaviour, set `ai.change_plan.enabled` to `false` in the settings file.
