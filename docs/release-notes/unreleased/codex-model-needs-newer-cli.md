## Picking a model your Codex is too old for now tells you to update it

When the Codex desktop app updates first, it adds newer models to the model list Tavotto shows, but the Codex command Tavotto runs may still be an older version that rejects them, so the assistant failed with a 404. Tavotto now compares the two versions. If the Codex it uses is older, the last row of the ChatGPT model menu reads "Update Codex", and a 404 failure card offers the same button. Updating switches to a newer Codex already on your computer (such as the one bundled with the desktop app), or installs one inside Tavotto. When neither is possible, the menu row is greyed out and says how to update, and the failure card offers to switch back to your default model, with the update command under "Details". Separately, when Codex fails because your sign-in expired or you ran out of quota, the failure card now says so and shows "Check connection". Before, it only said "Failed".
