## Connecting an AI editor now installs the Tavotto skill

Connecting Claude Code, Cursor, VS Code, Trae, ZCode, WorkBuddy or Antigravity from Settings now also copies the Tavotto skill into that editor's user folder, so its AI gets the same usage guide as Codex. Disconnecting removes the copy, and a copy you edited is left alone. Claude Desktop has no skill folder, so its AI reads the guide through a new `tavotto_guide` tool.
