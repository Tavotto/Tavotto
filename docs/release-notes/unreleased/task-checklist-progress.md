## Repair progress shows every step instead of a progress bar

While Tavotto prepares a Python environment (one-click repair on a script row, the "Prepare environment" dialog before a run, or the automatic switch to a supported Python version), the card now lists every step up front — prepare Python, create the environment, install the packages, run again — and ticks them off as they finish. The step in progress shows a spinner and, while Python downloads, the downloaded size. The list keeps the same height from start to finish, and you can fold it with the arrow.
