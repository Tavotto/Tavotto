## The first-launch usage-sharing question is easier to read

**The anonymous-usage prompt no longer opens with two blocks of bullet lists.**
Trigger: first launch, or being asked again after the data description
changed. Before: the dialog showed "What is sent" and "What is never sent"
side by side, which read like a legal notice. Now it opens with an
illustration and two plain sentences (only anonymous usage records are sent; your
figures, scripts, data and file names are never sent). The full lists
are one click away under "What exactly is sent". "Not now" and "Share
anonymously" are still two same-sized buttons on one row, and "Not now" is
remembered and not asked again.
