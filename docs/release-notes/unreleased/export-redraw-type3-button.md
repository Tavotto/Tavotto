## Redraw Type 3 figures straight from the export result

When an export result warns that the PDF uses Type 3 fonts and the cause is a PDF figure that has its script and no edits, the warning now has a "Redraw with its script and export again" button. It does the same thing as the canvas badge: the figure is redrawn by its script in one undoable step, then the export runs again. Exports still embed the original file unless you press it.
