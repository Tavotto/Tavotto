## Checks flag bar charts whose base is cut off

When bars on a linear axis start at a value the axis no longer shows, for example bars from 0 with the y axis set to 4–9, bar lengths stop matching the values. The problem list now says so in one line, such as "The bars start at 0, but the vertical axis only shows 4 to 9, so bar lengths no longer match the values". Horizontal bars and histograms are checked the same way. Floating bars, Gantt-style bars and the upper layers of stacked bars have no common base and are not checked, difference bars with 0 in view are fine, and bars on log, symlog or logit axes are left alone. It also appears when you cut the base off in the inspector, and goes away when you undo. Tavotto does not change anything for you: starting the axis at 0 or switching to a dot plot is your decision.
