## Agents can edit the points of a path

In the plugin, the agent can now edit a path point by point, the same way you do with Direct Selection: move points or drag their handles, add, delete or convert points between smooth and corner, cut a path at a point, join two ends or two paths, average points, reverse a path's direction, and make or release a compound path. It sees each path's points with their positions on the page, says which points changed and how many there are afterwards, and every edit can be undone in one step.
