## Your agent's suggestions show up in the assistant panel

When an agent connected through the Codex or Claude Code plugin suggests changes to a figure that is open in a Tavotto layout, the same tick-box to-do card now appears in the assistant panel, marked "From your agent". Tick what you want and press the button: the figure changes are made in the document in one step you can undo with ⌘Z, and the items that need a script change are handed back to your agent. The card only appears while the figure still matches what the agent looked at, and you can dismiss it.
