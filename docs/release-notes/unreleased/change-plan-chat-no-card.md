## Chatting or asking a question in the assistant no longer shows a "couldn't change the figure" card

With "show me a change plan first" turned on, a plain greeting or question (for example "which font is this figure using?") now goes straight to the assistant for an answer, instead of ending in a failed plan card. No plan card or script-editing checklist flashes up first: until the assistant knows what you asked for, it just shows that it is thinking.
