## Save failures now come with a button

When a save does not go through, the message under the canvas now has a button instead of leaving you to work it out. A failed save (Cmd/Ctrl+S, autosave, or saving into the project) offers “Retry save”. If another window or an outside edit got there first, it offers “Reload”, which brings back the newer version and keeps your edits as a recovery copy. If the same layout is open in two windows, it offers “Save as…” so each window can have its own copy. A style change that could not be saved offers “Try again” with the value you just typed.
