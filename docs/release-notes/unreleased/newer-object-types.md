## Layouts saved by a newer Tavotto open safely

Upcoming versions add new kinds of canvas objects, starting with free vector paths. If you open a layout that contains one of these in this version, the object is kept as it is: the layer list shows it as "Newer object", the canvas draws a dashed placeholder you cannot select or move, and saving keeps it unchanged. Export is blocked, with a line saying how many objects come from a newer version, so that a figure is never exported with a piece silently missing. Update Tavotto to edit or export them.
