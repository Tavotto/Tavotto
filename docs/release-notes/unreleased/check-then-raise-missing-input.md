## Link moved data for scripts that check or list it first

When a script checks for its data before reading it (`os.path.exists`, `isfile`, `isdir`, `getsize`, `os.stat`, `Path.exists` and similar), lists a data folder (`os.listdir`, `os.walk`, `Path.iterdir`) or collects files with `glob`, pointing Tavotto at the moved file or folder now makes the script run normally, without editing it. You can do this from the missing-data dialog, or let the AI fixer do it after you confirm. This also covers scripts that build the path from their own location and raise their own `FileNotFoundError` naming it, which previously showed up as a generic script error that could not be linked. Data read by native readers such as ovito `import_file` or h5py still needs the file put back where the script expects it, or the confirmed script rewrite.
