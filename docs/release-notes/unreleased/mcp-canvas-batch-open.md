## Opening several figures at once no longer shows a false error in the canvas

When the agent opened several figures in one call, Codex still showed an embedded canvas, and it claimed the tool result had been cleared and that you should update the plugin. The figures had actually opened fine. The canvas now says it holds one figure at a time and tells you to ask the agent to open the one you want to edit on its own. If the batch opened only one figure, the canvas shows it as usual.
