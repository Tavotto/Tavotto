## Drag a figure's edge outward in a layout to make it bigger

In a multi-figure layout, dragging a selected figure's edge outward used to stop at the figure's edge with the message "At image edge · right not cropped", so a figure could only be widened by stretching it. Dragging an uncropped figure's edge outward now changes that figure's size: the opposite edge stays in place, text keeps its size, and the figure re-renders when you release. Dragging inward still crops. A cropped figure stops at its edge and tells you to remove the crop first.
