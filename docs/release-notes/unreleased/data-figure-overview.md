## Data to figure can preview a data file and tell which scripts it generated (experimental, off by default)

Behind the experimental `ai.taf.enabled` switch, which is off by default, the data-to-figure backend gains two read-only pieces for the upcoming data page. A data file (a text table, or one sheet of an Excel workbook) can now be previewed before any figure is drawn: its column names and types, the number of rows and columns, the first rows as written, and any description lines skipped above the header. When the header row was not recognized, picking a different row re-reads the table right away, using the same reader the figure is later drawn from. The list of Excel sheets also reports each sheet's row and column counts. Scripts that Tavotto generated from a data file now say which data file (and sheet) they came from, so a figure can be grouped under the data it was drawn from. Nothing is written or changed in your files, and nothing changes while the switch is off.
