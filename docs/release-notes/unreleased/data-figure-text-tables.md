## Data to figure reads plain-text tables (experimental, off by default)

Behind the experimental `ai.taf.enabled` switch, which is off by default, the data-to-figure flow now reads `.txt`, `.dat` and `.asc` files as tables: it works out the separator (comma, tab, semicolon or runs of spaces), skips the description lines many instruments write at the top, and finds the row that names the columns. When it cannot tell which row that is, it says so and lets you pick the row instead of guessing silently; files that are not tables are reported as unreadable rather than failing. Cells written with thousands separators, such as `1,000`, are read as numbers. In semicolon-separated files a number containing a comma is never converted automatically, because `1,234` there usually means 1.234; you are asked what to do with it. Nothing changes while the switch is off.
