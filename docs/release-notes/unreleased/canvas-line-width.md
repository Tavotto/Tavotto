## Thin arrows, shapes and paths on the canvas are now checked against the journal's minimum line width

When the journal you picked sets a minimum line width, arrows, shapes and paths you draw on the canvas are now checked too — not only the data lines inside figures. A line thinner than the minimum shows up in Problems as "Line too thin" (the check formerly titled "Data line too thin"); clicking the row selects that object and puts the cursor in its line width field. Shapes with no outline are not checked. In single-figure editing the Problems list starts on "Current figure", which lists only issues on the figure itself; switch to "Whole layout" to see issues on objects drawn over it.
