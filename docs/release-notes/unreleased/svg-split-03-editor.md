# Bind SVG axes, series and legends and edit the computed figure

The binding interface lets you select scene nodes, calibrate axes and associate data columns with series and legends. Edits use the existing document writer and undo history. Full-frame geometry is adopted in the same transaction as the render, and stale responses cannot replace a newer project or chart revision.

This is part of the #1873 split. Architecture and release approval remain pending in [Issue #1877](https://github.com/Tavotto/Tavotto/issues/1877) and ADR-XXXX.
