## A library of ready-made cell-biology shapes for agents

Agents can now draw about forty editable biology shapes, including membranes, receptors and channels, kinases and G proteins, DNA and mRNA, organelles, the cytoskeleton, viruses and bacteria, and place them in a mechanism sketch. Each shape has a few adjustable parameters, membrane proteins sit in the membrane automatically, and every part stays an ordinary editable object. Agents look up the available shapes before drawing. The shapes are part of Premium.
