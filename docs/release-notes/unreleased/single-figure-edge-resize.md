## Drag a figure's edge to change its aspect ratio

When editing a single figure, dragging an edge of the canvas now resizes the figure along that side only, so you can make it wider, taller or square without changing the text size; it snaps to a square and to column widths. To add or trim the margin around the figure instead, hold ⌥ (Alt) while dragging an edge — this used to be what a plain edge drag did. Corner handles now use the same keys as in multi-figure layouts: hold ⌥ for a free aspect ratio and ⇧ to keep it proportional; hold ⌘ (Ctrl) to turn off snapping.
