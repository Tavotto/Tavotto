## Report a journal guideline issue from the Problems panel

When a journal is set for the layout, the bottom of the Problems panel now has a small link: "Report a journal guideline issue". It opens a short form where you can describe which rule is wrong or missing, or paste what the journal's editor wrote, add a screenshot or PDF, and leave an email if you'd like a reply. What you write is only used to check our journal data against the publisher's own pages and is never made public. Nothing is sent until you press "Submit feedback".
