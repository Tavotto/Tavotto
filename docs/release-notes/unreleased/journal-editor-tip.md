## Tell us when a journal's editor asks you to change a figure

When a journal is set for the layout, the bottom of the Problems panel now has a small link: "Editor asked for changes? Tell us". It opens a short form where you can paste what the editor wrote, add a screenshot or PDF, and leave an email if you'd like a reply. The editor's wording is only used to check our journal data and is never made public. Nothing is sent until you press "Submit feedback".
