## Layers list icons that look like your objects

Each object in the layers list now has its own icon: a landscape rectangle, an ellipse, a line with end nodes, a pen curve, a figure frame, and so on. The icon takes the object's color: filled shapes show their fill with a thin outline in the same hue, lines and text use their own color, and white or near-black objects stay readable in both light and dark appearance. Hidden objects are also faded in color.
