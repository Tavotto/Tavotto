## Your layout is always saved in the project, and ⌘S now names a version

Layouts are now saved into the project folder as you work — no key press needed. Move or copy the project folder and your layout comes with it. ⌘S no longer "saves"; it asks you to name this version, so you can find your way back to it later. If the folder is read-only, changes are kept on this computer and the top bar says so.
