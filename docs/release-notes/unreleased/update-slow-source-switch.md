## A slow in-app update tries the other download source

The desktop app downloads updates from either the Tavotto mirror or GitHub. Before, it only moved to the other source when the download stopped completely, so a download that kept trickling at a few dozen KB/s stayed on the slow source until it finished, which for a package of 150–200 MB could take a long time. Now, when the download would take more than about three more minutes, the app checks the other source for the same version and downloads from it for a few seconds while the first download continues. If the other source would finish clearly sooner, it takes over and the progress bar starts again from that source; otherwise the app drops it and keeps the first download. This happens at most once per update, and the installer's signature is verified the same way whichever source it came from.
