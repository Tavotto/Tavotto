## Plainer Chinese wording for common run and export errors

Several common errors in the Chinese interface no longer use engineering words. A timeout reads 脚本运行超时 instead of mentioning an "entry point", a script that drew nothing says it ran but drew no figure, a failed render gives an error code instead of an HTTP status, the export status message talks about the export rather than a "job", the write-back receipt says the figure was redrawn from scratch and checked, and the long build-timeout message is now one sentence. The English interface is unchanged.
