## Edits from Codex and Claude Code now land in your layout

When the agent changes a figure that sits in one of your Tavotto layouts, the change is written to that panel's in-figure edits and shows up in Tavotto on its own, and Undo takes it back in one step. If you edited the same setting yourself in the meantime, yours wins: Tavotto keeps your value and the agent is told on its next step. The agent never touches your script.
