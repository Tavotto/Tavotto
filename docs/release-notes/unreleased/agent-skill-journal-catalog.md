## AI editors can check a figure against a specific journal

Trigger: asking Codex, Claude Code, Cursor or another connected AI editor to
"make this ready for Nature" (or any journal in Tavotto's built-in list).
Before: the agent had to guess the journal's column widths and font sizes and
type them in by hand. Now it looks the journal up in the same journal library
the desktop app uses, checks and exports against it, and tells you which
journal and which version of its guidelines it used. If a journal isn't in the
library, the agent says so and asks for the guideline text instead of making
numbers up.
