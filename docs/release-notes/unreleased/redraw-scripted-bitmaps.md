## Figures saved as bitmaps by a script can be redrawn as vectors in one click

A figure placed from the PNG its script saved used to be exported as that bitmap until you edited something, while double-clicking it showed the script's redraw, so the canvas and the inside of the figure could look different (for example, boxes instead of Chinese characters). Selecting such a figure now shows a "Redraw with script" badge: it runs the script, lets you compare the redraw with the original when they differ, and from then on the canvas and every export use the redrawn vector figure. The canvas export dialog also redraws these figures before exporting by default, when the redraw is pixel-identical or a vector version of the same figure exists; untick the option to export the original files. Nothing runs when a project is opened, and undo goes back to the original.
