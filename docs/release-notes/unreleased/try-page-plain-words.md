## Plainer Chinese wording on the online trial page

On the online trial page (`/try`), the Chinese interface no longer shows engineering words to first-time visitors. The page is titled 在线试用 instead of 浏览器 playground, errors say the script ran out of time or that Python stopped unexpectedly instead of mentioning a "Python worker", the note under the source says edits are saved separately and the script is not changed, and the button that expands a script's error reads 报错详情 instead of Traceback. The English interface is unchanged.
