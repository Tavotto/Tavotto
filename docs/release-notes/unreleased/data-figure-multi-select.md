## Data to figure: plot several data files at once (experimental, off by default)

In the "Data" section of the left rail, a "Select" button sits in the title row next to the pin (it appears once there are at least two data files that can be plotted). Click it and a small panel opens under the title: it says how many files you have picked and has two buttons, "Plot each" and "Plot combined". Click files to pick them: a picked file turns into a white card with a check mark where its row count was. The button now reads "Cancel" (Esc does the same). Cmd/Ctrl+click and Shift+click (a range) still work and switch the mode on too.

"Plot each" makes one figure per file using the recommended way to plot it. While it runs the files that are waiting say "Queued", the current one spins, and finished ones say "Done"; "Stop" finishes the current file and leaves the rest. The new figures show up as cards in the asset library and none of them is opened for you. A file that can't be plotted is marked "Failed" (hover for the reason; click it to open it on its own), and the panel offers "View assets" and "Retry" for the ones that failed. "Plot combined" puts up to 8 picked files in one figure (one group per file) and opens the usual choice of ways to plot it in a temporary tab; if the columns don't match it says so and offers "Plot each" instead. With a flat list (no folders) the rows now line up with the title. Nothing changes while the experimental `ai.taf.enabled` switch is off.
