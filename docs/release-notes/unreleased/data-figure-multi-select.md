## Data to figure: draw several data files at once (experimental, off by default)

In the "Data" section of the left rail, a "Select several" button sits in the title row next to the pin (it appears once there are at least two data files that can be drawn). Click it and a small panel opens under the title: it says how many files you have picked and has two buttons, "Draw one each" and "Draw as one". Click files to pick them: a picked file turns into a white card with a check mark where its row count was. The button now reads "Cancel" (Esc does the same). Cmd/Ctrl+click and Shift+click (a range) still work and switch the mode on too.

"Draw one each" draws one figure per file using the recommended way to draw it. While it runs the files that are waiting say "Waiting", the current one spins, and finished ones say "Drawn"; "Stop" finishes the current file and leaves the rest. The new figures show up as cards in the asset library and none of them is opened for you. A file that can't be drawn is marked "Didn't draw" (hover for the reason; click it to open it on its own), and the panel offers "See what's drawn" and "Try again" for the ones that failed. "Draw as one" puts all the picked files in one figure (one group per file) and opens the usual choice of ways to draw it in a temporary tab; if the files' column names differ it says so and offers "Draw one each" instead. With a flat list (no folders) the rows now line up with the title. Nothing changes while the experimental `ai.taf.enabled` switch is off.
