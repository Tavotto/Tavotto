## Data to figure: draw several data files at once (experimental, off by default)

In the "Data" section of the left rail, a "Select several" button now sits in the title row (it appears once there are at least two data files that can be drawn). Click it, then click files to pick them; a + / check mark shows at the end of every row while you are picking, and clicking the button again (or pressing Esc) leaves the mode. Cmd/Ctrl+click and Shift+click (a range) still work and switch the mode on too. With two or more files selected, "Draw one each" draws one figure per file using the recommended way to draw it. The new figures show up as cards in the asset library and none of them is opened for you, so you pick which one to edit. A file that can't be drawn is marked and can be retried on its own. Nothing changes while the experimental `ai.taf.enabled` switch is off.
