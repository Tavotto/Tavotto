## Phone photos are no longer rotated and squashed on export

Photos taken with a phone usually store their pixels sideways and record how to turn them for display. The canvas already showed them upright, but PDF, PNG, TIFF and SVG export ignored that record, so a portrait photo came out turned 90° and squeezed into its frame. Export and previews now show the photo the same way the canvas does. JPEG photos are still embedded in PDFs unchanged, so file size and quality stay the same.
