## The figure-editing assistant follows Tavotto's scientific-figure guidelines

When you ask the AI assistant to change a figure, it now also receives a short set of scientific-figure guidelines: keep bars starting at zero, never put zero or negative values on a log axis, ask instead of guessing what error bars represent, and treat matters of taste (frames, grids, error-bar caps, pie vs. bar) as your choice rather than mistakes to fix. The Codex plugin skill gains the same guidelines as a reference file.
