## Nested groups, clipping masks and the transform panel

Groups can contain groups. Double-click a group to edit inside it and press Esc to step back out. Make a clipping mask from the top object of a selection and release it again; hiding the clipping path in the layer tree turns the clip off for now. The transform panel sets position, size, rotation, skew and mirroring around any of nine reference points, with a proportion lock and an option to scale strokes. ⌘D duplicates and repeats the last move, and ⌥⌘D repeats the last transform.
