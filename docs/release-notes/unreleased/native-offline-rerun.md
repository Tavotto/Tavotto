## Figures from an ended run say so and offer "Run again" instead of "Render failed"

A figure made by running a script with your own Python can only be edited while that run is alive. After reopening Tavotto, clicking such a figure showed "Render failed". It now shows "Run ended" with a "Run again" button, which runs the script the same way as "Open and run" in the script list. Once the run finishes, you can edit the figure again.
