## Pathfinder

Select two or more shapes or paths and use Pathfinder (right-click menu, the arrange row in the inspector or the command palette) to unite, subtract the front, intersect, exclude overlap, divide or trim them. Compound paths (⌘8, release with ⌥⇧⌘8), offset path, outline stroke, reverse path direction and simplify path are there too. The result is a normal path, so it exports everywhere and stays editable. Paths can also align their stroke inside or outside when closed. In the canvas embedded in Codex the pathfinder buttons are unavailable and say why.
