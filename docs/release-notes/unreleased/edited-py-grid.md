## The exported `_edited.py` now carries your grid and frame edits

Grid colour, line style, width and transparency, which sides show tick marks, the colour and width applied to all four frame lines at once, and the grid switch on 3D axes are now written into the `_edited.py` file you get by ticking **PY** on export. Before, these edits were left out and the script drew the grid and frame as it originally did.
