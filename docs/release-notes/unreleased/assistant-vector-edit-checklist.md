## Pick which steps of an assistant's canvas edit to apply

When the assistant proposes changes to the arrows, text and shapes you selected, each step in the plan now has a checkbox. Uncheck the ones you don't want and the before-and-after, the checks and what Apply writes update to match; a step that depends on one you unchecked is unchecked with it, and if the plan can't be recalculated, Apply stays off until you try again.
