## Contact the maker: attach any file type, and choose extra diagnostic content

**Any file type can be attached.** Trigger: adding a data file (CSV, MAT, HDF5,
ZIP …) in Contact the maker. Before: only images, PDF, Word, Excel and
PowerPoint were accepted. Now any file type is accepted, up to 5 files and
50 MiB in total (was 20 MiB).

**Attach diagnostic info can include script source, crash reports and damaged
sessions.** Trigger: ticking "Attach diagnostic info" in Contact the maker.
Before: the attached bundle never contained these. Now the three extra items
from Send a problem report appear under it, all unticked by default.

**Shorter hint for script source.** Ticking "Script source" in either Contact
the maker or Send a problem report no longer shows a privacy warning under it;
the other two extra items still do.
