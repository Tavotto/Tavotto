## Export follows the journal you picked

When a project is checked against a journal, the export dialog now starts from that journal's
requirements. Resolution starts at the journal's highest stated value (for example 1000 dpi for
Elsevier line art) unless your own default is higher, and a format the journal does not list is
swapped for one it does (PDF + PNG becomes PDF + TIFF). Formats the journal does not list stay
selectable and show a small dot; hovering explains why. The "Spec" dropdown under Checks now shows
the journal's name instead of being blank, and switching away from the journal there asks first.
