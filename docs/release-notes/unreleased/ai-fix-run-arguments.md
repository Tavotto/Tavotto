## AI repair fills in a script's run arguments itself

When a script needs command-line arguments (for example a required `--data` option), repairing with your AI used to work out the right values and then ask you to type them in, or even suggest editing the script. The AI now reads the script, sets the arguments, and checks that the figure appears. They show up in the script's run-arguments box afterwards, so you can see and change them. Your script is not modified.
