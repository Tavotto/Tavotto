## Agents can lay out a named diagram frame

When an agent draws a schematic beside your figure, it can now put it in a named diagram frame: a labelled group with an outline, with the arrows and text inside grouped and named the way a person would organise layers, so you can ungroup and edit any piece. The frame is free. Ready-made biological shapes (membranes, receptors and so on) and automatic pathway layout are part of Premium; without it the agent says so and links to the Premium page instead of drawing half a diagram.
