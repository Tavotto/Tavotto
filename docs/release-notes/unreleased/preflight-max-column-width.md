## Page-width check now covers journals that only state a maximum width

Some journals (for example JACS) give only a maximum width for each column, not an exact one, and the pre-submission check used to skip the page-width rule for them: a 228.6 mm wide figure passed without a word. The check now flags a page wider than the journal's largest stated maximum ("the page width 228.6 mm is over the profile's maximum width, 177.8 mm"). Journals with exact column widths are checked exactly as before; when a journal states both, either one is enough to pass.
