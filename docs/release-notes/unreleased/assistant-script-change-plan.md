## Script edits from the assistant now come back as a plan you can review before your script is touched

When a request needs the script, the assistant no longer edits your script directly. The Agent works on a private copy, runs it, and sends back a card with the before and after figure and the exact script changes (**Script changes** tab). Your own script is not written until you press **Apply**; Tavotto keeps two backups first, and **Undo** on the card restores the script from the backup (⌘Z does not undo script edits). If you edited the script in the meantime, the card says the figure changed and offers to regenerate instead of overwriting your work. This also works with Codex and Claude Code subscriptions: because an external tool can't be fully confined to the copy, Tavotto checks afterwards and makes no plan if anything outside the copy changed: it lists the other project files (without touching them), and if your script itself changed while the agent was running (it can't tell your own save from the agent's edit) it backs up both versions, leaves the script as it is, and offers **Restore the version from before** or **Keep the current version**. The script itself is sent to the AI connection you picked, as it already was when the Agent edited it. To go back to editing directly, turn off **Show a change plan before editing** in Settings → Assistant → Advanced.
