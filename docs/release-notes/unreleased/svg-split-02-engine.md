# Explicit SVG bindings can recalculate a chart without replacing unrelated artwork

A closed chart model associates axes, series, data and legends explicitly. Matplotlib calculates the bound region and the compositor preserves unbound annotations and decoration. Model validation and coordinate examples are shared with the frontend. The fixed chart command uses the existing process owner for deadlines, output limits and reaping; its separate capacity accounting remains an architecture decision in ADR-XXXX.

This is part of the #1873 split. Architecture and release approval remain pending in [Issue #1877](https://github.com/Tavotto/Tavotto/issues/1877) and ADR-XXXX.
