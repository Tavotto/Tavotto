## Data-to-figure (experimental, off by default) reads GBK / GB18030 and UTF-16 tables, and says clearly when a data folder is read-only

Behind the `ai.taf.enabled` experiment switch, which is off by default: text tables saved as GBK / GB2312 / GB18030 (common from instruments and Excel's "Save as CSV" in Chinese locales) or as UTF-8 with BOM and UTF-16 with BOM are now read correctly, including Chinese column names and group values, instead of being rejected as unreadable. Tavotto decides the encoding once (BOM first, then strict UTF-8, then strict GB18030) and the generated script uses the same one; files in any other encoding are still reported as unreadable rather than guessed into garbled text. The data overview and the file list now include the encoding that was used. If the data folder can't be written to (read-only folder or drive, no permission, or a full disk), creating the figure now fails with a specific message, and nothing is left behind. Your data files are never modified, and scripts generated from UTF-8 files are unchanged.
