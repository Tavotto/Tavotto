## Data to figure: choosing a journal no longer removes the top and right frame lines

In the experimental, off-by-default data-to-figure page, picking a journal used to switch new figures from a full four-sided frame to only the left and bottom axis lines. A journal that does not ask for an enclosed frame was read as asking for an open one. New figures now keep the default four-sided frame unless the chosen specification explicitly requires otherwise; scripts generated earlier are not touched.
