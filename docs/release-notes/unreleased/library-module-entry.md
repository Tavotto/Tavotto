## Running a file that only defines plotting functions now points you to the script that calls them

If you opened and ran a Python file that only defines plotting functions (a helper module from a larger codebase, where another script loads the data and calls them), Tavotto installed its dependencies, ran it, and then said no figure was produced, offering an AI fix that could only invent data. Tavotto now recognizes such a file before running it, without installing anything, and looks through the project and the code repository it belongs to for the script that imports it. The card names that script and offers "Run it" (or "Open and run" when it lives outside the project, which opens that repository folder first). "Run anyway" stays available. When no calling script is found, the card says the file only defines plotting functions and never calls them.
