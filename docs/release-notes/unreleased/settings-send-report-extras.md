## "Send a problem report" in Settings shows the extra-content checkboxes again

Trigger: Settings › Help & diagnostics › "Send a problem report" while
"Contact the maker" is available. Before: the button opened the Contact
dialog, whose attached diagnostic bundle has no checkboxes for source files,
crash reports or damaged sessions and never included them. Now it opens the
problem-report dialog with those checkboxes; the maker's reply still shows up
under "My messages".
