## Agents can add arrows, labels and significance brackets to your layouts — aligned to your data

In the plugin, the agent can now add vector annotations (arrows, text, significance brackets, connectors, boxes) to a layout in your project. It describes what it wants ("an arrow to the point at x = 8 on Sample B"), and Tavotto places it exactly, measuring from the figure as it is actually exported. Each batch is checked before it is saved: aligned, not covering data or text, inside the page, within the journal's font size and line width. The agent shows you, in plain words, what each annotation points at, plus a preview of that area. Significance stars and p-values are added only when they come from you or your data. Annotations are added as ordinary editable objects and only appended to the layout, and the last write can be undone in one step.
