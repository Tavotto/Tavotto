## Data-to-figure pairs Chinese "mean" and "standard deviation" columns

- A summary table whose columns are named in Chinese — for example 处理 / 均值 / 标准差 / n — is now drawn as means with the table's own error bars, the same as a table with `mean` and `sd` columns. Before, the 标准差 column was not matched to 均值 and the suggested figure could plot the wrong column. A 标准差 column with no column that says it is a mean next to it is still left unpaired.
