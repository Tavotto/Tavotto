## Data to figure: switch computed error bars between SD, SEM and 95% CI

In the experimental, off-by-default data-to-figure page, a figure whose error bars or shaded band are computed by Tavotto from replicate values (mean ± SD, SEM or 95% CI) now shows an "Error bars" row at the top of the properties panel when you click an error bar or the band. Picking another type redraws the figure from the same data as a new script in the same place on the canvas; the old script stays in the project and Undo brings the old figure back. The row only appears for figures you have not edited, and the redraw never sends the data to an AI model.
