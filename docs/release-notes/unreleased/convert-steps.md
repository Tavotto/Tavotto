## Making an editable version shows which step it is on

While Tavotto writes an editable Matplotlib version of an R, MATLAB or bitmap-drawing script, the card now lists the steps — read the original script, write the Python version, test run — instead of a bar that just sweeps. If the test run fails and the AI is asked to correct the new script, the "write" step shows "Round 2"; steps already done stay ticked.
