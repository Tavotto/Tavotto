## AI agents are told before closing a figure loses its edits

When an AI agent edits a figure through Tavotto's tools, the changes live in the Tavotto session until they are exported. Closing a session that still has unexported changes now says plainly that those changes were dropped and your files are untouched, and the one-step journal fix reminds the agent to export before closing. Previously an agent could fix a figure, close the session, and leave you with nothing.
