## Export, save and write-back failures now end with a button that does the next step

When a folder can’t be written to, the export failure now offers “Export to another folder”: pick a folder and the export runs again right there. When a bitmap export is over the size limit, it offers “Export at N dpi” with the highest resolution that fits, and exports at that setting when clicked. A save that fails because the file was changed elsewhere after you switched layouts no longer points you to a dialog that never opens. A write-back that fails its safety check now gives one plain sentence and a “Send feedback” button (the internal details are folded away), and a write-back blocked because the script changed has a “Re-render” button. A layout from a newer version now has a “Check for updates” button in the desktop app.
