## When a script change would alter your data, the plan card now asks first instead of refusing

If you ask the Agent for something that changes the numbers a figure plots, such as "change the x unit to seconds and convert the data", the plan card used to be refused with "this change would alter the data, so it can't be applied". It now shows the plan and asks one question first: "This change alters the data the figure plots. Go ahead?" "Go ahead" lets you review and apply it as usual, and you can still undo it from the card; "Not now" leaves the script and the data exactly as they were. Nothing is written before you answer, and Tavotto won't apply such a plan without that explicit yes, including plans made from a reviewer's comments. If the edited script stops drawing the original figure altogether, no plan is offered, as before.
