## Fixed: the rewrite preview after pointing at missing data could hang indefinitely on Windows

After choosing the real data file in the "data file not found" dialog, the first step could sit on "processing" for minutes with "Later" greyed out and Esc doing nothing, so the only way out was quitting the app. The preview's Git status check (used only to say whether the script has uncommitted changes) could be blocked by Git itself or by a helper process it started, and its 3-second limit did not release the preview on Windows. The check now runs with no inherited input, never prompts or takes repository locks, and always gives up after 3 seconds (the preview then simply omits the Git note). The preview request also has its own 30-second limit, and "Later" or Esc cancels it while it is pending; nothing is written to your script until you confirm the rewrite.
