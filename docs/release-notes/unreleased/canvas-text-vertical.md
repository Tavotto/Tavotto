## Text labels can be set vertically

A text label on the canvas can now be switched between horizontal and vertical with the new "Direction" control in the Properties panel and in the floating text toolbar. Vertical text runs top to bottom with columns from right to left; Chinese characters stay upright, while English letters and digits lie on their side, and full-width punctuation such as ，。「」（） uses its vertical forms. For vertical text the box height is the column length (text wraps into a new column when it is reached) and the width follows the number of columns; Left / Center / Right alignment becomes Top / Middle / Bottom within each column. Vertical text can also be rotated, and the exported PDF, SVG and images match what the canvas shows. Existing labels are unchanged.
