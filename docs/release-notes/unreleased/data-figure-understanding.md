## Data to figure: better default columns when an AI connection is set up

With an API-key AI connection, Tavotto now takes a few seconds to work out what each column of the selected table is and picks the X axis, Y axis and grouping accordingly. If you have not touched the three drop-downs the better choice is applied automatically; if you have, a small "Try suggested" pill appears instead and nothing changes until you click it. When the check fails or times out the page stays exactly as before.
