## A connection that stops working now says why and offers the one fix that helps

When an AI connection fails, the connection list and the failed-task card now say what went wrong in a few words (the key is wrong, the quota is used up, the model does not exist, or the address cannot be reached) and offer the matching action: re-enter the key, switch to another AI, change the model, or check the connection again. Custom addresses you added yourself now appear in the "Connect an AI" list with the same status and button, and saving a custom address no longer asks which protocol it uses.
