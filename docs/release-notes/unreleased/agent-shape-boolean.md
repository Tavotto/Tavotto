## Agents can combine, offset and outline shapes, not only paths

In the plugin, the agent can now merge, subtract, intersect or offset rectangles, ellipses, polygons and stars directly, and outline the stroke of shapes, lines and arrows; it can also convert a shape or arrow into an editable path on its own. The shape turns into a path that looks exactly the same, the change is read back in plain words ("converted to a path first"), and it can be undone in one step like any other agent edit.
