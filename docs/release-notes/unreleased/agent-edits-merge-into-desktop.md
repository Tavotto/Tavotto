## Edits the agent makes also merge into your open layout, without a prompt

When the agent edits, deletes or restacks objects on a layout you have open, Tavotto now brings those changes onto your canvas the same way it already does for new annotations: when you return to the window, or when you press ⌘S, as one step you can undo. Your own unsaved edits are kept, because the agent's changes are merged property by property. You are asked how to resolve it only when you and the agent changed the same thing — the same property of the same object, or something you edited that the agent deleted.
