## Reopening a saved layout no longer shows the restored draft's figure

**Canvas and export preview show the saved state of a script figure.** Trigger:
restore a draft, then open the saved layout of the same name that holds the same
script figure. Before: the canvas and the whole-sheet export preview kept
showing the draft's version (for example its title) while the exported file
used the saved one. Now both read the preview that matches the layout's own
settings, and the "approximate preview" badge appears when none exists.
