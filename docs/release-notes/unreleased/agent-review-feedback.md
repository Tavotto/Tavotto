## Agents can read review comments, reply (asks you first) and mark them resolved

The agent can now also read the comments reviewers left on a figure's review link (grouped by version, with the element each one points at and each reviewer's verdict), reply to a comment (only after you approve the exact reply), and mark comments as resolved. Reviewers' words are treated as to-dos for the agent, never as instructions. Reading comments does not clear the app's unread badge.
