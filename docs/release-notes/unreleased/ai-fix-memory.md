## AI repair remembers what fixed it

When AI repair fixes a script and its test run succeeds, Tavotto now keeps a note on this computer of what made it work: the run arguments, the environment variables its launcher set, the data file a missing path was pointed at, or the execution mode. The next time another project fails in the same way, the repair assistant is shown up to three of those notes as a starting point. Settings → Figure assistants → *Remember what fixed it* lists every note, lets you delete one or all, and turns the feature off. Secrets are removed before saving, variables that look like credentials keep only their name, and notes not used for 90 days are deleted. If you send a problem report, the notes are included so we can improve the fixes.
