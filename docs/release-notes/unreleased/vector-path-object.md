## Free-form paths on the canvas

The canvas has a new editable path object. Paths are drawn, hit-tested along their outline and exported with the same geometry in PDF, SVG, EPS and PNG. Right-click a shape and choose "Convert to path" to turn it into one: the drawing does not move and one undo brings the shape back. Paths share the fill, stroke, line style, cap and join controls with shapes, and the format painter copies between them. Files with paths open in older Tavotto versions as a placeholder that cannot be selected or exported.
