## Connection methods and the assistant’s model picker are now tidy lists

When a provider offers more than one way to connect (for example OpenAI: subscription sign-in or API key), the methods are now shown as a single list under the provider instead of separate cards. Icons line up with the provider logo, every method has its action button in the same place on the right, and the subscription and API-key methods have new icons.

In the assistant, “AI & model” is now one list as well, instead of a menu inside a menu: each connected AI is one row (subscriptions are marked), click a row to see its models under it, and the selected model has a check mark.
