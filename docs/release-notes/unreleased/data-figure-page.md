## Data to figure: a data page inside the project (experimental, off by default)

Behind the experimental `ai.taf.enabled` switch, which is off by default, the home screen offers a second way in for people who have data but no figure yet: pick a folder of data and Tavotto lists the tables it found in a "Data" section of the left rail. Selecting a file shows a preview; when Tavotto is not sure which row names the columns, you click the right row and it re-reads the file. Starting from a table, Tavotto offers a few ways to draw it, rendered from your real data, asks before using cells that are not numbers, writes a new script next to your data in `tavotto_figures/`, and opens the figure in the editor. Your data files are never changed. Nothing changes while the switch is off.
