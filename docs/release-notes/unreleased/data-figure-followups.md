## Data to figure: no dead end after many figures from one file, calmer file-list refresh, warmer candidate tiles

When a data file already has dozens of figures drawn from it, drawing another one no longer runs out of names, and if the name ever cannot be found the failure shows only its explanation, without a "try again" button that could never succeed. The list of data files now reads the disk at most once more after a burst of file changes instead of once per change. The candidate tiles in light theme use the same warm tint as the rest of the workspace.
