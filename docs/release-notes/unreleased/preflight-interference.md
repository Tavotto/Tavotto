## Checks flag text and legends that collide

The problem list now reports three layout collisions that used to be visible only to coding agents: text that overlaps other text, a subplot's labels or ticks running into the plotting area of a neighbouring subplot, and a legend that sits on top of the data. A legend is reported as covering the data only when it actually touches something drawn: a line, a marker, an image, or one of the error bars or caps of an error-bar series. A legend sitting in the empty space between error bars is not reported. When Tavotto can only measure the outer bounds of an element, it says the legend may cover the data. Each one appears under Layout, points at the element that collides, and is a warning that does not block export. Tavotto does not move anything for you.
