## Data to figure: switching the error type still works after reopening the project

In the experimental, off-by-default data-to-figure page, the row that switches computed error bars or bands between SD, SEM and 95% CI now also appears after you close and reopen the project. The figure remembers, inside your project, which table and columns it was drawn from. The row is only offered while the data file is still there and its contents are unchanged, and switching never sends the data to an AI model.
