## Pasted or imported SVG keeps arrowheads and superscripts

Simple arrowheads drawn with SVG markers (filled triangles, open chevrons, dots) now come in as the path's own arrow ends you can restyle, instead of turning the whole drawing into a picture. Superscripts, subscripts and bold or italic words inside a text line stay as they were, so `Ca²⁺` no longer comes in as `Ca2+`.
