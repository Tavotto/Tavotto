Windows now gets the same **real desktop application** macOS got in v0.2.0 —
its own window, no browser tab — and it still ships the bundled Python
rendering runtime, so nothing needs to be installed first. This release also
introduces the new Magplot brand identity, and makes script-backed
(parametrisable) panels easier to find in the asset browser.

## Added

**Windows: a true desktop app, runtime included.** The Windows installer is now
the Tauri shell with a local Python sidecar — the same architecture as the
macOS app: dynamic localhost port, one-time-nonce authentication, window closes
→ backend exits. The bundled rendering runtime (CPython 3.13 + numpy,
matplotlib, pandas, scipy, seaborn, Pillow at pinned versions) ships inside the
installer as before; the release pipeline refuses to build without it and
smoke-renders a real figure against it before anything is published.

**Asset browser: parametrisable panels first.** Panels generated by a
registered script — the ones you can open for in-figure editing — now sort
ahead of plain images in the default (by-name) ordering, and a dedicated
one-click `{ }` button next to the search box filters the list down to just
them. The filter is the same state as the existing filter popover, so the
removable filter chip behaves as before.

## Changed

**New brand identity.** Magplot has a proper mark — a page being laid out:
frame, two placed panels, one blue block for the panel in hand. It appears in
the top bar, the project picker, About, the app icon, the favicon and the
README. The interface accent colour moves from indigo to the brand blue
`#2868B7`; the selection blue is unchanged.

**Quieter iconography.** The lightning-bolt marker for parametrisable panels is
replaced by a neutral `{ }` braces marker everywhere (panel badges, element
tree, script registry), matching the marker the asset cards already used.

**Browser-opening desktop builds are retired.** The old PyInstaller-based
installers — which started a local server and opened your default browser —
are no longer built, for macOS or Windows; desktop downloads are now real
windows only. The Windows portable zip is retired with them, since it was that
browser-mode build in a folder. If you need the previous form, every earlier
release keeps its assets, and `pipx install "magplot[worker]"` remains the
supported browser-mode path on all platforms.

## Upgrading

Download the new installer from this release and install over your existing
copy (macOS: replace in Applications; Windows: run the setup). Projects,
layouts and settings are stored in your user data directory and are not
affected.
