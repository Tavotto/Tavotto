Adds **standalone desktop apps** — a signed `.dmg` for macOS and an installer for
Windows — so you no longer need to touch a terminal to install Magplot.

## Desktop apps

Download from the assets below, install, double-click. The app opens Magplot in your
browser.

**These apps do not bundle matplotlib, and that is deliberate.** Magplot renders *your*
scripts, which import *your* dependencies — scipy, pandas, whatever your figures need.
No interpreter we could ship would satisfy them. So the app finds the Python you
already have (the one you made your figures with) and renders through it. If it picks
the wrong one, set `MM_WORKER_PYTHON`, or check **Settings → Privacy, diagnostics and
About** to see which interpreter is in use.

If you have no Python with matplotlib at all, layout, annotation and export still work
on existing PDFs — only the ⚡ in-figure editing needs it.

macOS builds are signed and notarised. The Windows installer is not signed yet, so
SmartScreen will warn on first run — choose **More info → Run anyway**. A portable zip
is also attached for environments where running an unsigned installer is not allowed.

Prefer the command line? `pipx install "magplot[worker]"` is unchanged and still the
lightest option.

## Fixed

**Starting Magplot a second time no longer fails silently.** If port 5089 is already
serving Magplot, the existing window is brought up instead of starting a duplicate; if
some other program holds the port, Magplot moves to the next free one. Previously the
process died with `Address already in use` — invisible when launched by double-click.
