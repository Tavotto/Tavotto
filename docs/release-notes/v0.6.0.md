This release is about one sentence becoming true and staying true: **what
you see while editing is what gets written to your files, and what comes
back when you reopen them.** Everything else here — a new Rust supervisor,
a versioned worker protocol, transactional write-back, honest caches — is
machinery in service of that sentence, and it is now guarded by a
four-way equivalence test matrix that renders every scenario four ways
(live editing, full replay, a brand-new worker, and reopen-after-write-back)
and requires them to agree to within half a percent.

## Added

**A Rust supervisor for the render engine.** Worker processes are now
managed by `magplot-workerd`, a small Rust binary that ships inside the
desktop app. It owns the unglamorous parts of reliability: request queues
that collapse to the latest edit instead of piling up, hard timeouts that
kill and respawn a stuck worker, generation numbers that make it
impossible for a stale render to overwrite a newer one, and cancellation
that actually cancels. Python remains the policy layer — interpreter
discovery, bundled-runtime handling and all rendering semantics are
unchanged — and the pure-Python worker pool is still there as the
reference implementation and automatic fallback (`MAGPLOT_WORKERD=0`
switches back at any time; diagnostics now show which control plane every
render actually used).

**Write-back is a transaction.** "Write back to original file" now runs
prepare → verify → commit. Before touching anything it checks that the
source file and the generating script haven't changed under you. It then
replays your edits on a **brand-new worker** — the same thing a reopen
would do — and compares that clean replay against what you see on the
canvas, element by element; any divergence blocks the write with a
detailed report instead of silently baking a wrong figure. The files that
get committed are the clean replay's output, a backup is taken first,
partial failures roll back, and the receipt includes content hashes for
the patches, the manifest and the written files.

**Duplicate panels stopped lying.** Two panels sharing one source file but
carrying different edits used to fight over a single render slot — one of
them showed the other's figure. Render state is now keyed per variant:
each panel renders and displays exactly its own edits, identical copies
share one render, and the SVG now travels in the same response as its
manifest so the pair can never be mismatched by a concurrent render.

**A versioned worker protocol.** Requests and responses between the
supervisor and Python workers now carry a protocol version, request ids,
worker generation and structured error codes, with byte-identical patch
canonicalization on both sides pinned by shared golden vectors. The old
line protocol still works for hand debugging.

## Fixed

- Write-back baselines are stored **per project**: a `Fig1` in one library
  can no longer inherit overrides baked from another project's `Fig1`.
- Export and history preview no longer leave their patches applied to the
  live session — restoring an old version can't desync the canvas anymore.
- A failed write-back can no longer leave `.updating` files in your
  figures directory, and warnings from the renderer (missing elements,
  unsupported properties) now **block** the write instead of vanishing.
- A script stuck in an infinite loop used to freeze its render session
  forever; requests now time out, the worker is killed and the session
  rebuilds itself.
- Preview caches are keyed by file content (not modification time) and
  written atomically — no more torn thumbnails under concurrency.

## Performance

Measured before optimized: the engine now reports per-stage timings
(queue wait, build, patch apply, draw, manifest) end to end, and
`docs/perf-baseline.md` records the baseline. The one optimization the
data justified: interactive editing of image-heavy panels renders at a
lower preview dpi while you drag (−33% draw time, −75% SVG size) and
snaps back to full quality on release. Vector-only panels are untouched —
the data showed zero benefit there.
