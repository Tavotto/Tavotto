# Tavotto 0.19.2

A release about editing text inside figures the way you would in a word
processor, and about connecting an AI and converting scripts without
getting stuck. You can now italicize or subscript just part of a label and
see formulas typeset; Claude Code and Google Antigravity can be set up from
inside Tavotto; and several dead ends reported from real Windows and macOS
installs now end in a button that fixes the problem.

## Before you upgrade

**The Windows installer is still not code signed.** Expect a SmartScreen
prompt on first run; update packages remain minisign-signed. macOS builds
are signed and notarized as usual.

## New

**WYSIWYG text editing for figure text and annotations.** The text box in
the properties panel is now a rich editor: select part of the text and click
**B**, **I**, **x²** or **x₂** (or press ⌘B, ⌘I, ⌘↑, ⌘↓) and the box shows
the result directly, so you can italicize only the symbol in "T (K)" instead
of the whole label. A **TeX** switch in the corner of the box shows and
edits the LaTeX source; pasting `$…$`, `\(…\)` or `\[…\]` from a paper
turns into a formula block, and the source view shows a live preview of the
formula under the cursor, or the exact reason it cannot be typeset. Opening
a text without editing it never rewrites it. (#1488, #1489, #1492)
- Formulas in annotations are typeset as real formulas on the canvas, in the
  export preview and in exported PDF/SVG, using the same layout everywhere.
  A formula that cannot be typeset is drawn as its source and listed in the
  Problems panel. (#1497, #1501, #1502)
- Copying an annotated formula out of an exported PDF gives back its LaTeX
  source, and pasting it into Tavotto is recognized as a formula again.
  (#1505)
- When text inside a figure gets italic, bold or a sub/superscript, its
  formula font follows the body font instead of falling back to Matplotlib's
  default DejaVu Sans. (#1496, #1506)
- Small thumbnails (canvas list, version list) show formulas as readable
  Unicode (`Eₐ=RT²/k`) instead of LaTeX source, and on Windows use a font
  stack in which subscripts and superscripts match the surrounding text
  instead of falling back to a serif face. (#1517, #1522)

**Separate Chinese and English fonts for figure text.** The font row in the
properties panel and in Settings › Style is now two rows, "Chinese font"
and "English font". With the Chinese font on Automatic nothing changes;
picking one (for example Times New Roman + SimSun) draws Latin text in the
English font and Chinese characters in the Chinese font, in exported PDFs
as well. The English list only offers fonts that do not contain Chinese
characters themselves; if a figure already uses one that does, the choice
is kept and a hint suggests picking another. (#1533)

**Install Claude Code from inside Tavotto.** If Claude Code is not
installed, signing in with a Claude subscription under "Connect AI" now
offers "Install and sign in" instead of a greyed-out card.
Tavotto downloads the official Claude Code binary only after you click it
(from the npmmirror registry, falling back to Anthropic's own download
server), checks it against a pinned size and SHA-256, and keeps it in
Tavotto's data folder without modifying it; a Claude Code you installed
yourself is left alone. The installed copy does not update itself; Tavotto
moves it to a new version in a later release. Sign-in runs Claude Code's own
`claude auth login` in your browser and returns to Tavotto when it finishes;
Tavotto never sees or stores your credentials. Install errors (offline,
checksum mismatch, disk full…) now name the tool being installed. The
install button sits at the right of the row and doubles as the progress
bar. (#1491, #1495)

**"Connect AI editors" adds Google Antigravity.** Settings → Connect AI
editors lists Antigravity. Connecting writes a `tavotto` entry under
`mcpServers` in both `~/.gemini/config/mcp_config.json` and
`~/.gemini/antigravity/mcp_config.json` (merged, with a backup, never
overwriting other servers); disconnecting removes it from both. The row
shows "not installed" unless one of those Antigravity folders exists — a
`~/.gemini` folder from Gemini CLI alone does not count. Start a new
Antigravity session after connecting. (#1490)

**Folders you cannot write to offer "Save a copy".** When you open a project
whose folder Tavotto has no permission to write, it now offers to save a
copy into a folder of your own and opens the copy. If you keep it read-only
instead, a script that could not write its output files says so ("some
output files were not generated because Tavotto has no write permission to
this folder") rather than failing mysteriously. Nothing is written into the
read-only folder. (#1515)

## Fixed

**Converting an R / MATLAB script no longer stops at a missing package or
loses the script's output files.**
- A missing package that only shows up while the converted script is test-run
  (for example `openpyxl` behind `pandas.read_excel`) now brings up the usual
  "install" card instead of failing. (#1494)
- After you click install, the conversion is no longer reported as "dependency
  install failed" when the install actually succeeded. (#1499)
- If the test run after installing still finds a fixable problem, the AI that
  did the conversion gets one more chance to correct it instead of the
  conversion failing outright. (#1509)
- Files the original script writes into the project (for example a CSV next
  to the data) no longer count as a validation failure: during the test run
  they are redirected to a scratch area, and the AI is told to keep those
  output lines rather than deleting them to pass the check. (#1516)

**A script that imports from a folder your account cannot read no longer
fails at `import`.** Tavotto skips unreadable entries on the import path and
uses a readable copy of the module if there is one; if a package is the
problem, the usual one-click install card appears. Only when nothing else
helps does a one-line card name the folder. (#1507)

**Windows: fix permissions on a folder outside the project with one click.**
For that last case ("the folder the script loads is unreadable"), the card
now has a "Fix permissions" button: one UAC prompt, then only that one
folder's owner and inherited permissions are restored, and the run
continues. Cancelling says so and does not ask again. Other folders, parent
folders and system locations are never touched. (#1513)

**"Open and run" blocked by safe mode has a way forward.** Tavotto first
tries again from a function entry point; if the script really needs to write
files to disk, the browser version asks once ("Allow and run") to run it
natively for that time. The desktop app still falls back silently as before.
(#1504)

**Relay/proxy address missing `/v1` is corrected automatically.** A custom
"OpenAI-compatible" connection such as `https://api.example.com` used to fail
every request, because the server returned its website instead of the API.
Tavotto now checks the address when you save it and fixes it to `…/v1` when
that is clearly the right one (and does the same for already-saved
connections just before they are used). If a web page still comes back, the
failure card says "The connection address opens a web page, not an API." with
a "Check connection" button. (#1523)

**Image-editing failures say what went wrong.** When the AI itself could not
run (cannot reach the model, invalid credentials, quota, timeout, agent
process error), the failure card now states that in one sentence and offers
"Check connection" or "Retry", instead of claiming the change "did not pass
the pre-write checks". The raw error code is only in the details. (#1524)

**AI panel: figures made by "Run script" can be edited.** Sending an
instruction for a figure that comes from a runtime (script-run) panel no
longer fails with HTTP 404; the AI edits the figure's script and the figure
re-runs afterwards. (#1514)

**AI panel: a figure whose file is gone says so.** The failure card reads
"This figure's file could not be found; it may have been moved, renamed or
deleted", with "Refresh project" as the main button, instead of a "Retry"
that would fail again. (#1510)

**Windows: the rescue page can reinstall Tavotto when its files are missing or
blocked.** If the app's render service files are missing (#1508) or the
system refuses to run them, usually antivirus (#1520), the rescue page now
says so in one sentence, makes "Reinstall Tavotto" the main button, and
suggests adding Tavotto to the antivirus trust list if it keeps happening.
Startup diagnostics record which files were present and the category of the
launch error (no paths or error text). (#1508, #1520)

**First-run welcome.** The welcome page counts as "seen" only after you make
a choice, so closing the app on it shows it once more. When Tavotto starts
straight into a project as a new user (for example from the Codex plugin or
by dropping a script on it), a small "Tutorial" capsule appears in the top
bar instead of the full-page welcome. (#1511)

**Other fixes.**
- On a dark canvas, the line or arrow you are dragging out is now drawn with a
  light outline so it stays visible off the page; the finished annotation
  keeps its own colour. (#1525)
- Adjusting a parameter inside a figure no longer flashes an older image:
  the current figure stays on screen until the new one has loaded, and
  clicks always land on the figure you see. (#1529)
- Replaying a finished entry in the execution record no longer redraws
  every finished row at the end, so long records stay responsive. (#1531)
- Feedback bundles that include source now also carry R and MATLAB scripts
  and the conversion candidate (failed candidates are kept for six hours),
  with email addresses scrubbed from them. (#1498)
- A diagnostics bundle you export now says at which stage an AI request
  failed (as a fixed error category, never the error text), and for
  Tavotto-managed Python environments which packages and versions were
  requested and found, which one failed and whether the next render used
  the new environment. Paths, package-source URLs and credentials are
  still never included; the disclosure before sending lists this. (#1534)
- Dependency bumps: `rustls` 0.23.46 in the desktop shell. (#1474)
