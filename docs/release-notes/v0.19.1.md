# Tavotto 0.19.1

A patch release for people who open an R (or other non-Matplotlib) script
and ask Tavotto to make an editable version. In 0.19.0 a new user could
connect ChatGPT and still be told that no usable Codex was available, be
sent to a terminal to install Python, or see the conversion discarded
because "project files changed". All of these are fixed here, without
opening a terminal.

## Before you upgrade

**The Windows installer is still not code signed.** Expect a SmartScreen
prompt on first run; update packages remain minisign-signed. macOS builds
are signed and notarized as usual.

## Fixed

**Connecting an AI no longer needs a terminal.** If Codex is not
installed, the connection dialog now installs the official Codex CLI inside
Tavotto (from GitHub, with a mirror fallback when that is slow), checks its
size and checksum, shows progress, and then starts the ChatGPT sign-in. The
install lives in Tavotto's own data folder and does not touch a Codex you
installed yourself. Errors say what went wrong (offline, checksum mismatch,
disk full…) instead of "command not found". (#1479)

**Converting a script when no AI is connected opens the connection dialog
and then continues.** Before, the conversion was refused with "AI agent not
installed" and no way forward. Now the dialog opens in place, and once the
connection is ready the conversion starts by itself (once — it does not
loop). The connection state refreshes while the dialog is open and when you
come back to the window, so installing or signing in elsewhere is picked up
without restarting Tavotto. A new user is offered two clear choices first:
sign in with a ChatGPT subscription, or paste an API key. (#1481)

**Clicking Convert again while a conversion runs no longer fails.** The
second click attaches to the conversion that is already running, and after
a minute the card shows how long it has been working. (#1481)

**No more "install Python 3.10 or later" when Tavotto can do it for you.**
When no suitable Python is found — including when the one you installed is
newer than Tavotto supports, such as 3.15 — package management and the
"missing package" card offer to prepare a private Python and a managed
environment automatically, showing the download size first. The message
now says which version was found and which range is supported, and no
longer flickers while Python is being detected. A conversion that needs an
extra package on the built-in runtime offers "prepare automatically and
install" instead of asking you to switch environments. (#1483)

**Validating a converted script no longer writes into your project
folder.** The candidate script now runs from Tavotto's own working folder
while still seeing the paths, working directory and data files of its
future location, so sync clients (Nutstore, Dropbox, iCloud, OneDrive,
Google Drive, Syncthing) no longer upload temporary files. Files that sync
clients create on their own — conflict copies, lock files, `.DS_Store` —
and files whose modification time changed but whose content did not, no
longer count as "project files changed". Before adopting, the comparison
card says exactly which files will be added. (#1480)

**Other fixes since 0.19.0.**
- Resizing a subplot with a locked aspect ratio (`imshow`, `axis('equal')`)
  is now proportional, so an edge snapped to a guide stays there after the
  re-render. (#1476)
- A runtime asset whose script was deleted can be removed from the asset
  library; only its registration and cache are removed, and removal is
  refused while it is in use. (#1475)
- Editing a single figure no longer reports "outside the page". (#1472)
- The font field shows the font actually rendered (for example Times New
  Roman); generic families moved into a "follow the global font family"
  group. (#1470)
- The minimum font-size check now passes a size exactly at the limit, with
  a 0.005 pt tolerance for scaling noise (8 pt no longer fails as
  7.9996 pt). (#1469)
- Panel labels in the full export preview are drawn as they will be
  exported — the label's own font and size — and corners are no longer
  clipped. (#1467)
- The embedded canvas is available again for Codex users who only installed
  the desktop app. (#1468, #1482)
- Interface polish: one spinner everywhere, aligned icon slots, hand-drawn
  empty states and progress bar, an export-success toast, and a redesigned
  execution record panel. (#1463, #1464, #1466, #1471)
