# Tavotto 0.19.0

## Before you upgrade

**Telemetry consent is asked again once (consent version 3).** Version 3
adds three anonymous, closed-set items: an end-of-job export result
(`export_result`), a per-call usage event for Tavotto's MCP tools
(`mcp_tool_call`; no arguments and no returned content), and an optional
error summary attached only when you press Send on a diagnostic report.
If you agreed before, the consent dialog appears once more and says what
was added; if you declined, you are not asked again. Your earlier consent
authorizes nothing new until you agree again, and `TAVOTTO_NO_TELEMETRY=1`
still overrides everything. (ADR 0134, #1103, #1157)

**Everyone sees the new tutorial and the beginner home screen once, even
if you finished or skipped the old tutorial.** The tutorial is now three
steps on a built-in demo (drag the example script in, drag the legend,
change the title size). The demo runs no Python and writes nothing to
your files. On Windows, uninstalling and reinstalling also returns you to
the beginner state; an in-app update does not. (ADR 0136, #1181, #1269,
#1272)

**Choosing an AI now works through “Connect AI”.** Each provider is a
peer in one list, and a model is picked from the connections you have
made. If no AI is connected, repair and the assistant open an in-place
connection dialog rather than sending you to Settings. A connection by API
key no longer needs a coding-agent CLI installed. Third-party interface
presets changed: Codex only accepts the Responses protocol, so
Chinese-vendor endpoints are connected through Claude Code instead; an old
chat-protocol record is refused before launch and can be migrated in one
step. (ADR 0147, #1404, #1405, #1323)

**Python scripts opened from the project folder no longer shadow
installed packages.** The project root is now appended to the end of
`sys.path`, so a same-named package installed in your environment wins,
while the script's own folder stays first, as with `python script.py`.
(#1426)

**The Windows installer is still not code signed.** Expect a SmartScreen
prompt on first run; update packages remain minisign-signed. macOS builds
are signed and notarized as usual. The Windows desktop window no longer has the system title bar;
minimize, maximize and close are drawn at the top right. (#1279)

## Added

**Opening a script that makes a non-Matplotlib figure can produce an
editable version.** For Pillow, plotly, OpenCV, ROOT, R and MATLAB
scripts, the figure assistant writes a separate Matplotlib version, leaves
your original untouched, and lets you compare before adopting it. Needed
packages from a closed list are installed before validation. A Pillow
script that finishes without a Matplotlib figure now reliably offers this.
Inside an open project, R and MATLAB scripts offer the same action from
their asset card and the script library. (ADR 0143, #1277, #1330, #1340,
#1338, #1437)

**“Use your AI to fix it” on every failure card.** The backend picks the
single remedy for each failure type; your connected AI (including Codex or
Claude Code alone, through MCP) then works through a registry of
read-only, change and run tools with risk tiers, local audit, snapshots
and rollback. Commands run either inside a hardened sandbox or, outside it,
only after you approve. It can find a missing data file and connect it
after you confirm, switch to a suitable Python by creating a Tavotto-managed
environment, and hand a conversion to the editable-version flow. When it
cannot fix the problem you get a feedback card. (ADR 0148, ADR 0149,
#1341, #1353, #1371, #1372, #1383, #1381, #1393, #1396, #1398)

**A built-in figure-editing agent.** Tavotto can run its own minimal agent
loop (three protocols, bounded tools, budget, retries, cancellation), so
editing works with an API key and no installed CLI. It runs the same
pre-commit checks you get in the editor and checks that nothing outside
the requested scope changed. Official-login buttons for Codex and Claude
Code are in Settings; Tavotto neither reads nor stores those credentials. Settings lists 15 providers
with real model lists and icons, and Claude Code shows its concrete model
(for example Opus 5.5) with a matching effort level. (ADR 0147,
#1325, #1324, #1316, #1328, #1329, #1419, #1421)

**Source-backed editing of images.** When a figure was saved as a PNG,
Tavotto can rebuild it as an editable figure from its script (on by
default; `experiments.script_backed_figure=false` turns it off), showing a
before/after confirmation, and a PNG that cannot enter editing now gets
one sentence and one way forward. (ADR 0139, #1204, #1205, #1212, #1284)

**Multi-page PDF export.** Several figures written into one `PdfPages` file
can be exported as one multi-page PDF, page order following the script;
figures written into `PdfPages` are now recognised and captured. (#1379, #1394, #1395)

**Direct SVG export, and SVG that keeps editable text.** SVG exports use a
verified snapshot of the figure, keep text as text by default (so Word's
“Convert to shape” leaves editable text), and pair with the PDF from the
same draw. Static SVG images can be previewed and placed on the canvas.
(ADR 0142, #1055, #1283, #1355, #1156)

**Export dialog redesign.** Single-figure and multi-figure modes; a large
square-cornered preview with wheel zoom, drag and double-click reset;
the object header names the file and format that will be written; the
result is one summary sentence; export is always clickable. The export
route (source, checks, EPS availability, pixel preview) is decided by the
backend. (#1295, #1351, #1228, #1244, #1249, #1194)

**Opening and running scripts.** “Open and run” goes from one click to
editing, and a script dropped on the home page runs in the current canvas.
Scripts can ask `input()` / `getpass` questions in the interface;
argparse literals get a form. Preparation is a card at the lower right of
the canvas: the environment is detected automatically, and a missing
package is classified so that uninstallable ones no longer say “one-click
install”. (#1044, #1022, #1267, #816, #815, #820, #859)

**Environment discovery.** Tavotto finds a Python that can run your script
more often, including Conda via `.condarc`, PATH and the Windows registry;
captures Conda activation variables on all platforms; uses your CERN ROOT
install when the script imports ROOT; and explains in “Details” why a
candidate was not used, naming both versions when they disagree. If a
script needs a different Python version, Tavotto creates a suitable managed
environment and reruns it, without asking and without touching yours.
(ADR 0079, ADR 0114, ADR 0142, #1274, #1275, #1282, #1303, #1333, #1342)

**Layout timeline.** It is now a right-panel tab with images fetched at
display width × DPR (no blur), separate per canvas (“this canvas / all”),
and clicking a row opens a compare card. Single-figure editing shows only
that figure's versions. (#1268, #1349, #1350, #1389)

**Canvas and snapping.** Smart alignment: snap candidates with feedback
(thicker own edge, target boxes across figures), proportional-resize
snapping, alignment across figures inside figure editing, page guides,
and softer release. Drag the four page edges to resize the canvas with
live dimension annotations and column-width snapping (single-figure
editing: the figure frame). Single-figure editing versus layout follows the
number of figures on the canvas. Flowchart boxes can be resized. (ADR 0128,
ADR 0127, #1030, #1032, #1033, #1036, #1087, #1281, #1290, #1292, #1352,
#940)

**Compatibility.** 3D surfaces, 3D contourf, scatter and curves enter the
element tree with editable styles (ADR 0135); bar and shape hatch pattern,
hatch line width and hatch colour (with “follow edge”) are editable;
curves without a label take the legend handle's name; a translucent fill
no longer blocks clicking the curve under it; text inside
`AnnotationBbox` and `AnchoredText` boxes is editable like any other text.
(#1159, #860, #972, #1162, #1158, #1434)

**Contact the author, and diagnostics.** A “Contact the author” dialog (top
right) lets you write without logging in to email; replies arrive by
email and in the app, rendered as sent. “Send problem feedback” uploads a
diagnostic bundle you confirm each time (report text, log tail, session
state, environment details; source, crash report and damaged copies are
optional), and unexpected errors show a feedback card at the lower right.
The Chinese interface adds a WeCom entry. (ADR 0145, ADR 0118, #923, #1003,
#1184, #1312, #1344, #1375, #1037)

**Appearance, desktop and updates.** Dark theme with System / Light /
Dark; redesigned shell, settings (with search), dialogs, inspector, canvas
tabs, trees and problem panel; macOS traffic lights and the Windows menu
are folded into the top bar; and fullscreen is handled. In-app updates
prefer a China mirror with GitHub as fallback. A native rescue page
appears when the engine cannot start. The engine's unexpected exit is
detected with a one-click restart. A “Support Tavotto” button is in
Settings > About & updates. (ADR 0121, ADR 0129, ADR 0130, #834, #833,
#828, #832, #831, #829, #994, #1095, #948, #1072, #1040, #1020)

**The desktop app can serve Tavotto's MCP tools.** Desktop builds include
`tavotto-cli mcp`, which runs the same MCP server from inside the
installed app, so an AI editor can be pointed at it without first
installing the engine from PyPI. A pip or pipx install, which does not
carry the server, says so and exits instead. (#1451)

## Changed

**Problems point at the exact field.** Locating a problem highlights the
element, expands “More” and spotlights it on the canvas; the preflight
check only measures what is drawn (legend titles, colorbar ticks and bar
series are no longer reported twice; hidden legends are not reported); and
a clean check now says what the check covered rather than “passed”.
The default group style's minimum font size is inclusive: text at exactly
8 pt passes, and only smaller text blocks export. (#1365, #1366, #1194,
#1433)

**Fewer interruptions.** Errors and warnings are one neutral line; a
build mismatch is a top-bar chip; later notices no longer push the page
down; some explanatory lines in the export dialog and the model list were
removed. Legend placement in the tutorial figure and the example figures'
formulas (Times) were adjusted. (#1107, #1387, #1347, #1315, #1093)

**Windows environment repair.** `conda create -p` environments no longer
crash on missing DLLs: only PATH is supplemented and `activate.d` is not
executed. (ADR 0142, #1411)

**Redraws after export and edits.** All formats of one job come from the
same base; EPS from an SVG asset uses the live Figure instead of rerunning
the script; and an edit made after the script saved uses the Figure as
saved. (#1230, #1314)

## Fixed

**“Ran successfully but no figure.”** Figures still open at `plt.show()` and
closed afterwards, figures written to a temporary file then renamed, and
the last writer of a repeated path are now captured; a partial capture
reports which figure failed (“only N/M drawn”). (#1138, #1126, #1141, #1173)

**Missing-input mislabelling.** `python313.zip`-style unrelated opens are
no longer reported as missing inputs; sandboxed relative globs and
directory listings and C++ readers get an in-script-folder run hint; and
data paths computed from constants are recognised on first open. (#1297,
#1299, #1403, #1417)

**Legend labels.** Renaming a legend entry is not treated as replacing a
curve, and a swap of names is judged correctly. (ADR 0083, #1425)

**Telemetry and diagnostics.** Delivery timeout 3 s to 5 s; diagnostic
sending is per project and reconciles retries; the diagnostic bundle can
include the script that actually failed. (#1221, #955, #1273)

**Codex plugin on Windows.** Background environment repair requests
Windows' no-window flag, so repeated terminal windows (error
`0x800700e8`) stop. After a repair attempt starts, Tavotto waits 30
minutes before trying again; a process that fails to start does not set
the marker. The Codex message points to `provision.log` and the command
for manual repair. `TAVOTTO_MCP_NO_AUTO_PROVISION=1` now also reaches the
server under Codex. (#835)

**Several figures rendering at once no longer cut each other off.** When
more figures render at the same time than the engine keeps alive, the
eviction used to stop a session that was still in use, and the figure
failed with “exited by itself with code 0”. Only idle sessions are evicted
now. (ADR 0004, #1435, #1442)

**The export preview shows your edits.** A figure edited on the canvas was
previewed from the original file on disk; the preview now draws the edited
figure, as the export does. (#1431)

**Python 3.12: deleting an old output no longer fails the run.** In
in-script-folder mode, a script that deleted the same stale file twice
failed with “file operations Tavotto safe mode does not really perform”.
On Python 3.12 the guard's own path check counted as the script reading
the file back. (#1445)

**AI repair writes in your interface language.** With the Chinese
interface, the reasons on approval cards and the summary after a repair
were in English; they now follow the interface language, while package
names, commands, paths and error text stay as they are. When the repair
tools never reached the AI, the card now says so in one sentence instead
of only “the AI could not fix it this time”. (ADR 0149, #1452)

**Smaller fixes.** Links that open in a new window go to the system
browser (#1288, #1302); a Windows window no longer flashes white at
launch (#1286); ticking items in the feedback dialog no longer lags
(#1263); saving no longer warns that an SVG snapshot was not fully kept,
the note now appears when exporting SVG (#1291); two processes sharing a data directory no longer lose checkpoints
(#1211); a refresh or reconnect re-attaches a still-running AI session
(#1111, #1246); a repeated AI edit is not executed twice (ADR 0132, #1098);
usetex figures keep their TeX font (#1359); and only one override address
exists per quantity, so legend title, legend font size and colorbar ticks
take effect (#1367).
