Three things you can see: each side of a subplot's frame now has its own
tick switch, the Codex plugin asks three questions before it draws and then
remembers your answers, and opening a figure from Codex confirms the
project folder with you instead of trusting whatever path the model guessed.
Underneath them, a P1 hole in write-back verification is closed: a divergence
that only changed drawing attributes — not geometry — used to slip past the
clean-replay check and could reach your original files unnoticed.

## Added

**Ticks per side.** A subplot's frame is four spines, and you can now turn
tick marks on or off for each of them separately — `ticks_bottom`,
`ticks_top`, `ticks_left`, `ticks_right` — from the inspector or from a
Codex override, like any other element property. The old all-or-nothing
behaviour is unchanged if you never touch the switches. (#94)

**The Codex plugin asks before it draws.** On the first drawing request of a
session it asks three things through the host's question tool: figure width
(single column 8 cm or double column 15 cm, with a recommendation when you
are unsure), font (Times New Roman and Arial are always offered), and
whether the legend gets a frame. Answer "remember this" and the choice is
stored in your Tavotto config folder — never inside the plugin directory —
and not asked again; `scripts/prefs.py --unset` brings a question back. The
plugin also aligns itself to the latest marketplace version once per
session, tells you before it does, and never blocks drawing on a failed
sync. (#93)

**Drawing discipline for generated figures.** Figures the plugin produces
stay at the two standard widths, keep every font above 8 pt, point ticks
inward with major ticks only, and put nothing on the plot you did not ask
for: no background bands grading your data, no arrows pointing at peaks, no
explanatory captions. If an effect seems genuinely helpful the plugin asks
first. Multi-panel figures are composed in matplotlib itself — one script,
one 15 cm figure, never stitched by another tool — and every subplot
carries its own axis titles and tick labels on both axes rather than
sharing them. When Tavotto itself misbehaves, the plugin now drafts a
reproducible issue and submits it to the tracker only with your explicit
permission. (#93)

**A trusted workspace root for the Codex MCP server.** `project_path` from
the model is a candidate, not a permission. The server now resolves the
boundary through a fixed order of authorities — explicit environment,
host-declared roots, or a native confirmation dialog showing the exact
directory — and fails closed on decline, cancel or timeout. (#87)

**Codex probe knows the macOS ChatGPT app's bundled CLI**, and the AI
settings page echoes an already-saved CLI path instead of silently dropping
it on blur. (#91)

## Changed

**Only axis labels are bold.** The publication profile's text-weight
suggestions now bold axis labels and nothing else; tick labels and legend
text return to regular weight. The check stays suggestion-level — it never
blocks an export. (#93)

**Avatar-ready icons.** `assets/icon/` now ships square PNGs (256/512/1024)
generated from the same SVG as every other icon, for the places that want
an uploaded image rather than an `.icns`/`.ico`. (#93)

## Fixed

**Write-back verification gained a pixel gate (P1).** The clean-replay
check compared geometry — bounding boxes, anchors, sizes — so a divergence
that only changed drawing attributes could pass verification and be written
back to your original files. Staging and replay are now also compared
pixel-for-pixel before commit, with the same state-neutral renderer the
editor uses. (#95, closes #81)

**The static scanner reads ternaries correctly.** The `else` branch of a
conditional expression counts as an output name only when the expression is
a `savefig` argument; previously an unrelated ternary could register a
phantom figure. (#90)

**The MCP server survives a plugin update that removes its working
directory** instead of dying with an unrelated-looking error on the next
call. (#86)
