Three things you can see: the browser playground opens on a gallery of
runnable examples instead of an empty drop zone, the whole core editing
path now works without touching the mouse, and the right-panel inspector
has been rebuilt around the object you selected. Underneath them, the
Windows in-app update chain is repaired end to end — this is the first
release whose update packages the desktop updater can actually consume —
and a WebView2 white-screen caused by broken Windows registry MIME
associations is fixed for good.

## Added

**Examples-first playground.** `/try` now opens on a gallery of runnable
examples with real cover images; uploading your own script is still one
drag away, but no longer the only door. Every example runs for real in
Pyodide — no pre-baked previews — and the Code Sheet expands alongside the
canvas so you can see the script that drew what you are editing. (#108)

**A pure-keyboard golden path.** Selecting a panel, opening the inspector,
editing a property, undoing, and exporting now all work without a mouse.
Four keyboard-accessibility holes are fixed along the way — focus no
longer escapes into the void after a dialog closes, and dialogs, inputs
and the inspector sections are reachable in a sane tab order. A Playwright
E2E drives the whole path with nothing but key presses to keep it that
way. (#109, closes #37)

**Codex plugin first-use experience.** The README gains a real first-use
entry for the plugin, the drawing skill carries a session-entry state
machine so a fresh Codex session knows what to check before drawing, and
`openai.yaml` declares the MCP dependency explicitly instead of assuming
the host figured it out. (#118)

## Changed

**The inspector is organised around the object.** The right panel now
leads with what you selected — object first, then its visual properties,
then everything else — with visual pickers where a swatch or a shape says
more than a dropdown. On 1366-px screens both panels can now coexist.
(#104)

**MCP preflight speaks the widget's language.** Preflight entries in the
embedded Codex canvas used to arrive as fixed Chinese prose from the
Python evaluator. The evaluator now sends a translatable descriptor
(`message: {key, params}`) with every issue and the widget renders it in
the Codex host's locale, falling back to the original prose only for
engines that predate the protocol. (#113, part of #30)

**English error recovery, verified.** The error paths a non-Chinese user
actually hits — a script that raises, a missing AI CLI, an offline update
check — are now driven by an English-locale E2E, which flushed out two
places where Chinese system copy leaked into the English UI. (#114, part
of #30)

**Release pages tell you what is supported.** The download section of
every GitHub Release is now generated from the support matrix — one
authoritative file — and the README explains the Windows SmartScreen
prompt instead of leaving you to wonder. (#107)

## Fixed

**Windows in-app updates work again.** Since v0.7.0 the Windows update
packages were re-zipped with a compression method the updater plugin
cannot extract, so every in-app update on Windows failed after download —
while the release pipeline stayed green. The packaging step is fixed, a
nightly job now consumes the published packages exactly the way the
updater does, and the installer's branding bitmap and a duplicated text
annotation display are repaired in the same change. **If you are on
0.7.0–0.10.0 on Windows, this one update must be installed manually** —
download the installer from this release; in-app updates take over from
here. (#101)

**No more white screens from Windows registry MIME associations.** If
another program had claimed `.js` files in the Windows registry, the
desktop app served its own JavaScript as `text/plain` and WebView2
rendered a blank page. Bundled assets now carry their MIME types
explicitly, and the app clears poisoned HTTP caches on the next start so
an already-affected install heals itself. (#116, closes #115)

**The floating context bar yields to the drawer.** On narrow layouts the
text context bar no longer floats above the overlay drawer it was
supposed to sit under. (#106, closes #105)

## Notes

- Merging now goes through a GitHub Merge Queue: PRs get fast feedback,
  and the full cross-platform qualification (packaging on three
  platforms, two real-artifact smokes) runs once on the final combination
  of main plus the queued PRs. Coverage is unchanged; only when it runs
  moved. (#119, #120)
- The nightly Windows install-chain check was red for seven nights over a
  stale fixture filename left behind by the Magplot → Tavotto rename; the
  fixture and the assertion are fixed, and the legacy-registry read
  fallback — which that fixture was silently the last thing exercising —
  now has an explicit test. (#124, #125)
- Upgrading from 0.7.0 or earlier on desktop still requires uninstalling
  the old version first (the app identifier changed in 0.8.0).
