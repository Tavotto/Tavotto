# Tavotto 0.21.1

Export an edited copy of your Python script, search fonts by name, and use real
bold and italic faces in canvas labels. Connected AI editors now receive the
same usage guide and keep it up to date. This release also fixes desktop journal
catalog updates, Windows script drag and drop, and figures that stayed empty
after changing the script's working directory.

## Before you upgrade

**Dragging an uncropped figure's edge outward in a layout now resizes the
figure.** The opposite edge stays in place, the figure's text keeps its pt size,
and the figure re-renders when you release. Dragging inward still crops. A
cropped figure stops at its full edge and asks you to remove the crop before
enlarging it. Existing crops are kept.

**Connected AI editors refresh their usage guide when the desktop app starts.**
A copy you edited is left alone; Settings marks it as "Skill edited, not updated"
and offers Overwrite. If **Download updates in the background** is on, an
outdated Codex plugin is also updated automatically at startup. Turn that setting
off, or set `TAVOTTO_DISABLE_UPDATE_CHECK=1`, to keep the plugin as it is.

**Update downloads use a different source policy in mainland China.** Small
version checks still try the mirror first, but installer downloads now try
GitHub first. Background downloads and downloads you start yourself follow
different rules, described below. This takes effect once you are running a
version containing the change: an older installed app keeps its previous
behavior while downloading this release.

**The app grows by about 20 MB** to include real bold faces for the built-in
Noto fonts, including Chinese text.

## Export an edited Python script

**The export dialog has a new PY option alongside the image formats.** It saves
`<name>_edited.py` in your export folder, with supported figure edits expressed
as ordinary Matplotlib calls. The exported script does not import Tavotto.
Your original script stays byte-for-byte unchanged, even if it already has an
`_edited.py` name that would collide with the export.

- Export the script by itself or together with your figures. This works for
  individual script-backed figures from scripts that call `savefig` or
  `plt.show()`, including font changes. "Export each figure separately" can
  produce an edited script for each figure; a whole layout or a combined
  multi-page PDF does not have a single corresponding script.
- Tavotto re-runs the generated script and checks its geometry and pixels before
  delivering it. If verification fails, that `.py` is not exported; image
  formats can still finish. Edits that cannot be written into the script are
  reported separately, so a partial script export is not presented as containing
  every adjustment. The desktop notification gives the count; the browser
  result also lists the affected items in its details.
- Scripts that read data through relative paths still need their original data
  and environment. Put the exported copy beside the original script to run it;
  export does not rewrite data paths or bundle dependencies.
- For `bbox_inches="tight"`, the generated adjustment block keeps the crop box
  you saw in Tavotto. If you later change the script's data and want automatic
  tight cropping again, remove the last argument of `_install` in that block.
- PY is not remembered as an export default because verification runs the
  script again. Select it for each export where you need a copy. This option is
  currently in the export dialog, not the MCP tools.

**Export receipts are shorter.** File details focus on the filename, dimensions
and save location. Check failures still appear; the repeated "Checked", "Not
checked" and "replaced" labels are gone. File verification and the strict
file-check setting still apply.

## Fonts and figure editing

**Find fonts by English or Chinese name.** The font menus for figure text and
text annotations now have a search box. Quickly switching from the English
font menu to the Chinese menu no longer lets the closing menu steal focus and
close the new one. Enter or Escape still returns focus to the menu's button.

**Bold and italic labels use the font's real faces on the canvas and in
exports.** This includes bold or italic spans within a line. Chinese labels can
now export with the built-in Noto bold faces. A font you choose uses its own
bold and italic faces when available, such as Microsoft YaHei Bold; fonts
without them, such as SimSun, use simulated bold or italic in the same way as
Word. The canvas and export follow the same choice.

**Widen a figure in a multi-figure layout without scaling its text.** Previously,
dragging an uncropped edge outward stopped with "At image edge · right not
cropped". It now changes the figure's dimensions and redraws its contents when
you release. The opposite edge stays fixed and the figure's text keeps its pt
size. Inward drags continue to crop; remove an existing crop before enlarging.

**Border, tick and grid controls no longer hit an unexpectedly small limit on
scaled figures.** A figure displayed at 45% could previously stop at a border
width of 1.36 pt. Border width, tick width and grid width now allow up to 10 pt
before layout scaling, and tick length up to 20 pt, matching Style settings.

## Journal standards load correctly in the desktop app

**The journal list could stay limited to the built-in entries even after a
larger online catalog was published.** Restarting did not help because the
packaged desktop app was missing CFFI's native backend, which PyNaCl needs to
verify catalog signatures. That dependency is now included. Desktop build and
smoke checks verify a known signature and reject a tampered message so an
incomplete package fails before release.

**The roughly 3,700 journals refer to the online catalog, not the number bundled
with the installer.** The built-in subset works offline. Additional journals
are downloaded when selected and kept locally after signature verification;
the existing daily download allowance is shared with connected AI editors.
`TAVOTTO_NO_JOURNAL_SYNC=1` still disables these requests.

**The journal picker scrolls normally inside Settings.** Its list used to ignore
the mouse wheel and touch scrolling unless you dragged the scrollbar. The fix
also applies to other pop-up lists opened from dialogs.

## Connected AI editors get the same guide and update reminders

**The managed Codex installer now installs Codex 0.167.0.** Platform downloads
remain pinned to verified hashes from the official registry and mirror.

**Connecting an editor also installs the Tavotto usage guide.** Settings now
copies the skill into the user folder for Claude Code, Cursor, VS Code, Trae,
ZCode, WorkBuddy and Antigravity, giving their AI the same instructions as Codex.
Disconnect removes the installed copy unless you edited it. Claude Desktop,
which has no skill folder, reads the guide through the new `tavotto_guide` tool.

**Existing connections get the current guide at desktop startup.** Settings
shows the installed version for each editor, identifies edited copies without
overwriting them, and marks an outdated Codex plugin as "Update available".
The background-update setting controls automatic Codex plugin updates as
explained above.

**AI sessions using MCP tools can now mention a new Tavotto version.** Previously,
only the desktop hand-off path carried the reminder. `tavotto_health` and a
successful `tavotto_export` now include it, and the AI passes it on once at the
end of the task. The check runs in the background without delaying tool calls.
When GitHub is unreachable, it can read the public version index on the Tavotto
download mirror; this check reads a version number and downloads no installer.
The existing update-check switches still disable it.

## Update downloads in mainland China

**Background downloads start with GitHub without switching merely because it
is slow.** The version check still tries `dl.tavotto.cn` first. A failed or
stalled GitHub download can fall back to the mirror. After about three failed
attempts, subsequent background downloads try the mirror first. They also try
the mirror first when the new version has been available for more than about
three days, remains undownloaded, and this computer has already tried at least
once.

**Download and install gives GitHub a short trial and can switch to the
mirror.** When you start the download yourself, Tavotto tries the mirror if
GitHub sends no bytes for about eight seconds. If bytes do arrive, Tavotto
measures their speed for about eight seconds and tries the mirror when the
estimated remaining time is clearly over two minutes. The mirror takes over
when it starts sending data; the two sources' speeds are not compared.

Both paths keep the same version you were shown and verify the installer with
the same built-in key. Outside mainland China, the source policy is unchanged.

## Windows, script recovery and AI fixes

**Dropping a script on Windows no longer sends you back to the file picker when
native drop support is available.** A message-format mismatch in the WebView2
bridge prevented the app from recovering the dropped file's path. The native
handler and the web view now exchange the same JSON string.

**Changing the working directory refreshes figures that previously drew no
data.** A script could finish successfully with an empty curve because a relative
file search found nothing; choosing the correct working directory then left the
old empty figure on the canvas. Tavotto now invalidates figures and captured
results from the old directory, ignores render responses that arrive late, and
rebuilds against the new directory. A PNG waiting for your directory choice
continues through its existing source validation.

**The AI fix assistant can run the individual command you approve on Windows.**
A repair such as installing a missing program into your Conda environment could
stop with "not supported on this computer" even after you approved the fix,
because a protective sandbox was unavailable. The assistant now presents a
separate confirmation card showing the full command straight away. Nothing runs
until you agree, and that approval covers only that command.

A bare `conda` command also finds the Conda installation that owns the selected
environment when it is absent from PATH. Diagnostic bundles identify missing
external programs for runs in your own Python as well as in the built-in
runtime.
