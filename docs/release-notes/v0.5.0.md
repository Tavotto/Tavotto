This release is about trust and reach. The one bug that could genuinely lose
your work — object positions silently reverting with undo unable to bring
them back — is found and fenced off at three levels. Script-drawn arrows,
editable since 0.4.0, are now fully movable. Copy/paste finally works across
browser tabs everywhere, including Safari and the desktop app. Exports and
saved canvases land next to your project instead of a hidden data folder.
And both installers got a proper Magplot face.

## Added

**In-figure arrows are movable.** 0.4.0 made script-drawn arrows editable
but kept their positions locked to the script. In practice you asked to
place them freely — so now standalone `FancyArrowPatch` arrows can be
dragged as a whole or by either endpoint (with a live preview while you
drag), and both arrow style (solid/open/double heads, brackets and more)
and line style are switchable. Everything remains a non-destructive
override: undo works, and an empty override list restores the script's
original geometry exactly. Arrows attached to `annotate()` keep their data
anchors — the annotation machinery repositions them on every draw, so
Magplot deliberately offers style only.

**Write back from the top bar.** "Write back to original file" is a
high-frequency action, so it now lives permanently next to Export. It
targets the panel you are editing, the panels you selected, or every panel
on the canvas with unwritten changes — and can write several panels back in
one confirmed step, listing exactly which files will be overwritten and
where the backups go.

**Installers that look like Magplot.** The macOS disk image opens onto a
designed drag-to-Applications window — brand mark, paper background, a
single arrow showing what to do. The Windows installer is rebuilt on a
minimal branded template: no welcome page, one quiet progress bar, no log
noise, Magplot colours throughout.

## Changed

**Your output lands where you can find it.** Exports now default to a
`<project>-exports/` folder right next to your figure directory (a custom
export directory in project settings still wins), and "Save as canvas
file" writes into `canvases/` inside the project — visible, backupable,
and synced along with your figures. Canvas files saved by earlier versions
remain visible read-only from the old location. Autosaves, version history
and styles stay in the application data directory as before.

## Fixed

**Undo can no longer lose positions.** A drag interrupted by undo — easiest
to trigger through the desktop menu's ⌘Z accelerator, which bypassed the
in-drag guard — used to commit-and-revert the drag mid-flight, after which
the remaining pointer movement was written to the document *outside* the
history. Undo then restored some objects but not others, and the lost
positions were unrecoverable. Three fences now: history-less transaction
updates are dropped instead of silently applied, every undo entry point
(keyboard, top bar, desktop menu) goes through the same in-drag guard, and
a corrupt history entry is discarded instead of leaving the document and
the undo stack disagreeing.

**Copy/paste works across tabs — in every browser.** Object copy/paste now
rides the native clipboard events (synchronous `clipboardData`) instead of
the async clipboard API, which WebKit refuses outside editable fields.
Copying a panel in one tab and pasting it in another now works in Safari
and the desktop shell, and Firefox gains object paste for the first time.
Text fields are never hijacked.

**Canvas tabs: reordering and instant switching.** Dragging a tab to
reorder it actually works now (the drag never started in Firefox/WebKit),
with a visible drop target. Switching tabs no longer rebuilds the whole
canvas — each open tab keeps its rendered layer alive, so switching back
and forth is instant, with no white flash and no re-decode.

**Desktop assistant finds node.** Launched from Finder, the app inherits a
minimal PATH without `/opt/homebrew/bin`, so npm-installed codex died with
`env: node: No such file or directory` despite being detected. CLI child
processes now run with the common install locations appended to PATH —
detection and execution alike.

## Upgrading

Desktop: download the new installer from this release and install over your
existing copy. pip/pipx: `pip install -U magplot` (or let "Check for
updates" do it). Projects, layouts and settings are not affected; newly
saved canvas files simply start appearing inside your project folder.
