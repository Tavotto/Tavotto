The scripts AI assistants actually write — `plt.plot(...); plt.show()`, no
saved file, no special structure — now open in Tavotto like any other
figure. That is the headline: the Compatibility Bridge closes the gap
between "the script draws fine" and "Tavotto can edit it". Around it,
alignment edits no longer corrupt layouts, the settings page tells you
exactly which coding agents this build supports, a one-click diagnostics
bundle makes bug reports debuggable, and a desktop-wide UX consistency
pass smooths the edges you hit every day.

## Added

**Run-and-discover for show-only scripts.** The asset library's script
section gains "run and discover figures": any `.py` in your project —
including ones static analysis can't parse — can be probed in a sandboxed
one-shot worker, and every figure it draws becomes a first-class,
editable Runtime Figure asset (save, reopen, replay, compose, export;
structural write-back is refused rather than guessed). Multi-figure
scripts get a picker in the UI and `--stem` / `--pick-script` in the CLI.
On the compatibility baseline, 16 cases move to full support — 134 full,
0 product bugs. (#127)

**Coding-agent registry.** Which AI coding agents this build can drive is
now declared in one place and reflected honestly in the settings page:
each agent shows real install/auth/readiness state, and "needs
authentication" is no longer conflated with "not installed". (#128)

**One-click diagnostics bundle.** Settings gains a diagnostics export: a
ZIP with environment info, a privacy-scrubbed frontend event trace (user
text, absolute paths and override values never enter it — enforced by
dedicated tests), and engine state. Incoming payloads are validated
against per-event field allowlists and size-capped. (#139)

**Desktop UX consistency pass.** Batch style editing across text roles,
tick-direction and minor-tick task cards, a rebuilt AI model &
reasoning-strength popover, and progressive disclosure in settings — with
before/after evidence from the real app. (#142)

## Fixed

**Align no longer corrupts layouts.** Clicking left-align could silently
break the layout and lose position markers: the display-fallback pipeline
was allowed to write geometry it did not own. Geometry authority is now a
hard gate with a single authoritative predicate, undo after an edit
restores the exact previous variant instead of re-rendering a guess, and
version previews no longer bleed across projects. (#137, closes #131)

**Windows worker directories no longer leak.** One-shot replay workers
could leave `_replay-*` directories behind (kill-without-wait racing
rmtree against file locks), polluting later runs — the top CI flake for
two releases. Workers are now reaped with a timeout before their
directories are removed. (#129, closes #46)

**3-D tick editing writes to the right axis.** Selecting Z ticks on a 3-D
figure no longer routes edits to the X/Y axes, and Z-specific fields are
no longer hidden from the generic property list. (part of #142)
