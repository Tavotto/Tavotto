# 流程图框宽高编辑：可行性与验证

## 需求与现状

用户提供的 Matplotlib 流程图脚本有 12 个 `FancyBboxPatch`：阶段侧框、主流程框、
一个包含两个子框的外框。框里的字是独立 `Text`，连接线是独立的空文字 `Annotation`。
脚本使用线性坐标轴、标准 `round` boxstyle 与 `tight_layout`，保存 PDF / PNG 后调用 `show()`。

修改前，真实脚本进入 Tavotto 后 12 个框都已被识别为可拖动的 `patch`，没有框的宽高字段。
现有 `resizable` 表示的是子图 `axes.position`，不能直接拿来缩放图框，否则会改整个坐标轴。
沿用现有 artist override、图内预览、撤销和文档格式即可实现。

公开测试使用独立合成的 12 框嵌套流程图（`tests/fixtures/flowchart_resize.py`）。
原始脚本仅作本地验收，脚本和导出图件不进入仓库。

## 用户操作

进入图内编辑并选中受支持的矩形 / 圆角框后，可以：

- 拖动四个边中点独立改宽或高，或拖动四个角同时改宽高；对边 / 对角固定。
- 在右侧「图框尺寸」中输入页面上的 W / H（mm）；数值编辑固定左上角。
- 连续拖动数字时查看目标框预览，结束后一次提交；按 Escape 取消。
- 撤销 / 重做，或只恢复尺寸。位置与尺寸是可分别撤销的属性。
- 保存排版、关闭服务、重新打开，继续编辑并导出 PDF / PNG。

调整尺寸只改变选中图框。独立文字的内容、位置与字号、箭头端点、嵌套子框的尺寸不会随之改变。
现有「整体拖动框时带着内容移动」仍走原来的 `patchContents` 规则。

从 `.py` 运行得到的图把编辑保存在 Tavotto 排版与自动保存中；导出生成新的图文件。
Python 源码保持不变。已有 PDF / PNG 原图的「更新原图」事务同样接受尺寸 override，
经过热态 / 重放、几何与像素验证后再提交。

## 几何契约

| 字段 / 属性 | 含义 |
| --- | --- |
| `size_frac: [w, h]` | 图框路径外框宽高，相对于根 Figure 的当前图幅；包括 FancyBboxPatch 的 padding，不额外加描边宽度 |
| `pos_frac: [x, y]` | 沿用独立 Patch 的左下角锚点，y 向下 |
| `shape_bounds: [x, y, w, h]` | 引擎实际画出的未裁剪外框，左上角、y 向下；供手柄与宽高控件读取 |
| `shape_min_size: [w, h]` | 保留原有 padding / 圆角所需的最小外框宽高 |

手柄和数值控件提交 `size_frac`；只有左下锚点按 override 精度比较后确实移动，才在同一次
文档提交中附带 `pos_frac`。只改宽度或拖上侧 / 右上角时不新增位置覆盖，保留脚本的 data /
axes 相对定位，让图框继续跟随子图布局与坐标范围变化。用户原有的位置覆盖不会因此删除。
图内元素原来的 `bbox`、路径命中与裁剪语义不变；新增框尺寸能力也不设置 axes 专用的 `resizable`。
几何编辑必须基于当前文档对应的已挂载、精确 manifest。控件从 `useDisplayedExactManifest`
按 gid 解析元素，位图预览使用配对清单，不能用 canonical 清单中同 gid 的另一个对象替代。
SVG 解码交接期间暂停尺寸输入并取消数字拖动，其他样式与选区保留；提交动作再同步检查挂载版本。
控件读取 `shape_bounds`，避免显示已被引擎拒绝的尺寸。取消、回到原点、重复输入当前值都不产生新编辑。
页面 mm 换算使用 `panelFullRect`；旋转 / 翻转后的指针位移复用既有内容坐标换算。

后端通过原生 `set_bounds` 改矩形宽高，保留 boxstyle、mutation scale / aspect、padding、
rounding size 与 linewidth。
尺寸与平移共用原生几何和布局 pin，恢复尺寸不清掉位置，恢复位置不清掉尺寸。
布局重新计算前暂时放回脚本原样，完成后再按新的变换放置，保证不同 DPI、tight / constrained
布局下热态渲染、全量重放与导出一致。

`size_frac` 纳入后端图幅相关属性与重放顺序、前端几何写入校验。
切换 `figure.frame` 时尺寸只除以新 frame 的宽高，不能像点位一样减去 frame 原点。
组图 ↔ 子图同步跳过尺寸：某张图上的布局宽高不能当作样式搬到另一张图。
它不加入前端随行元素的点位属性集合，也不进入样式预设或多选批量属性编辑。

## 支持边界

本次开放具有可靠原生几何的轴对齐 `Rectangle`，以及标准 `BoxStyle.Round` / `Square`
的 `FancyBboxPatch`。变换必须是可逆、轴对齐的仿射变换，且归图幅、坐标轴或英寸坐标管理，
才能保证更换导出 DPI 后尺寸仍然一致。继承原生实现而不改绘制 / 路径 / 几何方法的子类可以使用。

柱形图的数据柱、旋转或剪切的矩形、非仿射 / log / 投影变换、固定像素坐标、其他 boxstyle
以及改写几何的用户子类不宣称可改宽高。它们继续使用原有的选中、样式或拖动能力。

宽高下限由原始 padding 与圆角决定；前端按 override 的精度向上取整下限，后端再次校验。
非法 / 非有限 / 过小的新值在修改几何前拒绝。如果已有合法值因后续坐标轴变动而不再适用，
后端恢复该框的原生尺寸、保留有效位置，并报告 warning；写回不能把这类失败当作成功提交。
回到支持的变换或输入合法尺寸后可以继续编辑。
