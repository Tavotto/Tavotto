## 实现批次

- **N1（批次 A）**：rotationDeg（text/shape/arrow）+ 格式刷。
- **N2（批次 B）**：文字（下划线/行距/内边距/背景/描边）、形状（圆角矩形/
  三角/菱形/多边形/大括号）、线条（独立端型 triangle/open/bar + 虚线）、
  填充透明度。前端模型 + `_draw_text/_draw_arrow/_draw_shape` + exportPayload
  + pytest 同步扩展。
- **N3（批次 C）**：预设面板（组合生成既有对象，标 ⬜ 的依赖弧线/折线，
  留给后续批次，不做假入口）。
