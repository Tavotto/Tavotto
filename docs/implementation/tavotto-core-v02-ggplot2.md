# R／ggplot2 原生图形

在桌面版脚本库的 R 脚本旁选择「用 R 运行」。填写脚本生成的 ggplot 对象名和图幅尺寸。可指定本机 Rscript 的路径。留空时查找桌面进程 PATH 中的 Rscript。脚本在自身所在目录以当前账户的权限执行。

R 运行时须安装 ggplot2、svglite 和 jsonlite，并能打开 Cairo PDF 图形设备。部分 macOS R 发行包需要 XQuartz 提供图形库。Tavotto 在执行脚本前实测 PDF 设备是否可打开。版本与支持等级见[支持矩阵](../support-matrix.json)。

已有 RStudio 或 renv 项目可在 R 控制台查看 `.libPaths()`，再在「R 包库目录」选择希望优先使用的库。这次运行会优先从该目录加载包，再查找所选解释器的默认库。已安装的包和项目启动文件保持原样。

进入图内编辑后，在元素树中选中普通文本的图标题、副标题、图注、坐标轴标题或图例标题即可改色。副标题和图注分别定位到图上实际绘制的文字，并沿用脚本设置的对齐方式。上、下、左、右各轴按图上实际绘制的标题独立编辑，包括次轴。图例按实际绘制的标题选择，标题文字需要能唯一识别该图例。公式和主题隐藏的文字不提供改色。适配器在会话内保留一次构建得到的 gtable、统计图层和范围。改色、撤销与导出只重绘这份已计算的结果。脚本通过标准输出生成的文字与会话控制分开传输。

普通 `facet_wrap()` 和 `facet_grid()` 的单层纯文本分面标签可分别改色。标签文字在同一侧需唯一。元素树会列出可定位的标签，横排和竖排标签都沿用图中实际位置。

普通 `guide_legend()` 中的纯文本条目也可分别改色。每个可编辑的图例需有唯一的纯文本标题，条目文字在所属图例里也需唯一。保存的改色同时绑定图例标题、条目文字和绘制位置。

进入图内编辑后，可在画布上拖动 ggplot2 的图例框。一个位置上的多份指南与共用背景作为一个图例框移动。上下左右和图内的图例框各自定位，保留原来的图幅、坐标轴布局和统计结果。可以撤销拖动，也能保存位置并在冷重开后继续导出。

普通 `guide_colourbar()` 可分别修改标题和整组刻度文字的颜色，横排与竖排色条均可用。刻度编辑要求唯一的纯文本图例标题和一组普通字符或数值标签。色带、刻度线、标题与图形沿用原样。 [ggplot2 连续色条指南](https://ggplot2.tidyverse.org/reference/guide_colourbar.html)

选中有唯一标题的连续色条，可在属性栏改调色板与数值上下限。线性和以 10 为底的对数颜色或填充尺度可联动普通散点、方格、矩形和栅格。范围使用原数据单位，对数色阶的端点必须为正数。色条与同一尺度下的所有图层用同一份配色计算，改范围时超出上下限的数值使用相应端点的颜色，原来的缺失值颜色照常使用。自定义标签可保留并切换调色板。数值范围编辑使用原生自动刻度，也可叠加已支持的数字格式编辑。同一原生尺度同时映射描边和填充时，合并后的单条色条也能调整整个尺度。

选中普通连续色条，可在共用属性栏切换横竖，并分别在最小值、最大值或两端添加三角延伸。原图用了反向色条时，三角仍跟随数值端和该端颜色。单独改方向或延伸沿用原来的数据配色，可以和已支持的调色板、范围、标题及刻度编辑叠加。若同一尺度画了多条色条，方向和延伸作用于选中的色条，调色板和范围仍联动整组。 [ggplot2 连续色条指南](https://ggplot2.tidyverse.org/reference/guide_colourbar.html)

普通连续色条还可以修改或补上标题、设置刻度字号与颜色、隐藏整条色条。隐藏时保留原来的布局空间，图中的数据配色和其他图例照常绘制。

**跨语言色阶合同。** `colorbar` 元素在清单中提供方向 `orientation` 和两端延伸 `extend`。能编辑数据映射的色条还提供 `vmin`、`vmax`、`cmap` 和当前色标。属性栏、覆盖项、撤销、保存与导出都消费这一形状。字段规则在 `engine/colorscale.py`，调色板由 `resources/color_palettes.json` 提供，保存 Matplotlib 命名色图的 256 项 RGB 序列。前端取同一目录的缩略色标。语言适配层负责识别哪些图层共享尺度、捕获已计算的数值，并把变更落到原生色条和图层。ggplot2 通过已计算图层和原生指南重绘，统计与位置计算只在原脚本捕获时运行。

普通单面板图支持按轴侧修改整组刻度文字颜色，包括实际绘制的次轴。每侧的字符或数值标签须由一个原生文字组绘制。使用公式、分行或自动避让的刻度继续沿用脚本样式。改色保留刻度线、文字排法和原数据位置。 [ggplot2 坐标轴指南](https://ggplot2.tidyverse.org/reference/guide_axis.html)

普通坐标轴和连续色条的刻度文字与原始数值逐项对应时，选中刻度文字可切换数字格式。固定小数位、通用格式和科学计数法只改变显示的文字。色条标注位置与图内数据的颜色对应沿用原尺度。普通单面板线性轴可在「刻度定位」选择固定间隔。线性轴和以 10 为底的对数轴也可输入一组固定位置，数值使用原数据单位。主刻度与主网格线一起变化，范围之外的位置会保留到下次编辑，绘图区范围保持原样。带次轴、特殊次刻度或自定义标签的轴保留原来的刻度定位。 [ggplot2 连续位置尺度](https://ggplot2.tidyverse.org/reference/scale_continuous.html)

单面板上能与原生数值逐项匹配的普通轴刻度还可按侧调整字号。刻度占用的空间由原生轴重新测量，其他轴侧和数据图层沿用各自的样式。

选中普通连续轴的刻度组，可在共用的「小刻度」控件显示或隐藏次刻度。线性轴支持设定次刻度间隔，次网格若已开启，会跟随同一组位置。对数轴支持原生自动次刻度。关闭次刻度线时，已经开启的次网格继续显示。撤销会恢复 R 脚本中原有的刻度。 [ggplot2 坐标轴指南](https://ggplot2.tidyverse.org/reference/guide_axis.html)

普通直角坐标轴的刻度线可按侧调整长度和线宽，主刻度和次刻度分别设置，单位为 pt。属性栏也能让刻度线朝内、朝外或跨在轴线上。跨轴的刻度线各有一半在轴线两侧，保留设定的总长度。各项独立保存，刻度位置和颜色沿用原图。

可在刻度组的「显示」开关隐藏该侧的刻度文字。刻度线仍会绘制，恢复显示后可继续使用已经设置的字号、字体和数字格式。

普通 `facet_wrap()` 和 `facet_grid()` 的连续轴可从分面上的实际刻度选中对应轴侧。主、次刻度位置及数字格式按 ggplot2 实际共享的尺度联动，匹配启用的网格线。字号、刻度文字显隐和刻度线样式可按可见轴侧独立编辑。开启次刻度后，可以为已有的次刻度添加数字标签。

在普通单面板图中选中子图，可在与 Matplotlib 相同的属性栏设置 X／Y 最小值和最大值，并在线性轴和以 10 为底的对数轴之间切换。端点始终按原数据单位从小到大输入。X／Y 轴可各自反转，并与范围、对数轴和固定刻度搭配。脚本用 `coord_cartesian(reverse = ...)` 设置的方向也可切换。对于支持的 `geom_raster()` 图，反转会同时调整色块次序和整张栅格在绘图区的位置，保持颜色与数据坐标对应。改范围只裁剪显示窗口。切换轴类型会重新投影已计算的位置与区间，并重建刻度，保留本次 R 运行得到的统计和分组结果。对数切换要求该轴上参与绘制的位置为正数，包括误差棒的端点和柱形的基线。原脚本中的范围过滤和自定义位置尺度沿用其原始设置。 [ggplot2 显示范围](https://ggplot2.tidyverse.org/reference/coord_cartesian.html) · [ggplot2 连续位置尺度](https://ggplot2.tidyverse.org/reference/scale_continuous.html)

普通 `dup_axis()` 镜像次轴和 `sec_axis()` 数值换算次轴会随主轴调整范围、反转和可用尺度。默认刻度按当前尺度重新计算，明确指定的刻度及标签沿用脚本设置。若次轴换算无法覆盖新范围，或换算在该范围内失去单调性，编辑会被拒绝。

同一属性栏也提供对称对数与对数几率。对称对数采用 Matplotlib 的默认尺度，在零附近使用线性刻度，可显示正数、零和负数。对数几率使用 R 的原生概率变换，要求图层位置和手动输入的范围端点都严格在 0 与 1 之间。两种尺度都保留 R 已算出的图层位置，可叠加轴反转和固定主刻度。 [Matplotlib 尺度定义](https://matplotlib.org/stable/api/scale_api.html) · [R 概率尺度](https://scales.r-lib.org/reference/transform_probability.html)

普通 `facet_wrap()` 和 `facet_grid()` 的连续坐标轴也使用这组控件。范围、尺度和反转会应用到实际共享该轴的分面，独立配置的轴可以分别编辑。可从同组任一分面继续调整或恢复。反转也支持普通 `geom_raster()`，图块的排列与位置会一起更新。

使用原生矩形面板边框或普通轴线的图，可逐边开关边框，并给全部边或某一条边单独设置颜色和线宽。逐边样式优先于整框样式。保存和导出使用当前边框，清除编辑后恢复原主题。

普通单面板子图可在共用属性栏设置绘图区底色或改为透明。底色覆盖的范围是坐标轴内的绘图区，图幅底色、原生矩形描边和数据图层沿用原图。

在普通直角坐标图中，可用共用属性栏按 X／Y 开关主网格，并修改主、次网格的颜色、透明度、线宽和线型。网格沿用原生刻度位置，类别轴也可用。`facet_wrap()` 和 `facet_grid()` 的每个分面可从画布或元素树单独选择。网格、绘图区底色与普通矩形边框的修改作用于所选分面，其他分面、共享轴、刻度与数据保持原样。移除编辑后恢复脚本主题。 [ggplot2 主题](https://ggplot2.tidyverse.org/reference/theme.html)

普通 `geom_point()` 系列复用散点属性。固定大小、形状和透明度可独立编辑，标记支持实心圆、方形、三角形和菱形之间替换。使用 `facet_wrap()` 或 `facet_grid()` 时，可在元素列表按分面选择，只调整这一格的散点。对使用标准形状、离散颜色或离散填充图例的散点，可以按实际数据类别修改适用的固定样式。同一类别在各分面的点和图例键会一起更新。即使两个类别同色，也能独立编辑。多个映射共用同一图例时，类别须逐点一致。由数据映射或图例单独指定的样式保留原设置。统一着色的实心散点可改填充色。对有独立填充和描边的标记（R 形状 21 至 25），可分别编辑填充色、描边色和描边宽度。各项只作用于对应的未映射样式。连续颜色映射沿用原尺度。改动沿用已计算的点位，并可与已支持的连续色阶和色条布局编辑叠加。

普通 `geom_col()` 和 `geom_bar()` 可使用共用的柱形系列控件。样式统一的系列可编辑填充、描边颜色、描边宽度和透明度。可以调整纵向柱的柱宽，以及横向柱的厚度，支持固定颜色和等宽柱的数据映射颜色。厚度使用与柱延伸方向垂直的轴的数据单位。柱中心、数据长度、堆叠或并排的位置、计数结果及数据映射的颜色和图例随原图保留。使用 `facet_wrap()` 或 `facet_grid()` 时，可从元素列表只编辑选中的分面。分面内按离散类别填色的柱形可以选中某个类别单独调整宽度。类别取自 R 捕获的分组，使用相同的填充颜色也能区分。轴反转和对数切换时会按当前尺度绘制厚度。画布按实际柱形命中，较大图层可从元素列表选中系列。 [ggplot2 柱形图](https://ggplot2.tidyverse.org/reference/geom_bar.html)

普通 `geom_line()` 和 `geom_path()` 可分别改线宽和线型，支持原始线宽和线型统一的多组曲线。标准分类图例能定位到该图层的线条键时，可按类别编辑，各分面的同类曲线和共用图例线会同步更新。同一图例中的散点键沿用原来的样式。由数据映射的各组颜色保持原样，统一设置了固定颜色且没有图例键的曲线还可改色。分面曲线没有共用图例键时，可单独编辑选中的分面。带箭头、笔画映射或自定义图例键的曲线沿用脚本样式。画布沿分面内的实际路径选择曲线，包括由缺失数据隔开的各段，也可从元素树选择。

普通 `geom_ribbon()` 置信带和 `geom_area()` 面积图，可使用与 Matplotlib 范围填充相同的填充颜色控件。支持没有数据映射或图例键的统一填充，分面可分别选择。没有描边时还可调整透明度，有描边时可独立改填充颜色。与曲线或柱形重叠时，画布按绘制顺序和填充透明度判定遮挡。改色、撤销和导出沿用已计算的上下界、堆叠位置和面板裁剪。普通分类填色、无描边的 `geom_ribbon()` 还可在分面内按类别单独调整填充透明度。类别沿用构建时捕获的实际数据映射，保留原颜色、分面、区间几何和图例。

普通 `geom_errorbar()` 系列和 Matplotlib 共用误差棒控件。样式统一时可以编辑颜色、线宽和透明度。常见的纵向和横向端帽还可设置长度和粗细，单位为 pt。长度设为 0 时隐藏端帽，误差区间和分组位置保持原值。未编辑长度时，端帽仍随原脚本的坐标尺度变化。使用分面时能单独修改选中的一格。数据映射的颜色和透明度保留原值，线宽与端帽仍可调整。使用普通分类颜色图例时，可在分面内选中某个类别，只改变该类别的端帽长度和粗细。其他类别、区间主干和共用图例键保持原样。同色类别也按 R 的实际数据分组区分。

R 会话进入可编辑状态后，可在样式栏的画布层统一修改 ggplot2 与 Matplotlib 的轴标题。字重提供常规和粗体，字形提供正体和斜体，两项可组合并各自撤销。对能定位到单段纯文本的图标题、轴标题、图例和分面标签也可单独修改。使用脚本原有字体族绘制，R 的字重以本机字体提供的常规和粗体为限。R 会话结束后，已归档的图保留上次确认的样式。

画布样式栏也可统一两种图源的轴标题字号。输入按页面上的实际 pt 计算，每张图按自身缩放比例换算。选中单个普通文字标题后，可在属性栏调整它的字号。ggplot2 的图标题、副标题、图注和四侧轴标题保留原有文字边距，字号变化后重新测量布局与命中范围。修改、撤销或导出沿用已捕获的数据和统计结果。

普通数值轴或类别轴的一侧刻度文字也可以单独选择字体族、设置粗体与斜体。使用主题控制文字方向的轴可在属性栏设置刻度标签旋转角度。轴边距和图内元素命中范围会随这些变化重新计算。 [ggplot2 刻度指南](https://ggplot2.tidyverse.org/reference/guide_axis.html)

可单独给上述标题选择无衬线、衬线或等宽字体，也可以用画布样式栏给混排轴标题统一切换。R 由运行时在本机解析具体字体面，已有的自定义字体可恢复回脚本原值。

保存布局时，Tavotto 在项目原有的 Figure 归档中保存该编辑状态的 SVG 与 PDF。重开可以显示和导出这份归档，临时预览缓存、R 会话或脚本已移走时也可读取。项目需要同时保留已有的 `tavottofile` 目录。重新进入图内编辑时，主动运行原脚本并指定同一对象即可定位到现有面板，包括它在另一张画布上的情况。重新计算采用本次运行时读到的数据。

如果启动时先恢复了一个没有图形归档的历史版本，缺失的磁盘脚本会在创建绘图进程之前报出。随后打开含完整归档的排版时，可从归档继续混排导出。

要接入 RStudio 或终端中已经运行的 R，在脚本库选择关联的项目 R 脚本和「连接已有 R 会话」，填写当前会话中的 ggplot 对象名。复制一次性连接命令，在同一个 R 控制台运行。Tavotto 会捕获该对象，沿用当前 R 的包、工作目录和图形设备。完成编辑后，在 Tavotto 的会话卡上点「返回原 R 控制台」。已保存的排版可在会话结束后重开和导出。

从项目脚本运行的 ggplot 图可在单图导出时选择 R，另存一份 `_edited.R`。图标题、副标题、图注和坐标轴标题的颜色、字号、字重和字形，以及四侧坐标轴刻度文字支持的颜色、字号、字重、字形和旋转角度，都可写进副本。字体族按当前图形使用的实际字体写入。原脚本的图形设备拒绝该字体时，字体设置随排版保存，其余样式在新的临时副本中重新验证。Tavotto 使用当前会话的 R 运行时，在断网且只有临时副本可写的环境中重放，并核对与当前图形的几何和像素。适用于 macOS、Windows x64 和配置了 Bubblewrap 的 Linux。

普通直角坐标图可将连续轴的显示范围和反转写进 R 源码。某个方向的范围或反转在所有分面轴组都采用同一项编辑时，会成为脚本的坐标设置。只改部分独立轴或给各组设不同值时，调整随排版保存。普通 `geom_raster()` 的轴反转也可写回。直接运行 R 脚本时，栅格顺序和图内位置跟随坐标方向，避免标签与数据格对应错误。普通散点和曲线直接使用数据位置时，线性、以 10 为底的对数和对数几率也可写回源码。写回这一项需要所有共享轴采用相同尺度，且其他调整能够一并写回。使用重新计算统计或位置的图层时，尺度切换随排版保存。范围仍使用原数据单位，并沿用源码的尺度定义。如果原有尺度无法表示新范围，范围也随排版保存。导出报告会列出留在排版中的调整。

普通矩形绘图区的主网格开关、网格线样式、底色和统一边框颜色及线宽可写回为原生 ggplot2 主题。分面都采用同一组改动时也可写回。只改一格、分面采用不同样式或逐边调整边框时，相关编辑随排版保存。

普通散点的固定面积、形状、透明度以及适用的填充和描边可写回原生图层。普通曲线也可写回固定的线宽、线型和颜色。普通柱形的固定填充、描边与透明度，以及普通误差棒的固定颜色、线宽与透明度也可写回。固定样式须在同一图层所有有数据的分面上采用相同的值。柱宽、横向厚度与误差棒的端帽长度及粗细可按单个分面写回，脚本按实际分面值识别它们。柱中心、堆叠与并排位置及误差区间仍由原代码计算。使用普通分类颜色图例时，柱宽、横向厚度与误差棒端帽也可按实际数据类别写回，同色类别各自保留自己的设置。其他单个数据类别的编辑和分面内不同的固定样式随排版保存。

普通连续色阶的数值范围与调色板可以写回 R 源码。重跑脚本时，色条和各关联图层会使用相同的颜色映射。色条上单独设置的刻度格式可随排版继续重放。

脚本可以在顶层一次赋值生成图对象，也可以连续几次给同一对象添加图层。样式代码放在这组赋值之后，原脚本的其它表达式和换行格式保留。

把当前排版保存到项目后，可在单图导出中选择「将样式写入 R 脚本」。Tavotto 展示逐行差异、两处备份位置和仍留在排版里的调整。用户确认后，Tavotto 再次重放比对，写入原脚本，并把剩余调整和核验过的图形归档写入同一份排版。Windows 使用同一渲染器绘制桌面和隔离重放的 SVG，并逐像素核对透明度。通过后，归档沿用已保存的原生 PDF。可以在确认窗口或设置的脚本备份中一键恢复原脚本和对应排版。如果之后编辑过源文件或改动排版内容，旧备份会保留，恢复请求会要求先重新核对。

输入文件完全追踪和其它 ggplot2 元素的源码转译仍属于后续工作。R／MATLAB 的转换入口与静态文件导入可独立使用。

## 验证

给 `TAVOTTO_TEST_RSCRIPT` 指定真实 Rscript 后运行 `tests/test_native_ggplot_capture.py`。用例核对副标题、图注、四边坐标轴标题和刻度文字、图例标题、图例条目、连续色条刻度文字及横竖分面标签的绘制位置与独立改色。用例也检查数字格式、刻度字号与主网格线对齐、多组曲线与图例键同步、置信带和面积图的填充、散点样式、色阶联动、柱形绘制样式及几何位置，以及未编辑图层和统计调用次数。桌面路径覆盖撤销与重做、布局重开及混排导出。

用独立的 `R_LIBS_USER` 可在同一 R 运行时下验证不同的 ggplot2 版本，同时保留工作项目的 R 库。当前实测版本在支持矩阵中记录。

`Native ggplot2` 工作流在 GitHub 托管的 Windows 和 Intel macOS 上运行真实 R，用同一套测试检查图内编辑、保存重开、项目交换和导出。它从源码启动桌面服务，安装包另行验收。

### 发布候选的混排与交换验收

在开发环境中把 `TAVOTTO_TEST_RSCRIPT` 设为本机 Rscript 的绝对路径，然后运行以下用例。要验收已打包的成品，同时把 `TAVOTTO_TEST_EXE` 设为该成品内桌面 sidecar 的可执行文件路径。

```sh
python -m pytest tests/test_core_v02_release_candidate.py
```

用例启动经过会话认证的桌面服务。在同一画布上修改 Matplotlib 标题和 ggplot2 标题颜色，保存、导出并制作交换包。另一份空白配置将包安装到新项目。移走接收端源脚本后，再用一份空白配置重开已保存的排版。独立 PDF 读取器核对图幅、两个标题的位置与 ggplot2 标题颜色，并比较传输前后的页面像素。两张图的归档 SVG 也逐字比对，附上不匹配的修改时必须拒绝。要再次进入图内编辑，需要提供源脚本和对应运行时。

从排版菜单选择「导出项目包」时，整个排版的每张画布都进入可安装的交换包。接收方可以从项目选择器安装到新目录。早期生成的项目包仍可在已打开的项目中按原流程打开。

同一用例还核对混排冷重开后的 PDF、矢量 SVG 和 144 PPI PNG。每份文件的摘要与自己的产物回执一致，三种格式对应同一次导出和同一画布状态。加入仅有 PDF 表示的普通素材时，SVG 单独报告该素材，PDF 和 PNG 照常写出。
