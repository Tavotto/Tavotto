# R／ggplot2 原生图形

在桌面版脚本库的 R 脚本旁选择「用 R 运行」。填写脚本生成的 ggplot 对象名和图幅尺寸。可指定本机 Rscript 的路径。留空时查找桌面进程 PATH 中的 Rscript。脚本在自身所在目录以当前账户的权限执行。

R 运行时须安装 ggplot2、svglite 和 jsonlite。生成 PDF 还需要 R 的 Cairo 图形设备。版本与支持等级见[支持矩阵](../support-matrix.json)。

进入图内编辑后，在元素树中选中普通文本标题即可改色。适配器在会话内保留一次构建得到的 gtable、统计图层和范围。改色、撤销与导出只重绘这份已计算的结果。脚本通过标准输出生成的文字与会话控制分开传输。

保存布局时，Tavotto 在项目原有的 Figure 归档中保存该编辑状态的 SVG 与 PDF。重开可以显示和导出这份归档，临时预览缓存、R 会话或脚本已移走时也可读取。项目需要同时保留已有的 `tavottofile` 目录。重新进入图内编辑需要用户主动启动 R 脚本，重新计算采用本次运行时读到的数据。

首批只使用由桌面启动的 R 会话。终端和 IDE 中已运行的 R 会话、其它 ggplot2 元素的编辑、R 源码写回和输入文件完全追踪都属于后续工作。R／MATLAB 的转换入口与静态文件导入仍可独立使用。

## 验证

给 `TAVOTTO_TEST_RSCRIPT` 指定真实 Rscript 后运行 `tests/test_native_ggplot_capture.py`。用例覆盖只改变标题颜色、统计调用次数及随机数状态保持、撤销、会话终止、未认证启动拒绝、布局归档及混排 PDF。
