# 文件都放在哪

> 属于 [Tavotto 自述](../../README.zh-CN.md)，这里放 README 指过来的细节。

## 文件都放在哪

<details>
<summary>数据目录与各自装什么</summary>

界面上只有四个名词：**项目**是你的脚本文件夹；**排版**是一份可以包含多张画布的
Tavotto 文件（一个项目可以有多份排版）；**画布**是排版里的一张图；**项目包**是导出的
`.tavotto` 单文件，用来分享。

| 界面上的动作 / 列表 | 存在哪 | 存什么 |
|---|---|---|
| **保存排版**（⌘S / Ctrl+S，也是自动保存） | 本机数据目录的 `layouts/_autosave/`：macOS `~/Library/Application Support/Tavotto/` · Linux `~/.local/share/tavotto/` · Windows `%LOCALAPPDATA%\Tavotto\` | 你正在编辑的这份排版（全部画布）。它在这台电脑上，**不在项目文件夹里** |
| **另存为新排版…**（⇧⌘S / Ctrl+Shift+S） | 项目内的 `tavottofile/<排版名>.json`（没打开项目时落在数据目录的 `layouts/`） | 此刻这份排版的一份命名副本，随项目一起备份 / 同步；之后按 ⌘S 不会自动更新它，要更新就再另存一次同名 |
| 顶栏菜单「项目里的排版」→ 打开排版… | 读项目的 `tavottofile/`（旧版本写在项目 `canvases/` 与数据目录 `layouts/` 的也列出来，只读兼容） | 另存进项目的那些排版 |
| 顶栏菜单「本机最近的排版」 | 这台电脑上的索引 + 数据目录 `layouts/_autosave/` | 最近在这台电脑上编辑过的排版，跨项目；属于别的项目的会标出项目名 |
| 排版版本… | 项目内的 `tavottofile/versions/` | 每份排版的版本快照 |
| 导出（成图） | 项目内的 `tavottofile/export/`（项目设置可改） | 导出的成图文件 |
| 导出项目包 | 同上，`tavottofile/export/<名>_<时间>.tavotto` | 当前这份排版 + 它用到的素材 + 源脚本 + 校验清单 |
| 导入项目包… | 不往项目里写任何东西 | 把包里的排版作为一份新排版打开（和别的排版一样保存在本机）；素材不会被自动装进项目 |
| 你的脚本与图 | 只读——除非你明确选择「写回原始文件」，且该权限可按项目锁死 | |

</details>
