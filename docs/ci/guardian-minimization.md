# CG-03 reviewed reduction mechanism (WIP)

This stage is not ready for product qualification. No real failing family has been
minimized; AC-06 remains not_run. The prior six synthetic tests missed evidence
forgery, non-finite budgets and untitled Figure loss. Independent review exposed
those problems; this revision adds retained-packet checks rather than accepting
caller verdict dictionaries.

Only exact file-graph hashes in a committed, unchanged schema-2 review plan may
execute. The original is subject to the same review requirement as every reduction.
Unreviewed AST deletions return readable source/graph packets with pending_review
and execution=not_run. No external LLM, installer, worker or OS sandbox is added.

Each real probe retains its exact input script/helper/data bytes, raw native and
authenticated V2 observations, actual exec-event and fixture counters, process logs,
source-before/after identity, plan digest, UUID, and environment facts. The verifier
reads these hash-referenced bytes and independently derives the result. It rejects
changed source/plan/input/data, missing counters, native errors, unbound environments
and mismatched counts. Scientific truth is explicitly reviewed per-Figure titles;
this is not general array correctness. Untitled Figures remain in the required
capture set. The signature includes the exact failing criterion and observed delta;
a different wrong scientific value cannot stand in for the original failure.
V2 does not expose per-stem titles. A multi-Figure result without an observed
failure is therefore unknown; aggregate title equality cannot prove association.

A bounded search counts candidate attempts separately from its original probe and
records oracle calls; verified per-leg execution counts remain in each proof. Time
budgets must be finite and positive; cleanup has its own existing process-group
budget. Partial/timeout bytes remain in the artifact and cannot qualify acceptance.
Completed history survives a rejected or interrupted trial. An atomic terminal
report records source identity and every retained evidence reference.
Even a complete raw packet cannot qualify after timeout, a nonzero process exit,
or unproved process-tree cleanup. The reused Windows cleanup lacks a group-gone
predicate, so this mechanism does not qualify that platform yet.

File preservation means identical relative names and unchanged non-entry bytes.
It does not establish arbitrary runtime import/data access relationships. Shared
tracebacks and caller-supplied confirmed_cause claims never confirm a cluster; all
root-cause proposals remain hypotheses until a separate causal contract exists.

The pending example is a negative control: current CI 38847288841 proves both
native and Tavotto title value=2. It supplies no failing-family premise or execution
authority, and must not be used to invent a defect.

Cloud dependency/font downloads remain CONNECT403. The standard-library packet
tests and isolated witnessed mutations are mechanism evidence only. The rewritten
real probe has not executed. A real reviewed failure, every accepted native/Tavotto
trial, final re-verification and independent review are still required before PR
promotion; Safe API results cannot prove desktop Native behavior.
