# 科学图形准则（选图、画图、改图前读）

<!-- 由 Tavotto 仓库的 src/tavotto/profiles/sciviz_guidance.json 生成，不要手改 -->

依据三本书（Wilkinson《The Grammar of Graphics》、Munzner《Visualization Analysis and Design》、Wilke《Fundamentals of Data Visualization》）与 Tavotto 自己的推导。
「作者偏好」一类不是对错：按用户或期刊来，不要当成问题报告给用户，也不要擅自改掉。
「只能由作者确认」一类不要猜：问用户，或如实说不知道。

## 数据与编码必须一致（违反即错图）

- **G-001 对数轴上只放正值**（硬性）：对数轴画不出 0 和负值，matplotlib 会把它们静默画到轴外。数据里有非正值时，改用线性轴或 symlog，或在脚本里显式处理，并告诉用户少画了哪些点；误差线下端 ≤ 0 时同理。
  - 例外：symlog / logit 轴不适用；色条的 LogNorm 另行处理
  - 出处：FDV ch.3 Coordinate Systems and Axes, p.20；MATH log(x) 在 x ≤ 0 处无定义；负值的情形书里没有讨论
- **G-002 线性轴上的柱从 0 起**（硬性）：柱长要和数值成比例，线性轴上的柱必须从 0 起，不要用 ylim 截掉柱底。要突出小差异时改用点图或折线（它们可以不从 0 起）。表示差值的柱从 0 向两侧画，并在图注说明是差值。
  - 例外：差值柱；浮动柱 / 区间柱 / 甘特图：柱底本身有含义；对数轴上的柱见 G-003
  - 出处：FDV ch.17 The Principle of Proportional Ink, p.209；FDV ch.6 Visualizing Amounts（点图与非零范围）, p.53–54；GoG §6.1, p.92（零基线是尺度问题，条形的定义本身不要求底在零）
- **G-004 填充面积图从 0 起**（硬性）：用面积表示数量（面积图、填到底的曲线）时，y 轴要从 0 起；否则不要填充，只画线。
  - 例外：置信带等表示区间的填充不适用
  - 出处：FDV ch.13 Visualizing Time Series, p.134
- **G-035 饼图各块合计 100%，重叠类别不进同一个饼**（硬性）：饼图和堆叠比例图的各部分必须互斥且合计为整体；一个样本可能同时属于多类时，不要画成一个饼。
  - 出处：FDV ch.11 Visualizing Nested Proportions, p.105
- **G-036 数据约束的属性不按美观改**（硬性）：柱高、点的位置、表示数值的气泡面积由数据决定，编辑图时不能为了好看去改；颜色、线宽、字体、图例位置是样式，可以随意改。用户要改前者时，告诉他应该改数据或脚本。
  - 出处：GoG §10.5, p.278；GoG ch.18 ViZml（数据 / 结构 / 样式三层）, p.589–609

## 统计表达（依赖上下文，说明而不替用户定）

- **G-003 对数轴上的柱表示比值，从 1 起；数量用点**（硬性）：在对数轴上画数量（amount）的柱，柱长没有意义，改用点图。只有柱表示比值（ratio、fold change）时才在对数轴上画柱，且从 1 起。是不是比值要问用户，不要猜。
  - 出处：FDV ch.17 The Principle of Proportional Ink, p.215
- **G-006 SD 与 SE 不混用**（硬性）：SD 描述数据的散布，SE 描述估计的精度，两者含义不同。用户问「用哪个」时说明区别，由用户按研究目的选，不替用户定。
  - 出处：FDV ch.16 Visualizing Uncertainty, p.187
- **G-007 不靠误差线是否重叠判断显著性**（硬性）：不要根据误差线是否重叠告诉用户「差异显著 / 不显著」。Tavotto 图上只放描述性汇总，不做显著性检验。
  - 出处：FDV ch.16 Visualizing Uncertainty, p.191
- **G-009 改轴范围不会重算统计**（硬性）：缩小 xlim / ylim 只是裁掉画面，脚本里算好的回归线、均值、置信带仍基于全部数据。用户为好看而裁掉数据时，提醒被裁掉的点仍参与了汇总，或者建议在脚本里真正筛选数据并重算。
  - 例外：有意的局部放大（inset）
  - 出处：GoG §9.1.8, p.219；GoG §9.1, p.191–192（数据缩放与图形缩放）
- **G-011 先变换、再汇总**（硬性）：均值的 log 不等于 log 的均值。数据要在对数尺度上比较时，先取对数再算均值和误差，在原始刻度上画出来的误差线会不对称。改轴尺度不会自动做这一步，要说明。
  - 出处：GoG §6.2, p.93；GoG §9.1.8, p.218
- **G-012 能露出原始数据就露出**（强建议）：汇总统计会丢信息（均值、方差、相关都相同的数据可以长得完全不同）。数据量允许时，把原始点叠在汇总图形上或并排展示，并说明汇总丢掉了什么。「数据量允许」的具体界线是工程选择，由数据出图的配方规则定义，要如实说是工程阈值。
  - 例外：点太多导致严重遮挡时改用密度或分箱，并说明
  - 出处：FDV ch.12 Visualizing Associations, p.124；VAD §1.6 与 ch.13 Reduce（Anscombe 四重奏）, p.7–8
- **G-013 样本太少不用小提琴、密度图和箱线图**（强建议）：每组点数不多时，小提琴和密度图会凭空造出形状；箱线图的箱和须也只由少数几个点决定。这时改画原始点（加抖动）。书里没有给具体的 n 阈值；Tavotto 用的阈值是工程选择，要如实说。
  - 出处：FDV ch.9 Visualizing Many Distributions at Once, p.85；TAVOTTO 箱线图同样适用是 Tavotto 的推导；书里只对小提琴与密度图明说
- **G-014 直方图的 bin 宽要试、要说明**（强建议）：直方图的形状随 bin 宽变化，要试几个 bin 宽，并告诉用户选了多少、为什么；各 bin 必须等宽。不要声称某个 bin 宽「正确」。
  - 出处：FDV ch.7 Visualizing Distributions, p.61；VAD §13.4 Histogram, p.306
- **G-015 密度估计不预测不可能的值**（强建议）：核密度曲线伸到负浓度、负年龄等不可能区间时，要截断或换画法，并告诉用户。
  - 出处：FDV ch.7 Visualizing Distributions, p.64
- **G-016 平滑与拟合写明方法和参数**（强建议）：同一份数据可以平滑成很多样子。画平滑线或拟合线时，告诉用户用了什么方法、什么窗口或参数，并建议写进图注；有明确函数形式时优先用它。
  - 出处：FDV ch.14 Visualizing Trends, p.150
- **G-017 抖动会改数据：要小心、要固定种子**（强建议）：加抖动（jitter）时幅度要小于数据精度，并固定随机种子，保证重跑得到同一张图。
  - 出处：FDV ch.18 Handling Overlapping Points, p.222；FDV ch.28 Choosing the Right Visualization Software, p.326
- **G-037 派生数据要说明，不擅自派生**（Tavotto 推导）：归一化、差值、比值、取对数、分箱、聚合都会改变读者看到的东西，而且会丢信息。只在用户同意后做，做了要写进脚本、告诉用户丢了什么，并建议写进图注。
  - 出处：VAD §3.4.2.3 Derive, p.50–53；TAVOTTO 「只在用户同意后做」是 Tavotto 的约束
- **G-053 已经汇总过的表不再汇总**（强建议）：表里已经是均值和误差列（sd、sem、ci）时，直接用这两列画点和误差线，误差类型按列名或用户确认；不要对均值再算均值和 SD，那会得到一个没有意义的数。误差列类型拿不准时按 G-005 处理，不默认成 SD。
  - 出处：GoG §3.5, p.52（预聚合后统计不可复原）；TAVOTTO 「对汇总表不再算 mean ± sd」是 Tavotto 据此的推导

## 感知建议（指导性原则，有例外）

- **G-010 变量取 log 与轴取 log 的标题不同**（强建议）：轴本身是对数轴时，轴标题写变量名（如 Concentration），不写 log(Concentration)。数据先取了对数、再画在线性轴上时，轴标题写 log10(…) 并注明底数。
  - 出处：GoG §6.2, p.93；FDV ch.3 Coordinate Systems and Axes, p.17–18
- **G-018 只有有序、被连续跟踪的横轴才连线**（强建议）：折线暗示相邻值之间有连续变化，只用于时间、剂量、浓度这类有序横轴上对同一对象的跟踪。类别横轴（组名、样品名）用柱或点；两个独立测量的量之间（方法比较、材料性能、两种指标的关系）没有 key，用散点，不连线。
  - 出处：VAD §7.5.1 Line Charts, p.156；VAD §7.4 Scatterplots, p.146
- **G-019 最重要的量用位置编码**（强建议）：人眼判断同一刻度上的位置最准，长度次之，角度、面积、颜色深浅更差。把读者最需要比较的量放在共同坐标轴的位置上。这是指导性的综合结论，不是定律，说理由时要这么表述。
  - 例外：任务是看整体与部分的比例时，饼图也可以（见 G-043）
  - 出处：VAD §5.4 Channel Effectiveness, p.102；VAD §5.5.1, p.105（转述 Cleveland–McGill 与 Heer–Bostock 实验）
- **G-020 有序数据用有序的通道，类别用可区分的通道**（强建议）：数值和有序类别用位置、长度、亮度编码；无序类别用色相、形状或分区编码。不要用色相表示大小，也不要用暗示顺序的通道表示无序类别。
  - 出处：VAD §5.4.1 Expressiveness, p.100
- **G-021 类别色不超过约 8 种**（强建议）：类别色超过约 8 种就很难区分。可以合并成「其他」、分面，或者直接在线条末端标注名称，而不是继续加颜色。
  - 例外：连续色映射不适用
  - 出处：FDV ch.19 Common Pitfalls of Color Use, p.234；VAD §10.3.1 Categorical Colormaps, p.226–229（小而分离区域约 6–12 种）
- **G-022 连续数据不用彩虹色图**（强建议）：jet、rainbow 这类色图亮度不单调，会制造假边界、藏起真细节。连续数据用亮度单调的色图（如 viridis、batlow）。类别少的分段彩虹色可以用。
  - 例外：类别少的分段彩虹色
  - 出处：VAD §10.3.2 Ordered Colormaps, p.232–234；FDV ch.19 Common Pitfalls of Color Use, p.237–238
- **G-024 照顾色觉缺陷读者：冗余编码，并用模拟器检查**（强建议）：约 8% 的男性有色觉缺陷。不要只靠颜色区分组别，同时用线型或标记形状区分；避免红绿对比；用色觉模拟检查，不要只依赖「色盲安全色板」。
  - 出处：FDV ch.19 Common Pitfalls of Color Use, p.242；VAD §10.3.4 Colorblind Safe, p.235
- **G-025 黑白下也要读得懂**（强建议）：最关键的区分在灰度打印下也要成立：把最重要的属性放在亮度上，色相只做辅助。
  - 出处：VAD §6.9 Get It Right in Black and White, p.140
- **G-026 x、y 同单位时两轴等比例**（硬性）：两个轴画的是同一个量（如两种方法测同一批样品、前后两次测量、预测与实测）时，用相等的轴比例（aspect=1），并考虑画 y = x 参考线。两列单位相同只是线索：是不是同一个量，由用户确认，或者以用户自己的话为准。
  - 例外：两轴单位不同时可以自由拉伸
  - 出处：FDV ch.3 Coordinate Systems and Axes, p.15
- **G-027 小倍数用相同的轴范围**（强建议）：同一种图拆成多个面板比较时，各面板用相同的轴范围；确实要不同时，在图注里提醒读者。
  - 例外：各面板量纲不同
  - 出处：FDV ch.21 Multi-Panel Figures, p.259
- **G-028 多面板视觉语言一致**（强建议）：同一个类别在所有面板里用同一种颜色、同样的顺序；面板标签的字体、大小、位置一致；轴要对齐。
  - 出处：FDV ch.21 Multi-Panel Figures, p.261–265
- **G-029 叠加不超过两三层，多了改并排**（强建议）：一个坐标系里叠两层很容易读，三层要小心；更多系列时考虑拆成小倍数并排。书里没有给精确的系列数阈值。
  - 出处：VAD §12.2 Juxtapose vs Superimpose, p.267
- **G-030 没有理由不用 3D**（硬性）：3D 柱、3D 饼这类装饰性 3D 会扭曲数值，不要画。数据本身是三维形状（地形、结构）时才用 3D；抽象数据的第三个变量改用颜色、分面或热图。
  - 例外：真实三维对象；可交互旋转的展示
  - 出处：FDV ch.26 Don’t Go 3D, p.305；VAD §6.3 No Unjustified 3D, p.117
- **G-031 在最终尺寸下检查文字大小**（强建议）：轴标签、刻度标签往往太小。按最终印刷尺寸检查文字大小；具体的 pt 下限只来自期刊或 Tavotto 的出版规范，书里没有给数值。
  - 出处：FDV ch.24 Use Larger Axis Labels, p.291
- **G-032 数值轴的标题带单位**（强建议）：数值轴的标题写明量和单位，如「Time (h)」；不要让读者猜轴代表什么。类别轴、年份这类一看就懂的可以省略单位。
  - 例外：自明的类别或年份
  - 出处：FDV ch.22 Titles, Captions, and Tables, p.270–271
- **G-033 图例顺序跟数据走；能直接标注就不用图例**（强建议）：图例条目的顺序和曲线末端的上下顺序一致；线条不多时，可以把名称直接标在线旁。
  - 出处：FDV ch.20 Redundant Coding, p.249–251
- **G-034 含线条和文字的图不存 JPEG**（强建议）：数据图优先存矢量 PDF；需要位图时用 PNG 或 TIFF，不用 JPEG（有损压缩会糊掉线条和文字）。期刊另有要求时按期刊。
  - 例外：期刊明确要求的格式
  - 出处：FDV ch.27 Understanding the Most Commonly Used Image File Formats, p.322
- **G-039 推荐理由分三档说**（Tavotto 推导）：给出推荐理由时分开说三件事：数据事实（如「横轴是有序的时间」）、感知依据（如「位置比面积准确」，这是指导性原则）、用户确认过的目的（如「比较组间均值」）。不要把它们合成一个「置信度」，也不要说某种图「被证明最优」。
  - 出处：VAD ch.4 Validation, p.77–78；VAD §1.11, p.13；TAVOTTO 「三档分开、不合成置信度」是 Tavotto 依据 VAD 第 4 章验证层次的推导
- **G-040 无序类别的柱按数值排序**（强建议）：柱代表无序类别时，按数值升序或降序排；类别本身有顺序（时间、剂量、等级）时保持原顺序。
  - 例外：类别有自然顺序
  - 出处：FDV ch.6 Visualizing Amounts, p.48
- **G-041 双 y 轴尽量避免**（偏好）：两个量纲不同的量优先上下分面，各画各的坐标轴。用户坚持用双 y 轴时照做，不当错误处理。依据只有一本书，另两本没有讨论。
  - 出处：GoG §12.1.4, p.351–352
- **G-052 同一个横轴值有多次观测时不逐点连线**（Tavotto 推导）：同一个 x 有多个重复观测（平行样、重复孔）而没有确认过的个体编号时，不要按行顺序逐点连线，那会来回折出不存在的变化。画每个 x 的汇总线（写明汇总方式）并露出原始点；有个体编号且用户确认是同一对象时，才按个体分别连线。
  - 例外：用户确认的个体轨迹（每个个体一条线）
  - 出处：VAD §7.5.1 Line Charts, p.155–156（连线标记表示有序 key 上的连续）；TAVOTTO 重复 x 不连线是 Tavotto 依据 expressiveness 的推导；数据出图配方的拒绝码 line_duplicate_x_unconfirmed 是同一条
- **G-054 数据跨数量级或表示倍数时考虑对数轴**（强建议）：数据跨好几个数量级（剂量梯度、细菌载量、浓度），或者表示比值、倍数变化时，考虑用对数轴，否则小值会挤在一起看不出差别。含 0 或负值时不能用对数轴（见 G-001）；取对数后的汇总按 G-011。用对数轴是展示选择，要告诉用户，「跨几个数量级算多」是工程阈值。
  - 例外：含 0 或负值的数据
  - 出处：FDV ch.3 Coordinate Systems and Axes, p.17；FDV ch.3 Coordinate Systems and Axes, p.20

## 只能由作者确认（不猜）

- **G-005 误差线必须说明代表什么**（硬性）：画出来的误差线看不出是 SD、SEM 还是 95% CI，必须由作者写明（图例或图注）。不知道时问用户，绝不默认成某一种；你自己算的汇总要如实告诉用户用了哪一种。
  - 出处：FDV ch.16 Visualizing Uncertainty, p.189；GoG §7.2, p.131（误差线只是 interval 几何，同一几何可表示不同统计）
- **G-008 置信带写明置信水平**（强建议）：拟合线外的置信带要写明置信水平（如 95%）和拟合方法；不知道就问。
  - 出处：FDV ch.16 Visualizing Uncertainty, p.199
- **G-023 发散色图的中点要有含义**（强建议）：发散色图只在数据有一个有意义的中点（0、对照值、阈值）时使用，中点由用户确认，不能因为数据里有负数就自动选发散色图。
  - 出处：FDV ch.4 Color Scales, p.30；VAD §2.5 Attribute Types（diverging）, p.33
- **G-038 数据含义由用户确认，不从数值猜**（硬性）：光看数值无法知道列的含义：哪一列是自变量、是否为时间、样本是独立还是重复测量、误差列是 SD 还是 SEM，都要用户确认。拿不准时问选择题；用户说不确定，就走最保守的画法。
  - 出处：VAD §2.2 / §2.6.1, p.22, p.36, p.39；GoG ch.19 Reader, p.612（没有元数据就分不清独立组与重复测量）

## 作者偏好（不是对错：按用户或期刊，不要当问题报告）

- **G-042 折线图和点图可以不从 0 起**（偏好）：位置编码（折线、点）不要求从 0 起，按想让读者看到的变化选范围；但范围选得太窄会夸大变化。不要把「折线没从 0 起」当成问题报告。
  - 例外：与柱或面积组合时按 G-002 / G-004
  - 出处：FDV ch.6 Visualizing Amounts, p.53–54；ch.17, p.209–210
- **G-043 饼图、堆叠柱、并排柱没有绝对优劣**（偏好）：表示比例时，饼图适合少数几块、强调整体的简单分数；多组比较时柱更好。按数据和用户偏好选，不要把饼图本身当错误。
  - 出处：FDV ch.10 Visualizing Proportions, p.96
- **G-044 分组柱还是拆成多张图：品味**（偏好）：分组柱与拆成多个小图各有取舍，按用户偏好和要强调的比较选。作者本人偏好拆开，但明说是品味。
  - 出处：FDV ch.6 Visualizing Amounts, p.52
- **G-045 直方图还是密度图：品味**（偏好）：单个分布用直方图或密度图都可以；比较多个分布时密度图通常更清楚（作者不推荐堆叠直方图）。
  - 出处：FDV ch.7 Visualizing Distributions, p.64–68
- **G-046 误差线带不带端帽：品味**（偏好）：端帽有无纯属偏好，按用户或期刊风格，不要提建议。
  - 出处：FDV ch.16 Visualizing Uncertainty, p.192
- **G-047 外框、网格：品味**（偏好）：要不要外框、要不要网格、网格多密都是偏好。默认按 Tavotto 出版规范或期刊；作者本人偏好白底上浅而少的网格。不要把相反做法当问题。
  - 例外：完全没有网格时，至少保留一条关键参考线（如基线）
  - 出处：FDV ch.23 Balance the Data and the Context, p.279–282
- **G-048 空心点还是实心点，轮廓还是填充：品味**（偏好）：作者偏好实心点和浅色填充，而不是空心轮廓，但这是意见。用户的选择照做，不提建议；只有在遮挡严重时，才把空心点作为可选方案提一句。
  - 出处：FDV ch.25 Avoid Line Drawings, p.297–302
- **G-049 刻度标签旋转：偏好横排**（偏好）：类别名太长时，作者偏好把柱改成横向，而不是旋转刻度标签；这是偏好，用户要旋转就照做。
  - 出处：FDV ch.6 Visualizing Amounts, p.46
- **G-050 柱加误差线技术上没错，但常有更好的画法**（偏好）：均值柱加误差线是科研常见画法，不是错误；数据量允许时可以建议同时画出原始点或分布，让读者看到变异。用户坚持就照做。
  - 出处：FDV ch.16 Visualizing Uncertainty, p.193
- **G-051 不按心理物理指数修正大小**（偏好）：不要为了「感知准确」去按 Stevens 指数改写面积或大小映射；保持数据到大小的映射可解释，必要时限制变化范围。
  - 出处：GoG §10.1, p.258–259
